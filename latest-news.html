C-03Sphinx: A Git Hook That Quizzes You on AI-Generated Code Before You Push

📰 Article (English)

Sphinx is a free, open-source Git hook designed for developers who use AI coding agents. When you attempt to push to a protected branch, Sphinx pauses the push and presents a scenario based on the diff — asking what the code does when something goes wrong, such as a retried payment request or a failed API call. The reviewer evaluating the scenario has never seen your conversation with the agent, so it focuses purely on the code's behavior. A correct answer lets the push proceed; an incorrect one prompts further explanation and a follow-up scenario. The tool addresses a real risk in AI-assisted development: shipping code that the developer cannot fully explain. By requiring engineers to reason about edge cases before each push, Sphinx keeps humans accountable for what AI agents produce. Technically, Sphinx installs via npm as sphinx-understand and runs on macOS, Linux, or WSL with Node 22.19 or later. Running sphinx install hooks it into supported agents including Codex, Claude Code, Cursor, OpenCode, and Pi. The review model is configurable through OpenRouter or any OpenAI-compatible endpoint. Critically, .env files and secrets are never read. For urgent situations, sphinx yolo bypasses the check — but every skip is logged. The project is MIT licensed and available on GitHub under 140 stars at time of writing.
