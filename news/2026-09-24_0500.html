📰 本文 + 和越対訳

Một chuyến bay nội địa của hãng ANA đã phải hạ cánh khẩn cấp tại sân bay Narita vào ngày 24/9, buộc hành khách và phi hành đoàn phải thoát ra ngoài qua cầu trượt khẩn cấp ngay trên đường băng. Hàng chục hành khách đã được sơ tán an toàn dưới sự hướng dẫn của nhân viên mặt đất. Sân bay Narita tạm đóng cửa đường băng liên quan, dẫn đến hàng loạt chuyến bay bị đình hoãn và chuyển hướng. 韓国から輸入されたスクイーズ（握ると変形するスポンジ状おもちゃ）複数種から、基準値を超える有害化学物質が検出されたと消費者庁が発表した。問題となった物質はホルムアルデヒドおよびフタル酸エステル類で、どちらも長期接触や誤飲によって健康被害を引き起こす可能性がある。対象商品は主に100円ショップやネット通販で広く流通しており、低年齢の子どもが頻繁に触れる可能性が高い点から、消費者庁は保護者に対し直ちに使用を中止するよう呼びかけている。輸入・販売事業者に対しては自主回収の実施を求めており、一部事業者はすでに対応を開始したと報告されている。消費者庁は「国内で流通する商品に対する検査体制を強化し、子どもの安全を守るために継続して監視を行っていく」とコメントしており、今後は対象商品の範囲を広げて調査を続ける意向を示した。

C-03GitHub Copilot Gets Local Sandboxing — Agent Sessions Now Restricted to Per-Project File & Network Access

📰 Article (English)

GitHub has shipped local sandboxing for Copilot agent sessions, a significant security improvement that restricts what agentic AI can access during a coding session. Previously, when Copilot agents ran multi-step tasks — browsing files, executing terminal commands, or making external requests — they had broad access to the developer's full filesystem, credentials, and network. The new sandboxing model limits each agent session to only the files and network resources explicitly associated with the open project. Specifically, the sandbox prevents agents from reading files outside the project directory, accessing stored credentials or SSH keys, making arbitrary outbound network requests to external services, and accessing other open workspaces or system configuration files. The feature ships as an opt-in configuration in VS Code and JetBrains, with enterprise admins able to enforce it across organizations. The engineering motivation is clear: as Copilot agents become more capable (now running 50+ step tasks), the blast radius of a malicious prompt injection or a misguided agent action grows proportionally. The sandboxing implementation uses OS-level process isolation on macOS and Linux, and a virtualized environment on Windows. GitHub notes that some agent tasks — like installing packages or running test suites that require network access — may need sandbox exceptions to be configured per-project.

Cụ thể, sandbox ngăn agent đọc file ngoài thư mục project, truy cập credentials hoặc SSH key được lưu trữ, thực hiện các network request tùy ý đến dịch vụ bên ngoài, và truy cập workspace khác hoặc file cấu hình hệ thống. Tính năng này có thể bật opt-in trong VS Code và JetBrains, admin enterprise có thể bắt buộc áp dụng toàn tổ chức. Triển khai dùng OS-level process isolation trên macOS/Linux, và môi trường ảo hóa trên Windows. Một số task như cài package hoặc chạy test suite cần network có thể cần cấu hình exception riêng theo project.
Nếu team bạn đang dùng Copilot agent trên codebase có chứa .env, AWS credentials, hoặc SSH key, đây là tính năng cần bật ngay và kiểm tra lại cấu hình. Đặc biệt quan trọng với Cloud Engineer làm việc trên infra repo có nhiều secret.
