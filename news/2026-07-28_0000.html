C-02Scriptc by Vercel: TypeScript Compiled to Native Binaries via C — No JavaScript Engine Required

📰 Article (English)

Vercel has open-sourced "scriptc," a compiler that takes standard Node.js-compatible TypeScript and compiles it all the way to a standalone native binary — with no JavaScript engine bundled inside. This approach differs fundamentally from what Bun, Deno, or Node.js's single-executable app feature do: those tools simply package the runtime alongside your code. Scriptc instead converts TypeScript through a Typed IR (Intermediate Representation), then emits C source code, which is compiled by the system's clang into a true native executable. The resulting binary contains a purpose-built reimplementation of Node.js APIs, so existing TypeScript code typically runs without modification. The tool is currently in early stage and primarily targets scripting use cases — CLI tools, build scripts, and serverless functions where cold-start latency matters. Vercel published scriptc on GitHub and the project has gained 231 points on Hacker News, suggesting strong developer interest. The practical implications are significant: zero-dependency deployments, faster startup times, and reduced attack surface for supply chain vulnerabilities in JavaScript dependencies.
