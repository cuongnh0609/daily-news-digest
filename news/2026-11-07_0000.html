B1「code as spec」— 仕様書として機能するコードを書くことでAIとの協働を最適化する新アプローチ

📰 本文 + 和越対訳

Zennに投稿されたエンジニア・ruriさんの記事「code as spec」が技術コミュニティで注目を集めている。この記事では、AIコーディングエージェント（Claude Code、Cursorなど）との協働において、コード自体を仕様書として機能させるアプローチが提唱されている。従来、開発プロセスでは別途仕様書や設計書を用意し、それを元にコードを書くという流れが一般的だった。しかし「code as spec」の考え方では、コード内に意図・制約・期待される振る舞いを表現し豊かに記述することで、AIが実装の文脈を正確に理解できるようにする。具体的には、型定義を仕様として活用したり、テストコードを期待動作の仕様として書くほか、コメントではなくコード構造そのもので「何をすべきか」を表現するパターンが紹介されている。この手法はSpec-Driven Developmentの実践的な形として、AIペアプログラミングの品質向上に直接つながると筆者は述べている。

Bài viết "code as spec" của kỹ sư ruri trên Zenn đang thu hút sự chú ý trong cộng đồng kỹ thuật. Bài viết đề xuất một phương pháp cộng tác với các AI coding agent (Claude Code, Cursor...) bằng cách biến chính đoạn code thành bản đặc tả. Trong phát triển phần mềm truyền thống, người ta thường viết tài liệu đặc tả riêng trước rồi mới code. Nhưng với "code as spec", ý định, ràng buộc và hành vi kỳ vọng được diễn đạt ngay trong cấu trúc code để AI có thể hiểu đúng ngữ cảnh implementation. Cụ thể, bài viết giới thiệu các pattern như dùng type definition làm spec, viết test code như một đặc tả hành vi kỳ vọng, và thể hiện "cần làm gì" qua cấu trúc code thay vì comment. Tác giả khẳng định đây là dạng thực hành của Spec-Driven Development giúp nâng cao chất lượng khi pair programming với AI.
