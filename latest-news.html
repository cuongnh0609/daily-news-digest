C-03Critical RCE Vulnerability in Apache HTTP Server — CVE-2026-119618 Affects All 2.4.x Through 2.4.63

📰 Article (English)

Wiz Research has disclosed CVE-2026-119618, a critical remote code execution vulnerability in Apache HTTP Server affecting versions 2.4.55 through 2.4.70. The flaw is a race condition in the assign_headers() function of the mod_http2 module, allowing an unauthenticated remote attacker to corrupt heap memory and achieve arbitrary code execution. The vulnerability was independently discovered by Anthropic's security team and Google Cloud's Vulnerability Research Team before coordinated disclosure. An attacker sending a crafted HTTP/2 request can trigger the race condition without any authentication, making this exploitable by any internet-facing Apache server with HTTP/2 enabled. Wiz data shows 64% of cloud environments contain vulnerable Apache instances, with 51% publicly exposed. The Apache Software Foundation patched the vulnerability in version 2.4.71, released November 11, 2026. As an interim mitigation, disabling HTTP/2 by setting Protocols http/1.1 in the Apache config eliminates the attack surface. No exploit code is publicly available and no active exploitation has been confirmed as of this disclosure, but the attack surface is wide given HTTP/2's prevalence.
