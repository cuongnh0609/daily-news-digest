B1Claude Code v2.1.287で「Claude Mods」登場――プラグインがセッション常駐型に進化し、UI・動作の深いカスタマイズが可能に

📰 本文 + 和越対訳

Anthropicが2026年10月1日にリリースしたClaude Code v2.1.287から「Claude Mods」機能が導入され、プラグインアーキテクチャが大幅に刷新された。従来のフックはシェルコマンドを都度起動する方式だったのに対し、Modsはセッション全体を通じてJavaScript/TypeScriptモジュールがプロセス内に常駐する。これにより、コンテキストウィンドウの使用量を天気アイコンで可視化する「Token Weather」、危険なBashコマンドを実行前に確認ダイアログで止める「Blast Radius」、前のターンでのコード編集を視覚的にリプレイする「Replay Theater」などのMod実装例が公開されている。ModはユーザーのOS権限と同等で動作するため、npmパッケージと同様のセキュリティ評価が必要だとされる。Team・Enterpriseプランでは組み込みのsec-default Modが不正な権限昇格をブロックする。

Claude Code v2.1.287 ra mắt tính năng "Claude Mods" — một cuộc cách mạng trong kiến trúc plugin. Thay vì gọi shell command rời rạc theo từng sự kiện như trước, Mods sử dụng module JavaScript/TypeScript thường trực trong tiến trình suốt toàn bộ session. Điều này cho phép các ví dụ thú vị như "Token Weather" hiển thị mức dùng context window qua icon thời tiết, "Blast Radius" ngăn các lệnh Bash nguy hiểm bằng hộp thoại xác nhận, và "Replay Theater" phát lại trực quan quá trình chỉnh sửa code. Mods chạy với quyền của người dùng nên cần được đánh giá bảo mật như package npm. Môi trường Team/Enterprise có Mod `sec-default` tích hợp để chặn leo thang quyền trái phép.

📰 本文 + 和越対訳

VoidZeroは2026年9月28日、JavaScriptエコシステムの開発ツールを単一のコマンドラインインターフェイスに統合した「Vite+ 1.0」を正式リリースした。従来、開発者はランタイム管理・パッケージマネージャー・バンドラー・リンター・フォーマッター・テストランナーをそれぞれ異なるツールで管理する必要があった。Vite+はこれらすべてをvpコマンドで操作できるようにし、設定ファイルも一本化した。内部にはRustベースのバンドラーであるRolldownを含む最新のVite、Vitest、Oxc、tsdownが組み込まれており、ビルド速度の大幅な向上が見込まれる。2026年6月にCloudflareに買収されたVoidZeroのもとで開発が継続されており、MITライセンスのオープンソースとして公開されている。
