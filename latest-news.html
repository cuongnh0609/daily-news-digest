B-01WSL ContainersでClaude Codeを隔離する——権限リスクを最小化するローカル開発環境

📰 本文 + 和越対訳

Claude CodeはbypassPermissionsモードで実行する場合、ホストOS上のファイルシステムやプロセスに広範なアクセス権を持つ。これはエージェントの生産性を高める一方で、誤った操作や意図しないファイル削除のリスクも高まる。本記事では、Windows Subsystem for LinuxのContainer機能（WSL Containers）を使ってClaude Codeを隔離コンテナ内で動作させる構成を紹介する。ホストのファイルシステムはマウント設定で明示的に許可した範囲のみ参照でき、コンテナ内で発生した破壊的操作がホストに波及しない設計となっている。VolumeMountを使ったプロジェクトディレクトリの限定共有や、コンテナ破棄後も状態を保持するためのnamed volumeの活用方法なども解説されており、開発者にとって実践的な安全対策として注目されている。

Khi chạy Claude Code ở chế độ bypassPermissions, agent có quyền truy cập rộng vào hệ thống file và process trên host OS. Điều này tăng năng suất của agent nhưng cũng làm tăng nguy cơ thao tác sai hoặc xóa file không mong muốn. Bài viết này giới thiệu cách cấu hình để chạy Claude Code trong container cô lập sử dụng tính năng Container của Windows Subsystem for Linux (WSL Containers). Hệ thống file của host chỉ có thể được tham chiếu trong phạm vi cho phép tường minh qua cài đặt mount, và các thao tác phá hoại xảy ra trong container không ảnh hưởng đến host. Bài viết cũng hướng dẫn cách chia sẻ có giới hạn thư mục dự án bằng VolumeMount và cách sử dụng named volume để giữ lại trạng thái sau khi container bị xóa, được đánh giá là biện pháp bảo mật thực tế cho developer.

C-02OpenAI and Cisco Open-Source "Shirudo" — Live Linux Protection via eBPF Without Reboots

📰 Article (English)

OpenAI and Cisco have released Shirudo, an open-source runtime security tool that lets teams protect running Linux systems while patches are being prepared — without requiring a system restart. The core mechanism is eBPF programs ("shields") that can be hot-loaded into a running kernel. Each shield intercepts a specific system call path and blocks or modifies the vulnerable behavior. In a controlled test, a Codex-generated shield blocked a Java4Shell exploit against a live Elasticsearch service by adding an input validation hook inside Java's Base64 decoder — with zero downtime. Shields support a monitor-before-enforce workflow, letting operators observe the shield's side effects before committing. Cryptographic signing ensures that only verified shields can be loaded, and a TPM-backed log tracks all load and removal events for audit. Longer-term, the project roadmap includes workload permission limiting and safer kernel update mechanisms. Shirudo is dual-licensed under BSD 2-Clause and GPL. Source code is at github.com/shirudo-dev/shirudo, and a VM quickstart is available for immediate testing.
