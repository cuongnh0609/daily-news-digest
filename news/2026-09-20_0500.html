C3PlanetScale Introduces TIN: 25× Faster Full-Text Search for Postgres Using ctid-Based Indexing

📰 Article + Impact

PlanetScale has released TIN (Text INdex), a new full-text search extension for PostgreSQL that dramatically outperforms existing alternatives. The key architectural innovation is using Postgres' native ctid (current tuple identifier) as document identifiers rather than sequential numbering — this 48-bit value directly locates tuples in the Postgres heap, eliminating the expensive identifier-to-ctid mapping step that other engines must perform. TIN supports boolean expressions, phrase queries, span queries, fuzzy matching, wildcard and regex matching, case and accent folding, COUNT(*), and BM25-scored top-k results. Benchmarks show 25× more queries per second than ParadeDB with 26× lower p99 latencies on ranked queries, and 10× more throughput on conjunction/phrase queries. The implementation also uses vectorized CPU instructions and a two-level bitmap encoding (page-level + offset-level) for set operations. TIN is now generally available for all Postgres and Neki (PlanetScale's new sharded Postgres service) databases. For developers using Postgres who have been considering adding a dedicated search service like Elasticsearch or OpenSearch, TIN may eliminate that need entirely.

Nếu stack của bạn dùng Postgres và đang xem xét thêm Elasticsearch cho search, hãy đánh giá TIN trước — 25× faster với zero infrastructure overhead có thể là đủ cho phần lớn use case.

📖 Thuật ngữ

Thuật ngữ (EN)Phát âmGiải thích tiếng Việt
ctid (tuple identifier) /ˈsiː tɪd/ Định danh vật lý trong Postgres — cặp (page_number, tuple_offset) xác định chính xác vị trí của một hàng trong file heap trên đĩa
BM25 /biːɛmˈtwentifaɪv/ Best Match 25 — thuật toán xếp hạng tìm kiếm toàn văn bản tiêu chuẩn (dùng trong Elasticsearch, Lucene...) tính điểm liên quan dựa trên tần suất từ và độ dài tài liệu
Vectorized CPU instructions /ˈvektəraɪzd/ Lệnh SIMD (Single Instruction Multiple Data) — xử lý nhiều phần tử dữ liệu song song trong một lệnh CPU, tăng tốc đáng kể các phép toán tập hợp
Full-text search extension /ɪkˈstenʃən/ Plugin mở rộng tìm kiếm toàn văn cho database — cho phép tìm kiếm theo từ khóa trong nội dung văn bản, không chỉ match chính xác
