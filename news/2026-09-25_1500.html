B1Claude CodeのMEMORY.mdを定期的に大掃除する——肥大化するAIメモリを2スキルで整理する実践術

📰 本文 + 和越対訳

Claude Codeはプロジェクトリポジトリにメモリを自動蓄積し、MEMORY.mdというインデックスファイルを通じてコンテキストを参照する。しかしこのファイルには「最初の200行・25KB」という厳格な読み込み制限があり、放置すると重要な情報がアクセス不能になる。Loglass社のエンジニアが実践した解決策は、2つのスキルを組み合わせた定期的な大掃除だ。まず/memory-compactionスキルでトピックごとにメモリを統合し、1ファイルあたり3〜7KBを目安に重複を排除する。次に/rule-creatorスキルで頻繁に参照される重要パターンを.claude/rulesファイルに昇格させ、セッションを超えて機能させる。Claude Fable 5.1ではルールファイルはキャッシュにより約40倍安価なトークンで処理されるため、ルール化のコスト効率は高い。スキルベースの自動化より、重要なルールを常時ファイルとして管理する方式が実務では有効だという。

Claude Code tự động tích lũy memory vào repository dưới dạng file chỉ mục MEMORY.md, nhưng file này có giới hạn nghiêm ngặt: chỉ đọc được "200 dòng đầu hoặc 25KB" mỗi phiên làm việc. Kỹ sư tại công ty Loglass chia sẻ giải pháp: kết hợp hai skill để dọn dẹp định kỳ. Đầu tiên, dùng /memory-compaction để tổng hợp memory theo từng chủ đề, mỗi file mục tiêu 3-7KB, loại bỏ trùng lặp. Sau đó dùng /rule-creator để đưa các pattern quan trọng thường xuyên tham chiếu lên file .claude/rules, đảm bảo chúng hoạt động xuyên session. Trên Claude Fable 5.1, file rule được xử lý với chi phí token rẻ hơn khoảng 40 lần nhờ caching. Tác giả kết luận rằng quản lý rule dạng file thường trực hiệu quả hơn tự động hóa thuần bằng skill.
