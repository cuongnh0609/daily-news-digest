C3You Could Have Invented Transformers from Memory — Alex Wang's Capacity-First Derivation

📰 Article (English)

Alex Wang published an essay arguing that every layer type in a transformer can be understood as an associative memory store — a structure that holds key-value pairs and retrieves values by comparing a query against stored keys. The insight is not just pedagogical; it provides a principled way to derive the architecture from first principles, by asking how many memories each store can hold before interference overwhelms recall. A basic linear store has capacity roughly equal to d_k (the key dimension). Fitting weights with least squares roughly doubles that. Adding a nonlinearity such as ReLU turns it into an MLP. Applying a softmax to the similarity scores — what attention does — produces exponential weighting that suppresses weak matches far more aggressively, pushing theoretical capacity to around 1.2 million memories for standard d_k=64 heads. Crucially, MLP memories are trained weights (fixed), while attention memories are the tokens currently in context (dynamic), meaning the memory store grows with each new token in the sequence. Wang's central claim: if you understood associative memory and wanted maximum retrieval capacity, you would have invented softmax attention. The piece hit Hacker News front page with a score of 314, indicating strong engagement from the ML practitioner community.
