Harness này được thiết kế xoay quanh một Git repository duy nhất, kết hợp file chính sách master (AGENTS.master.md), bảng quản lý task, bộ skill và module hook để các coding agent xử lý xuyên suốt từ phát triển, nghiên cứu, viết tài liệu đến triage chat.
