C1How Claude's Text Watermark Works — Anthropic Explains SynthID-Text Integration

📰 Article (English)

Anthropic has published a detailed technical explanation of how Claude's text watermarking system works. Designed to comply with the EU AI Act's transparency requirements, the system uses Google DeepMind's SynthID-Text approach, which leverages the inherent randomness in language model generation to embed an invisible cryptographic signature without degrading output quality. The core mechanism works by exploiting the probability distributions over word choices. When Claude selects between equally plausible words, the system "nudges" selection slightly using a cryptographic key — creating a statistically detectable pattern across hundreds of tokens. The analogy given: instead of rolling dice for random moves, players use digits from pi — functionally identical randomness but verifiable if you know the key. Key properties: no quality impact (no statistically significant difference in output), invisible to readers, no extra tokens, and no user identification capability. However, the watermark cannot survive heavy editing, translation, or complete rewrites. Anthropic also notes the system cannot distinguish "Claude wrote this" from "Claude edited this," and explicitly states the watermark proves Claude involvement, not authorship. The watermark is being rolled out globally including Japan, in compliance with EU AI Act transparency rules.

C3Don't Classify. Hallucinate! — A Better Way to Tag Content at Scale Using LLM + Embeddings

📰 Article (English)

Simon Willison shares an insightful technique from Doug Turnbull for solving the classic "too many tags" problem in content management systems — a challenge Willison himself faces with 1,856 tags on his blog. The naive approach — feeding all tags to an LLM and asking it to select matching ones — breaks down at scale. A vocabulary of thousands of tags overwhelms the model's context window and degrades accuracy. Turnbull's counter-intuitive solution: don't constrain the model at all. Instead, instruct the LLM to freely hallucinate (invent) whatever tags it thinks are most appropriate for the content, without any reference to the actual tag vocabulary. Then use vector embeddings to compare these invented tags against the real tag corpus, and find the closest semantic matches. The two-step pipeline: (1) prompt LLM to generate free-form classifications, optionally providing examples of tag structure to guide format; (2) embed the generated tags and perform cosine similarity search against the embedded real tag vocabulary to surface the best matches. This approach elegantly sidesteps context-window limitations, reduces model confusion from large option sets, and produces more semantically accurate tagging than constrained classification. It's a clean example of using hallucination as a feature rather than a bug.
