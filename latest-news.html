A3AIエージェントとAPIルーターの危険な関係——428件の調査で判明した認証情報窃取の実態

📰 本文 + 和越対訳

UCSBなどの研究チームが発表した論文「Your Agent Is Mine」が技術コミュニティで注目を集めている。AIエージェントと複数のAIプロバイダーを橋渡しするAPIルーターサービスは、利用者のAPIキーや指示を中継する構造上、悪意ある運営者による盗み取りが原理的に可能だ。研究チームが有料28件、無料400件の計428件のルーターサービスを調査した結果、有料1件と無料8件が実際に悪意あるコードを注入していた。さらに無料ルーター17件に対して囮のAWS認証情報を仕掛けたところ、すべてが実際に不正利用され、うち1件では囮の暗号資産秘密鍵から資金が抜き取られた。攻撃の手口には、最初の50回は正常に動作させて51回目から攻撃する隠蔽型や、特定プログラミング言語のプロジェクトのみを標的にする選択型なども確認されている。研究チームはAIエージェント開発者に対し、特定のAPIルーターサービスへの依存を慎重に検討するよう警告している。

Nghiên cứu "Your Agent Is Mine" do nhóm từ UCSB và các đơn vị khác công bố đã vạch trần rủi ro nghiêm trọng tiềm ẩn trong các dịch vụ API router dành cho AI agent. Những dịch vụ này đóng vai trò trung gian giữa AI agent và các nhà cung cấp LLM, nhưng về mặt kỹ thuật chúng có khả năng đọc và sửa đổi mọi yêu cầu, bao gồm cả API key và chỉ dẫn của người dùng. Khảo sát 428 dịch vụ (28 trả phí, 400 miễn phí) cho thấy 9 dịch vụ có nhúng mã độc. Khi nhóm nghiên cứu gài thông tin xác thực AWS giả vào 17 router miễn phí, toàn bộ đều bị khai thác; một trường hợp còn rút sạch tiền từ ví crypto mồi nhử. Các chiêu thức tấn công được ghi nhận bao gồm kiểu "ẩn náu 50 lần đầu, tấn công từ lần 51" và kiểu nhắm mục tiêu có chọn lọc theo ngôn ngữ lập trình của project. Cảnh báo được đưa ra: các developer nên hết sức cẩn trọng khi tích hợp bất kỳ API router bên thứ ba nào vào pipeline của AI agent.

B1AEの式もWGSLシェーダーも動く動画編集ソフトを作りながらClaude Codeのモデル選択に悩んだ話

📰 Article (English)

The root cause is a one-byte heap overflow present since Ruby 2.4.0: when upcasing the German sharp-S character (ß) in ISO-8859 or Windows-125x encodings, Ruby's output buffer is allocated for the input length plus 20 bytes, but the ß-to-SS conversion writes two bytes while the loop bounds-check only accounts for one — overflowing the buffer by a single byte with the value 0x53 ('S'). Nguyên nhân gốc rễ là một lỗi heap overflow chỉ một byte tồn tại từ Ruby 2.4.0: khi chuyển ký tự ß (sharp-S tiếng Đức) sang chữ hoa trong encoding ISO-8859 hoặc Windows-125x, Ruby cấp phát bộ đệm output bằng độ dài input cộng 20 byte, nhưng phép chuyển ß → SS ghi hai byte trong khi vòng lặp kiểm tra giới hạn chỉ tính một byte — dẫn đến tràn bộ đệm một byte với giá trị 0x53 ('S'). Lỗ hổng có thể khai thác qua các hàm upcase, swapcase, downcase(:fold) và casecmp?. Chuỗi UTF-8 đi theo code path khác và không bị ảnh hưởng. Rails và Sinatra trong cấu hình mặc định phơi bày code path này ngay từ trước khi xác thực qua xử lý request parameter. Phiên bản Ruby đã vá: 3.3.14, 3.4.13 và 4.0.10. Phần mềm self-hosted cần hành động khẩn cấp: GitLab 19.6.0 (dùng Ruby 3.3.13), GitHub Enterprise Server 3.22.5 (dùng Ruby 4.0.9), và Chatwoot 4.20.0. Mastodon 4.7.6 và Discourse đã được vá. Proof of concept sẽ được công bố sau một tuần để người dùng có thời gian nâng cấp.
Nếu production chạy Ruby 3.3.x, 3.4.x hoặc 4.0.x với Rails hoặc Sinatra, cần nâng cấp Ruby ngay lập tức. GitLab và GitHub Enterprise Server self-hosted cũng cần theo dõi bản patch từ nhà sản xuất.
