B1Ubieが社内AIエージェント基盤「Remoco / Uvin」を公開——sandbox-as-a-toolアーキテクチャと自己改善ループの実践

📰 本文 + 和越対訳

医療テック企業Ubieのエンジニアリング責任者・小谷裕樹氏が、2023年から構築してきた社内クラウドエージェント基盤の全容をZennで公開した。基盤の名称は「Remoco」、その上で動くエンジニアリングエージェントは「Uvin」と呼ばれる。RemococはWeb、Slack、cron、Webhook、MCP経由でエージェントを起動できるマルチインターフェース設計で、Temporalワークフローを中心に構成されている。アーキテクチャの特徴は「sandbox-as-a-tool」と呼ぶ設計だ。エージェント本体はサンドボックス外に置かれ、ツール実行時のみサンドボックスを呼び出す仕組みにより、クレデンシャルの漏洩リスクを最小化している。サンドボックスはGKE上のmicroVMとして動作し、全アウトバウンド通信はプロキシ経由に制限される。UvinはCursorのpstackを参考に「playbook（作業手順）」と「principle（判断原則）」に基づくエージェントスキル設計を採用しており、毎日のセルフ改善ループがセッションを分析してPRを自動で開く。法律一次対応エージェントやキャリアコーチングエージェントにも応用されている。

Kỹ sư trưởng Yuku Kotani của công ty y tế công nghệ Ubie đã công bố trên Zenn toàn bộ kiến trúc nền tảng agent AI nội bộ mà họ đã xây dựng từ năm 2023. Nền tảng có tên "Remoco" và agent kỹ thuật chạy trên đó được gọi là "Uvin". Remoco hỗ trợ nhiều điểm khởi động (Web, Slack, cron, Webhook, MCP) và được xây dựng xoay quanh Temporal workflows. Điểm đặc sắc kiến trúc là thiết kế "sandbox-as-a-tool": thân agent nằm ngoài sandbox, chỉ gọi vào sandbox khi thực thi tool, giúp tối thiểu hóa rủi ro rò rỉ credentials. Sandbox chạy dưới dạng microVM trên GKE, tất cả lưu lượng ra ngoài đều qua proxy. Uvin áp dụng thiết kế Agent Skills dựa trên "playbook (quy trình làm việc)" và "principle (nguyên tắc phán đoán)" học theo pstack của Cursor. Một vòng lặp tự cải thiện hàng ngày phân tích các phiên làm việc và tự động mở PR. Hệ thống còn được ứng dụng vào agent hỗ trợ pháp lý và agent coaching sự nghiệp.

Cloudflareは、AIエージェント向けに特化した軽量ヘッドレスブラウザ「Kitesurf」をApache 2.0ライセンスでオープンソース公開した。タブ、テーマ、拡張機能などの通常ブラウザ機能を一切排除したKitesurfは、CPUおよびメモリ使用量がChromiumと比べて3〜7倍少ないと同社は説明している。Kitesurfは主にRustで書かれ、WebAssemblyにコンパイルされて、Cloudflare Workers上で動作するよう設計されている。ローカル実行はWranglerを通じて行える。内部的にはHTMLパース・DOM・レイアウト・描画を担う「Blitz」、CSSエンジン「Stylo」、WebAssembly上で動くJavaScriptエンジン「Boa」、テキストレイアウトと2Dグラフィックスの「Linebender」、PDF生成の「Krilla」という複数コンポーネントで構成されている。Chrome DevToolsプロトコル（CDP）をサポートするため、Puppeteerスタイルのクライアントからも接続可能だ。AIエージェントがWebをブラウズする際のコスト削減と安全な実行環境の提供を目的としている。

Cloudflare đã phát hành mã nguồn mở trình duyệt headless nhẹ "Kitesurf" theo giấy phép Apache 2.0, được thiết kế chuyên biệt cho các AI agent. Loại bỏ hoàn toàn các tính năng trình duyệt thông thường như tab, theme và extension, Kitesurf tiêu thụ CPU và bộ nhớ ít hơn 3 đến 7 lần so với Chromium. Viết chủ yếu bằng Rust và biên dịch sang WebAssembly, Kitesurf được thiết kế để chạy trên Cloudflare Workers, với khả năng chạy local thông qua Wrangler. Kiến trúc nội bộ bao gồm Blitz (phân tích HTML/DOM/layout), Stylo (CSS engine), Boa (JavaScript engine trên WebAssembly), Linebender (text layout, 2D graphics), và Krilla (tạo PDF). Hỗ trợ Chrome DevTools Protocol nên các client kiểu Puppeteer cũng có thể kết nối. Mục tiêu là giảm chi phí và cung cấp môi trường thực thi an toàn khi AI agent duyệt web.

C2AWS Launches Nitro Sandboxes — Hardware-Isolated MicroVMs for AI Agent Code Execution at Native EC2 Speed

📰 Article (English)

AWS has launched Nitro Sandboxes, a new compute primitive that gives AI agents hardware-level isolation without sacrificing the performance of native EC2 instances. Unlike containers, which share a host kernel, each Nitro Sandbox gets its own guest OS and system calls cannot escape beyond it, making them suitable for running untrusted AI-generated code. The Nitro Sandbox leverages the same Nitro System hardware security chips that power EC2 instance isolation. Deployment is flexible: sandboxes can run as EC2 instances, ECS pods, or EKS pods. In EKS Auto Mode, enabling Nitro Sandboxes converts a standard Kubernetes Pod into a lightweight VM with no changes required to container images, Helm charts, or deployment pipelines. This "drop-in" compatibility is a key differentiator from alternatives like gVisor or Kata Containers that often require runtime modifications. The launch addresses a growing need as more teams deploy LLM-based agents that execute dynamically generated code — a scenario where kernel-sharing containers expose significant attack surface to prompt injection or jailbreak-triggered exploits.
