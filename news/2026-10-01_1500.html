C-035x Faster Edge Functions: Cloudflare Moves from V8 Isolates to Firecracker MicroVMs for AI Workloads

📰 Article (English)

Cloudflare announced a major architectural shift for Edge Functions: heavy AI workloads on their platform will now run on Firecracker microVMs rather than the V8 JavaScript isolates that have powered Workers since 2017. The change delivers approximately 5x faster throughput for compute-intensive operations such as running AI inference, image processing, and large payload transformations. V8 isolates remain the default for lightweight request/response Workers and provide near-zero cold start, but they impose a hard constraint on memory (128MB) and CPU time that proves limiting for GPU-offload inference tasks. Firecracker microVMs, developed originally by AWS for Lambda and Fargate, provide stronger isolation boundaries, dedicated memory allocation, and can run arbitrary binaries — enabling Cloudflare to support Python and Rust natively alongside JavaScript. The migration is transparent for existing Workers code; Cloudflare's runtime automatically selects the optimal execution environment based on resource requirements. This shift is significant for the edge AI inference use case — latency-sensitive applications can now run sub-second model inference at network edge without routing traffic back to a central data center, reducing P99 latency by up to 300ms for global user bases.
