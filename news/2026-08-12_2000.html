📰 本文 + 和越対訳

Model Context Protocol（MCP）サーバーの認可実装は複雑になりがちだが、Cloudflare AccessのManaged OAuthを使うことでその負担を大幅に削減できると、Zennのエンジニアが実装例とともに解説した。Managed OAuthはメタデータ公開・動的クライアント登録（DCR）・認可コード+PKCEフロー・トークン発行と更新という認可フローの全工程をCloudflareが肩代わりするため、MCPサーバー側は届いたJWTを検証するだけで済む。二重検証の仕組みとして、Cloudflareレベルでopaqueトークンを検証しユーザー特定・ポリシー評価を行い、MCPサーバーレベルでは署名・issuer・audience・有効期限を確認する。AzureEntra IDとの比較では、自己実装が必要なコード量を大幅に削減できることも示された。Web経由とMCP経由双方で同じJWT形式を受け取れる設計は、認証統合の観点でも利点が大きいとされている。

Một kỹ sư trên Zenn đã giải thích với ví dụ thực tế rằng việc sử dụng Cloudflare Access Managed OAuth có thể giảm đáng kể gánh nặng triển khai authorization cho MCP server. Managed OAuth đảm nhận toàn bộ quy trình authorization bao gồm công bố metadata, đăng ký client động (DCR), luồng authorization code + PKCE, phát hành và làm mới token, vì vậy MCP server chỉ cần xác thực JWT nhận được. Kiến trúc xác thực hai lớp gồm: Cloudflare xác thực opaque token và đánh giá policy, còn MCP server xác minh chữ ký, issuer, audience và thời hạn hiệu lực. So với Azure Entra ID, lượng code tự triển khai được giảm đáng kể. Thiết kế nhận cùng định dạng JWT qua cả web và MCP mang lại lợi thế lớn về tích hợp xác thực.
