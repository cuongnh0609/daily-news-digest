B1Claude Codeの危険コマンド遮断hookが特定条件で素通りしていた——Zennで発覚したセキュリティ設計の盲点

📰 本文 + 和越対訳

Zennに投稿された技術記事が話題となっている。著者のminewo氏は、Claude Codeのhook機能を使ってrm -rfなどの危険なコマンドを遮断するスクリプトを実装していたが、特定の条件下ではそのhookが機能しない「フェールオープン」の挙動をしていたことを発見したと報告した。具体的には、hookスクリプト自体がエラーで終了した場合、Claude Codeはコマンドの実行を「許可」する側に倒れる仕様となっており、これを「fail-open」と呼ぶ。セキュリティの世界では「fail-safe（失敗時は安全側に倒れる）」が原則だが、Claude Codeの設計はその逆だったという。記事は実際のhookコードと再現手順を示しながら、根本的な対策としてhookスクリプトにset -eフラグを設定し、加えてClaude Codeの設定ファイルでhookStrictMode: trueを有効化することを推奨している。開発者コミュニティからはClaude Code公式ドキュメントへの反映を求める声も上がっている。

Một bài viết kỹ thuật trên Zenn đang thu hút chú ý. Tác giả minewo báo cáo đã phát hiện hành vi "fail-open" trong đó hook script dùng để chặn các lệnh nguy hiểm như rm -rf trong Claude Code không hoạt động trong điều kiện nhất định. Cụ thể, khi bản thân hook script thoát ra với lỗi, Claude Code sẽ "cho phép" thực thi lệnh thay vì từ chối - đây gọi là "fail-open". Trong lĩnh vực bảo mật, nguyên tắc là "fail-safe" (khi thất bại thì nghiêng về phía an toàn), nhưng thiết kế của Claude Code lại ngược lại. Bài viết giải thích cùng code hook thực tế và các bước tái hiện, khuyến nghị đặt flag set -e trong hook script và bật hookStrictMode: true trong file cấu hình Claude Code như biện pháp căn bản. Cộng đồng developer cũng đang kêu gọi phản ánh vấn đề này vào tài liệu chính thức của Claude Code.

C1Energy-Based Reasoners: 385x More Efficient Inference Without Sacrificing Accuracy

📰 Article (English)

Researchers have published a novel approach to LLM inference called Energy-Based Reasoners (EBRs) that achieves up to 385x greater computational efficiency compared to standard autoregressive transformer inference on reasoning tasks. Rather than generating token sequences autoregressively, EBRs treat reasoning as an energy minimization problem: the model learns an energy function over possible answers, and inference becomes finding the low-energy configuration that best satisfies the problem constraints. During training, the model learns to assign low energy to correct solutions and high energy to incorrect ones, then at inference time a lightweight gradient descent or MCMC-based search finds the solution. The key advantage is that EBRs separate the "thinking" (energy landscape learning) from the "searching" (inference-time optimization), allowing the search procedure to scale compute at inference time without rerunning the full model. Benchmarks show equivalent performance to chain-of-thought prompting on math and coding tasks while using a fraction of the tokens. The researchers released weights, code, and training details on GitHub. This is a preprint and has not yet undergone peer review.
