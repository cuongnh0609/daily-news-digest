A-01台風25号、21日（月）午後に雨風がピーク——東海・関東・伊豆諸島に線状降水帯の恐れ

📰 本文 + 和越対訳

B-01jev-lint 公開——コードの命名・コメントが「嘘」かどうかを Jev でバッチ検証するツール

📰 本文 + 和越対訳

mizchi 氏が、コード内の命名やコメントが実装と乖離していないかを高速で検証するツール「jev-lint」を公開した。従来の静的 lint では対応できない意味レベルの検査に対応しており、関数名と実装の一致性、テストケース名と内容の整合性、コメントの正確性などを自動チェックする。内部では ast-grep でコード断片を抽出し、Jev の Choice/Score 型判定をバッチ処理で一括評価することで、LLM を呼び出すよりも大幅に低コストを実現している。著者の計測では約 9,800 行のコードを約 8 円で検査でき、precommit hook や PR レビューのアドバイザリーとして実用的に運用できるという。開発者が「コードと説明が食い違ったまま放置される技術的負債」を Jev という新しいアーキテクチャで解消する試みとして注目されている。

Tác giả mizchi đã phát hành "jev-lint" — một tool kiểm tra xem tên hàm, comment hay tên test trong code có "nói dối" so với implementation không. Khác với static lint truyền thống, jev-lint kiểm tra ở cấp độ ngữ nghĩa: sự nhất quán giữa tên hàm và logic bên trong, tính chính xác của comment, v.v. Về mặt kỹ thuật, tool dùng `ast-grep` để trích xuất các đoạn code rồi đưa vào Jev xử lý batch — rẻ hơn nhiều so với gọi LLM thông thường, khoảng 8 yên cho ~9.800 dòng code. Có thể tích hợp vào precommit hook hoặc dùng như advisory trong PR review, giúp giảm technical debt dạng "code và mô tả bất đồng bộ".

B-02Claude Code と MCP でデータ分析基盤を 1 人月で構築——PKSHA が BigQuery + dbt + Lightdash の「Laplace」を公開

📰 本文 + 和越対訳

PKSHA Technology の SRE・三浦氏が、VoiceAgent 向けに新たなデータ分析基盤「Laplace」を構築した事例を Zenn で公開した。Aurora へのアドホッククエリに頼る従来構成から脱却し、BigQuery（DWH）・dbt（データ変換・577モデル）・Lightdash（セマンティックレイヤー、OSS版）・MCP サーバ・GKE Autopilot という5層スタックに移行した。最大の特徴は、Claude Code がコードのほぼ全量を生成したことで、1人月という短期間でのリリースを実現した点だ。ビジネスメンバー29名がセルフサービスでダッシュボードを作成・参照でき、月額運用コストは約1,200ドルに抑えられた。PII ガードと監査ログも内包しており、「誰が何をいつ読んだか」の追跡が可能な、セキュアな分析環境を整えている。

Stack gồm 5 tầng: BigQuery (DWH), dbt (577 model chuyển đổi dữ liệu), Lightdash (semantic layer, bản OSS), MCP server và GKE Autopilot. Điểm nổi bật: gần như toàn bộ code được Claude Code tự động sinh ra. 29 thành viên business hiện tự tạo dashboard, chi phí vận hành ~1.200 USD/tháng. C-02Jev: Non-Autoregressive Decision Model by Ex-OpenAI Researcher Hits 37 Billion X Impressions

📰 Article (English)

TypeSafe AI, founded by Diogo Almeida — co-author of InstructGPT and former OpenAI researcher — launched Jev, a fundamentally different class of AI model. Unlike LLMs, Jev does not generate free-form text. Instead it returns only three structured output types: Choice (select one of up to 255 options), Score (a numerical value), and Noul (a yes/no probability). This architectural decision eliminates hallucinations by design — the model has no mechanism to fabricate information. The performance claims are striking: 70–500ms response latency versus seconds or minutes for frontier LLMs, and costs 40–1,000 times lower. Under the hood, Jev uses RLCD (Reinforcement Learning from Calibrated Data) to align confidence scores with actual accuracy, making its uncertainty signals trustworthy for downstream routing logic. The intended use case is replacing LLMs in classification, routing, and scoring pipelines where structured judgment is required but generated text is not. Developers can threshold on confidence to decide whether to escalate a decision to an LLM or a human. The announcement received over 37 billion X impressions, and Japan's developer community has already shipped tools like jev-lint that apply Jev to code quality analysis.
