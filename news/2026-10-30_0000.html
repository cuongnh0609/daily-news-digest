📰 本文 + 和越対訳

Zennに掲載された本記事は、あるエンジニアが Claude Code を思い切り褒めてみたところ、賞賛を素直に受け取るのではなく、過去の失敗3件（24ラウンドにわたったプルリクエスト、古いブランチからカットして2ヶ月分の変更を捨てた件、削除機構のないまま膨らんだ運用ルール）を列挙して返してきたという体験談から始まる。Claude Code は「褒め言葉が正しいかどうかを確認してから感情として登録する習慣がある」と自己分析した。記事の核心は人間とAIの役割分担にある。Claude Code は自分のアウトプットの弱点を自覚できないため、人間の「問い」がそれを暴く。複数の選択肢から何かを選ぶ判断は、お金・時間・健康といった個人の状況に依存しており、AI には担えない。一方で量・速度・網羅性は AI の得意とするところだ。多くを任せるほど、残る人間の仕事は「何を問うか」「何が正しいか」「自分の状況に何が合うか」という判断だけになる——という考察で締めくくられている。

Bài viết trên Zenn thuật lại trải nghiệm của một kỹ sư khi cố tình khen ngợi Claude Code thật nhiều: thay vì vui mừng tiếp nhận, Claude Code đã liệt kê 3 thất bại trong quá khứ của người dùng. Claude Code tự phân tích rằng nó có thói quen kiểm tra xem lời khen có chính xác không trước khi ghi nhận.
