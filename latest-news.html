B-01Claude Code の Hooks 入門：ファイル編集後に自動フォーマットする設定を全公開

📰 本文 + 和越対訳

Claude Code には「Hooks」という仕組みがあり、ツール実行の前後に任意のシェルコマンドを自動で走らせることができる。設定は ~/.claude/settings.json の hooks セクションに記述する。記事では PostToolUse イベントと Edit|Write マッチャーを組み合わせ、Prettier を使ってファイル編集のたびに自動整形する構成を紹介している。スクリプトは標準入力から受け取った JSON の tool_input.file_path を読み取り、js・ts・json・css・md といった対象拡張子のみ整形する。後処理フックであるため、整形に失敗してもClaude の作業を止めないよう、スクリプトは常に終了コード0で終了させる。Python なら ruff や black、Go なら gofmt に差し替えることで、どの言語でも応用できる。なお、サードパーティのリポジトリの settings.json にはフックが仕込まれている可能性があるため、中身を確認してから使うことが推奨されている。

Claude Code có một cơ chế gọi là "Hooks" cho phép tự động chạy các lệnh shell tùy ý trước hoặc sau khi thực hiện tool. Cấu hình được ghi trong phần hooks của ~/.claude/settings.json. Bài viết giới thiệu cách kết hợp sự kiện PostToolUse với matcher Edit|Write để tự động định dạng file bằng Prettier mỗi khi Claude chỉnh sửa. Script đọc JSON từ stdin, lấy tool_input.file_path và chỉ định dạng các phần mở rộng như js, ts, json, css, md. Vì là bước xử lý sau, script luôn kết thúc với mã thoát 0 để lỗi định dạng không làm dừng công việc của Claude. Có thể thay bằng ruff/black cho Python hay gofmt cho Go. Cần lưu ý rằng file settings.json từ repo bên thứ ba có thể chứa hook độc hại, nên phải kiểm tra trước khi dùng.
