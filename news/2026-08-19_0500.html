B1GoogleがAIコンパイラ「HEIR」を発表——完全準同型暗号でデータを復号せずAI推論が可能に

📰 本文 + 和越対訳

Googleは8月18日、完全準同型暗号（FHE: Fully Homomorphic Encryption）を活用したAIモデル向けコンパイラ「HEIR（Homomorphic Encryption Intermediate Representation）」を発表した。HEIRは、Pythonで書かれた学習済みAIモデルのコードを変換し、暗号化されたデータを復号することなくそのままAI推論処理に使えるよう変換するツールだ。開発者は秘匿データを扱うPythonアノテーションを記述するだけで、HEIRが自動的にFHE対応コードへと変換する仕組みになっている。すでにレコメンデーション、詐欺検出、侵入検知、ホットワード検出などの用途で動作が検証されており、クラウドプロバイダーが顧客のプライベートデータを保護しながらAIサービスを提供できる未来が近づいている。特にヘルスケア・金融・法務など規制が厳しい業界での応用が期待される技術だ。

Google ngày 18/8 công bố "HEIR (Homomorphic Encryption Intermediate Representation)", một compiler dành cho mô hình AI tận dụng mã hóa đồng hình hoàn toàn (FHE: Fully Homomorphic Encryption). HEIR là công cụ chuyển đổi code của mô hình AI đã được huấn luyện viết bằng Python, cho phép xử lý suy luận AI trên dữ liệu đã mã hóa mà không cần giải mã. Developer chỉ cần viết annotation Python chỉ định dữ liệu bí mật, HEIR sẽ tự động chuyển đổi sang code tương thích FHE. C1How Claude's Invisible Text Watermark Works — Anthropic Explains the SynthID-Text Implementation

📰 Article (English)

Anthropic has published a detailed technical explanation of the text watermarking system now embedded in Claude's output. The system uses SynthID-Text, a technique originally developed by Google DeepMind, which operates by altering the randomness source used to select words during text generation. Rather than choosing words entirely at random, the system employs a cryptographic key combined with the preceding context to subtly influence which word is chosen when multiple semantically equivalent options exist — for example, selecting "overcast" over "grey" in a weather description. The watermark is imperceptible to human readers and does not introduce additional tokens, meaning there is no cost or latency impact. Critically, the watermark contains no identifying information: it cannot be traced back to a specific user, organization, or session. Anthropic confirmed this applies globally as of August 2026, aligning with EU AI Act requirements for marking AI-generated content. Significant limitations exist: watermarks degrade on factual text with constrained vocabulary, on code, and on text that has been substantially edited by a human. A detection API is planned but not yet available. The system represents one of the first production deployments of robust, invisible AI content marking at scale.
