Amazon Bedrock AgentCoreのGateway機能は、Lambda関数やREST APIをMCP互換エンドポイントとして外部に公開するサービスだ。そのGatewayが提供するWeb Search機能はAmazonのウェブインデックスをMCPツールとして呼び出すマネージドコネクタであり、Claude DesktopなどのMCPクライアントから直接検索を実行できる。しかしGatewayの認証方式としてAPIキーが使えないため、この記事ではJWTを使ったOAuth認証での接続方法を詳解している。具体的にはGatewayのQuick Createウィザードが自動でAmazon Cognitoのユーザープールを作成し、ループバックURIを持つパブリックアプリクライアントを追加することでPKCE付きOAuth認証を実現する。利用者はClaude Desktop上でブラウザを通じてCognitoアカウントでサインインするだけでよく、AWS CLIの認証情報設定が不要という大きなメリットがある。著者は合わせてセルフサインアップの無効化やトークン有効期限の調整など、本番環境への移行前に確認すべきセキュリティ設定も解説している。

Amazon Bedrock AgentCore Gateway là dịch vụ cho phép expose Lambda function và REST API dưới dạng endpoint tương thích MCP. Tính năng Web Search của Gateway là một managed connector gọi chỉ mục web của Amazon như một MCP tool, cho phép Claude Desktop và các MCP client khác thực hiện tìm kiếm trực tiếp. Vì Gateway không hỗ trợ API key làm phương thức xác thực, bài viết hướng dẫn chi tiết cách kết nối bằng OAuth với JWT. Người dùng chỉ cần đăng nhập bằng tài khoản Cognito qua trình duyệt trong Claude Desktop mà không cần cấu hình AWS credentials — đây là lợi thế lớn cho người không có quyền AWS. Tuy nhiên, kỹ sư Nomura từ atama plus lập luận ngược lại trên Zenn: chất lượng câu trả lời của AI phụ thuộc trực tiếp vào chất lượng tài liệu nguồn, nên nếu tài liệu cũ hoặc sai thì AI cũng trả lời sai.
