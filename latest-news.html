📰 本文 + 和越対訳

Zennに投稿された技術記事では、Next.jsアプリの認証ライブラリ「Better Auth」をMCP（Model Context Protocol）の認可サーバーとして構成し、AIエージェントが第三者サービスへOAuth2.0フローでアクセスする仕組みを実装した手順が詳細に解説されている。従来のMCPサーバーはAPIキーや固定トークンを直接扱うケースが多く、権限管理の粒度が粗い問題があった。この手法では、エージェントが実際のユーザーの代わりにスコープ限定の認可トークンを取得し、操作ログも残せる設計になっている。実装の肝は、Better AuthのカスタムOAuthプロバイダー機能とMCPサーバーのtransport層をつなぐ薄いアダプター層にあり、具体的なコードサンプルとともに公開されている。エージェント時代のセキュアなアクセス制御として注目を集めている。

Một bài viết kỹ thuật trên Zenn mô tả chi tiết cách cấu hình thư viện xác thực "Better Auth" của Next.js thành máy chủ ủy quyền MCP (Model Context Protocol), cho phép AI agent truy cập dịch vụ bên thứ ba thông qua luồng OAuth 2.0. Các MCP server truyền thống thường dùng API key hoặc token cố định với quyền kiểm soát phân quyền thô, còn phương pháp này cho phép agent lấy token ủy quyền có phạm vi giới hạn thay mặt người dùng thực và ghi lại nhật ký thao tác. Điểm mấu chốt là một lớp adapter mỏng kết nối tính năng OAuth provider tùy chỉnh của Better Auth với transport layer của MCP server, được chia sẻ kèm code mẫu cụ thể. Đây đang thu hút sự chú ý như một giải pháp kiểm soát quyền truy cập an toàn trong kỷ nguyên agentic.

C1Anthropic Donates Agent Skills Standard to the Agentic AI Foundation Under Linux Foundation

📰 Article + Impact

Anthropic has donated its Agent Skills standard to the Agentic AI Foundation (AAIF), which operates under the Linux Foundation umbrella. This move follows a pattern Anthropic established when it donated the Model Context Protocol (MCP) to the same foundation — the AAIF was co-founded by Anthropic, Block, and OpenAI in 2025. By transferring governance of Agent Skills to a neutral multi-vendor body, Anthropic signals that the specification is meant to become an industry-wide standard rather than a proprietary format. Agent Skills define how an AI agent can expose reusable capabilities — named, typed, versioned units of work that can be composed into larger agent pipelines. The technical goal is interoperability: an Agent Skill built for Claude should be callable by any MCP-compatible runtime. Simon Willison, who had predicted this move in December 2025, notes that the governance transfer also activates the community contribution process, allowing third-party developers to propose extensions to the spec.

This feature signals that GitHub views "agentic adoption rate" as a first-class organizational KPI.
