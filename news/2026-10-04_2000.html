📰 Article (English)

Cloudflare has announced an open competition inviting developers and teams to build the next generation Git hosting platform entirely on top of the Cloudflare developer platform. The initiative offers significant financial prizes and infrastructure credits to winners who can demonstrate a production-ready alternative to centralized Git platforms. Cloudflare argues that the existing landscape is dominated by a small number of providers, and that distributing Git infrastructure across its global edge network would improve resilience, latency, and developer sovereignty over their code. The competition encourages contestants to leverage Cloudflare Workers, R2 object storage, D1 database, KV, and Durable Objects to build core Git features including repository hosting, pull request workflows, CI integration, and access control. Cloudflare CEO Matthew Prince highlighted that git is "fundamentally a distributed protocol" and that hosting it on centralized servers was "an accident of history." The deadline for submissions is December 2026, with judging criteria weighted toward performance, scalability, and open-source licensing.
