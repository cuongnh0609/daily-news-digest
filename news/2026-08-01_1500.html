B1GitHubにスタックPRが登場——gh stackでAIエージェント時代の大量コードを分割管理

📰 本文 + 和越対訳

GitHubが「スタックプルリクエスト」機能をパブリックプレビューとして公開したことを受け、Zennでその実践的な使い方を解説する記事が話題を集めている。AIエージェントが大量のコードを生成する現代において、一つの巨大なPRはレビュー困難になりがちだ。スタックPRはそれを解決するために、変更を意味のある単位で積み上げて数珠つなぎにするアプローチで、CLIから gh extension install github/gh-stack で導入できる。gh stack submit で複数PRを一括作成し、前のPRに変更が入った際には gh stack sync で後続のすべてのブランチを自動でrebaseできる。著者はAPI実装を3層（スキーマ定義・ビジネスロジック・エンドポイント）に分けた実例を示しており、各レイヤーでレビューの焦点が絞られることで、AIと人間が協働するコードの品質管理に新しい選択肢が生まれると主張する。

GitHub vừa ra mắt tính năng "Stacked Pull Requests" dưới dạng public preview, và một bài viết trên Zenn giải thích cách sử dụng thực tế đang được chú ý rộng rãi. Cài qua CLI với lệnh gh extension install github/gh-stack, dùng gh stack submit để tạo nhiều PR cùng lúc, và gh stack sync để tự động rebase toàn bộ stack khi có thay đổi. Tác giả minh họa bằng ví dụ chia API thành 3 tầng: schema, business logic, và endpoint — mỗi tầng cho phép review tập trung hơn, tạo ra lựa chọn mới cho việc quản lý chất lượng code trong thời đại AI và người cùng phát triển.

📰 Article (English)

Simon Willison has released smevals, an open-source evaluation framework co-developed with Jesse Vincent's Prime Radiant research lab, designed for developers to build and run systematic test suites against AI models. The framework introduces clear terminology: an "eval" is a collection of challenges designed to answer a specific question about a model; "tasks" are individual challenges within an eval; "configs" specify model parameters and prompts; "runs" record config-task executions; and "graders" evaluate outputs through sequences of checks ranging from simple string matching to complex LLM-as-judge assessments. The workflow proceeds in three phases — run, grade, and visualize — with results surfaced through either a local web server or static HTML reports. Willison calls this his "third iteration on evaluation methodology" and says it feels fundamentally right for ongoing personal use. The release comes amid a broader industry push for more rigorous, developer-accessible AI evaluation tooling, distinct from expensive academic benchmarks that teams cannot run themselves.

A new open-source project called QM (Multiplayer agent harness for work) has surfaced on Hacker News with 523 points, positioning itself as an organizational AI agent platform where each employee gets an isolated workspace rather than a shared assistant. QM enables searching across internal notes, email, documents, databases, and the web within a single identity layer, and supports publishing internal apps to specific people with live data. Architecturally, QM uses scope-based isolation — each person and room maintains separate memory, files, permissions, scheduled tasks, and sandboxed environments. CLI-driven initialization generates org-specific configuration, and organizations can deploy to private forks for customization. The project represents an emerging pattern: enterprise-grade multi-agent orchestration infrastructure that any organization can self-host.
