A-1東京・近畿で「木枯らし1号」——昨年より6日早く、今季最初の冬の訪れ

📰 本文 + 和越対訳

B-1ダウンロードした AGENTS.md による乗っ取りをClaude Code・Codex・Cursorのhookで防ぐ——防衛設計のイタチごっこ

📰 本文 + 和越対訳

AIエージェントがダウンロードフォルダに配置された悪意ある AGENTS.md や CLAUDE.md を読み込み、本来の設定を上書きする「乗っ取り」攻撃への対策を実装した記録だ。著者はまず文字列照合によるガードを試みたが、攻撃役エージェントに突破された。そこで設定ファイルの書き込み後に値の変化を検知する方式へ改め、ガード本体と基準値をrootが所有するパスに移動させた。さらにCodexのフルアクセスを禁止し、アプリ更新後にガードが有効かどうかを毎朝自動チェックする仕組みを追加した。「セキュリティと利便性のトレードオフ」という普遍的な問題を、AIエージェント時代特有の攻撃ベクターとして捉え直した実践的な記事だ。

Bài viết ghi lại quá trình tác giả triển khai biện pháp phòng thủ trước tấn công "chiếm quyền" khi AI agent đọc file AGENTS.md hoặc CLAUDE.md độc hại được đặt trong thư mục download. Giải pháp kiểm tra chuỗi ký tự ban đầu bị agent tấn công vượt qua, buộc tác giả chuyển sang phát hiện thay đổi giá trị sau khi file config bị ghi, đồng thời chuyển file guard và giá trị chuẩn sang đường dẫn thuộc quyền root. Codex bị hạn chế full access và có cơ chế kiểm tra tự động hàng sáng để xác nhận guard vẫn hoạt động sau mỗi lần cập nhật app.

B-2KiroからBacklog・Google Chat・Google Driveを横断検索——公式MCPサーバーで実現するワークスペース統合

📰 本文 + 和越対訳

AmazonがリリースしたIDEツール「Kiro」から、Google Workspace（Chat・Gmail・ドライブ・カレンダー）とBacklogをまとめて操作できる環境の構築手順が公開された。Google Workspaceには公式MCPサーバーを、Backlogにはnulab公式サーバーを使用する。Kiro Desktop版はクライアントシークレットを直接入力できないため、OAuth認証をmcp-remote経由で中継する構成が必要になる。記事では認証フローの詳細な設定例に加え、クライアントIDの入力ミス・リダイレクトURIの登録漏れ・認証中断時の対処法など実際に詰まる箇所と解決策を丁寧に解説している。MCP生態系の広がりとともに、AIエージェントによる業務ツール統合が現実的な選択肢となってきた事例として注目される。

Bài viết hướng dẫn cách kết nối Kiro IDE (công cụ của Amazon) với Google Workspace (Chat, Gmail, Drive, Calendar) và Backlog thông qua MCP server chính thức. Do Kiro Desktop không hỗ trợ nhập client secret trực tiếp, OAuth cần được relay qua mcp-remote. Tác giả chia sẻ cấu hình chi tiết và các lỗi thường gặp: nhập sai client ID, thiếu redirect URI, xác thực bị ngắt giữa chừng.
