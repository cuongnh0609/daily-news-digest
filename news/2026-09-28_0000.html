C-01"As a Language Model": Chat Template Injection Manipulates LLM Self-Referential Voice

📰 Article (English)

Researchers at arXiv have published a paper revealing a subtle but powerful attack vector targeting large language models through chat template manipulation. The paper, "As a Language Model," demonstrates that by injecting specific phrases into the chat template — the structured metadata layer that wraps user and assistant turns — an adversary can cause an LLM to alter the voice in which it refers to itself, shifting from first-person reasoning to detached third-person narration. This shift degrades the model's apparent self-awareness and makes it easier to elicit behaviors the model would normally suppress through its persona constraints. Unlike traditional prompt injection which targets the user-visible content, this technique operates at the formatting layer that most developers overlook. The attack was demonstrated across multiple frontier models including GPT-class and Claude-class architectures. The researchers argue this represents a new class of vulnerability distinct from jailbreaking: rather than bypassing rules, it subtly re-frames the model's identity context. Mitigations include template hardening, system prompt anchoring, and strict schema validation before messages reach the model's context window.

🟠 MEDIUM Developers using custom chat templates or multi-tenant prompting pipelines should audit their template handling for this class of injection.

C-03Jev Introduces "Decision Models" — A New Class of LLM Specialized for Binary and Probabilistic Judgments

📰 Article (English)

Simon Willison's deep-dive coverage of Jev — from TypeSafe AI — argues this represents a genuinely new shape of language model, one he calls "System One" or Decision Models. Unlike conventional LLMs that generate open-ended text responses, Jev takes natural language input and returns structured probabilistic outputs: yes/no answers, multi-class choices, or scoring values (0.0–1.0). This is accomplished by distilling a large generalist model down to a tiny specialist that has been fine-tuned specifically on classification and scoring tasks, discarding the generative head entirely. The result is a model that costs $0.042 per million input tokens with free output — roughly 100× cheaper than Claude Haiku — and can answer queries in under 50ms. Jev's design philosophy is explicit: it is not meant to replace LLMs but to act as a fast, cheap routing layer in agent pipelines and human-in-the-loop systems. Willison notes that Jev already powers production routing at several companies, deciding which tier of LLM to escalate a given query to, and is increasingly being embedded in CLAUDE.md and system prompts as a policy enforcement layer. The broader implication is an emerging LLM ecosystem stratification: frontier models for generation, mid-tier for reasoning, and sub-cent decision models for routing and gating.

🔴 HIGH Decision models like Jev offer a cost-effective gating layer for agent pipelines — worth evaluating if you're paying for LLM calls that only need yes/no answers.
