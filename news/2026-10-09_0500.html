📰 本文 + 和越対訳

Google Cloudは、Claude CodeやCursorなどのAIコーディングエージェントに対してGoogle Cloud固有の知識とツールを直接提供する「Google Cloud Developer Plugin for AI Coding Agents」を発表した。このプラグインはMCPサーバーとして機能し、エージェントがCloud RunやBigQueryなどのGoogle Cloud製品のドキュメント・APIリファレンス・デプロイコマンドにリアルタイムでアクセスできるようにする。従来はエージェントが汎用的な知識しか持たなかったため、Google Cloud特有の設定ミスが多発していたが、このプラグインによって「GCP専門エンジニアを常駐させた状態に近い」支援が可能になるという。Claude CodeのMCPサポートと合わせて活用することで、インフラ構築の自動化が大幅に加速すると期待されている。

C-03Samsung LittleBit: Sub-1-Bit LLM Compression via Latent Factorization Cuts Memory by 85% Without Significant Accuracy Loss

📰 Article (English)

Researchers at Samsung Labs published LittleBit, an open-source technique for compressing large language models below 1 bit per weight on average using latent factorization. Traditional quantization methods (INT4, INT8) represent each weight as a fixed-bit integer, but LittleBit decomposes weight matrices into low-rank latent factors that can be stored at mixed precision, achieving average bit-widths of 0.7–0.9 bits per weight. On benchmarks including HellaSwag, ARC, and WinoGrande, a 7B model compressed with LittleBit retains 96–98% of the accuracy of the full-precision baseline while reducing model size by approximately 85% compared to FP16. The approach differs from sparse methods like SparseGPT by maintaining dense representation in latent space rather than zeroing out weights. The code is available on GitHub under Apache 2.0 and supports quantizing models from Hugging Face Hub. This matters particularly for deploying capable LLMs on edge devices or reducing inference costs at scale.
