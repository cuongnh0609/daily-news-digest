C1llm 0.33 Released — OpenAI v3.x Compatibility, Multi-Template Merging, and Reasoning Summaries

📰 Article (English)

Simon Willison released llm 0.33, a significant update to his open-source command-line LLM tool. The release brings three major improvements. First, dependency updates: the tool now requires OpenAI Python library 3.x and switches from httpx to httpx2 for HTTP transport, aligning with the latest upstream API client changes. Second, embedding enhancements: llm embed and llm embed-multi commands gain a --key parameter allowing per-call API keys to be passed to embedding plugins without modifying shared model state — bringing embedding models into parity with regular LLM model patterns. Third, template composition: users can now stack multiple -t/--template flags in a single command to merge templates sequentially, enabling reuse of model configuration from one template with a prompt from another. This is particularly useful for packaging model presets. Additionally, reasoning-capable response models gain a reasoning_summary option with auto, concise, and detailed settings. The llm tool supports dozens of models across providers and is widely used in the developer community for scripting and automation workflows involving LLMs.

A new open-source macOS menu bar app called Ambient Context captures what users work on throughout the day by recording text from focused windows, storing it as daily markdown files that LLM agents can reference. Simon Willison công bố phân tích cho thấy tính năng tìm kiếm của ChatGPT đã bắt đầu sử dụng toán tử tìm kiếm site: một cách có hệ thống và quy mô lớn khi thu thập bằng chứng hỗ trợ cho câu trả lời. Điều này có nghĩa là ChatGPT đang chủ động giới hạn tìm kiếm web trong các domain cụ thể — ví dụ chạy site:docs.python.org để lấy tài liệu chính thức thay vì kết quả web thông thường. Hành vi này được phát hiện qua việc kiểm tra các query tìm kiếm mà ChatGPT tiết lộ trong giao diện của mình. Hệ quả rất đáng chú ý: nhà xuất bản web và tác giả tài liệu có thể thấy lưu lượng truy cập từ ChatGPT tăng lên, nhưng chỉ đối với các trang xếp hạng cao trong query site: được lọc. Các trang web có cấu trúc kém hoặc nội dung mỏng có thể bị bỏ qua hoàn toàn để ưu tiên các nguồn có tổ chức tốt hơn. Đối với developer, xu hướng này có nghĩa là việc duy trì tài liệu chính thức cập nhật và có cấu trúc tốt ngày càng quan trọng — không chỉ cho người đọc mà còn cho các hệ thống retrieval AI. Willison lưu ý đây là một phần của xu hướng rộng hơn: AI search ngày càng tinh vi trong cách chọn nguồn, vượt qua keyword matching đơn giản để hướng đến hiểu biết về domain nào nắm giữ nội dung uy tín cho từng chủ đề cụ thể.
Đối với SE/Cloud Engineer: nếu team bạn có public API docs hoặc tài liệu kỹ thuật, đây là tín hiệu để đầu tư vào cấu trúc và chất lượng nội dung — tài liệu tốt sẽ được ChatGPT Search ưu tiên trích dẫn hơn, tăng khả năng hiển thị với developer dùng AI search.

site: operator /saɪt ˈɒpəreɪtər/ Toán tử tìm kiếm giới hạn kết quả trong một domain cụ thể. Ví dụ: site:github.com llm agent chỉ tìm trong github.com.
authoritative source /ɔːˈθɒrɪtətɪv sɔːs/ Nguồn thông tin có thẩm quyền — thường là trang chính thức của tổ chức, tác giả, hoặc chuẩn mực ngành. AI retrieval ưu tiên nguồn này vì độ tin cậy cao.
thin content /θɪn ˈkɒntɛnt/ Nội dung "mỏng" — trang web có ít thông tin giá trị, nội dung trùng lặp, hoặc không đủ chi tiết. Google và AI search đều hạ ưu tiên với loại trang này.
retrieval system /rɪˈtriːvəl ˈsɪstəm/ Hệ thống tìm và lấy thông tin từ một tập hợp lớn tài liệu (web, database, vector store). Trong AI, RAG (Retrieval-Augmented Generation) là kiến trúc phổ biến dùng retrieval system.
