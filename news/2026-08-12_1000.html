C2GitHub Copilot Behind a MitM Proxy — Researchers Expose Plaintext Session Storage and Context Leakage

📰 Article (English)

A detailed technical investigation published in the Lighthouse Newsletter reveals the internal mechanics of GitHub Copilot by intercepting its network traffic through mitmproxy. The research exposes several architectural details with significant security and privacy implications. Copilot's bootstrap sequence performs OAuth authentication, model discovery, and policy checks before any user interaction. A dedicated /models/session/intent endpoint classifies each prompt into categories like "code-gen" and "debugging" to route to the most suitable model. Most critically, the system maintains a local SQLite database storing all user messages and assistant responses in plaintext without encryption or scrubbing — enabling historical context retrieval via SQL queries but raising serious data confidentiality concerns. On context injection: Copilot automatically includes recently edited files in completion requests, meaning unrelated files containing sensitive data such as environment variables or credentials can leak into AI requests if open in the editor. The researcher describes modern AI coding tools as stateful systems where "context is becoming the product", highlighting the tension between usefulness and data confidentiality that every AI tool developer must navigate.
