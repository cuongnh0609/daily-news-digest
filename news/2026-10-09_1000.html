B1オブジェクト指向UIをClaude Agent Skillに——AI生成UIの構造スコアが8→10点に向上

📰 本文 + 和越対訳

Emuni社のエンジニアが、「オブジェクト指向UIデザイン」（上野・藤井、2020年）の原則をClaude Codeの Agent Skillに変換し、AI生成UIの品質向上を実験した。OOUIの核心は「動詞（タスク）」ではなく「名詞（オブジェクト）」を起点にUIを設計することで、著者はこれを4つの原則にまとめたSKILL.mdファイルとして実装した。同じプロンプトで生成したRAGドキュメント管理画面をSkillあり・なしで比較したところ、構造スコアはSkillなしの8点からSkillありの10点に向上した。具体的には、サイドバーがオブジェクト（ドキュメント、ユーザーグループ）単位で整理され、詳細画面がモーダルではなくサイドパネルで表示されるようになった。著者は「抽象的な原則リストより、手順書形式で記述することがAgentに指示を守らせる鍵」と結論づけている。

Một kỹ sư tại Emuni đã chuyển đổi các nguyên tắc từ sách "Object-Oriented UI Design" (Ueno & Fujii, 2020) thành một Claude Code Agent Skill và thực nghiệm cải thiện chất lượng UI được tạo bởi AI. Cốt lõi của OOUI là thiết kế UI bắt đầu từ "danh từ (object)" thay vì "động từ (task)". Tác giả đóng gói bốn nguyên tắc thành file SKILL.md và so sánh màn hình quản lý tài liệu RAG được tạo với/không có Skill — điểm cấu trúc tăng từ 8/10 lên 10/10. Sidebar được tổ chức theo đơn vị object thay vì theo chức năng, và màn hình chi tiết hiển thị bằng side panel thay vì modal. Tác giả kết luận: "Viết hướng dẫn dưới dạng quy trình tuần tự thay vì danh sách nguyên tắc trừu tượng là chìa khóa để Agent tuân theo."

B3Microsoft、VS CodeにマルチモデルAI協調機能「HydraFusion」をプレビュー実装——品質を保ちつつコストを削減

📰 本文 + 和越対訳

マイクロソフトはVS Code 1.140（9月30日リリース）にAIモデルのオーケストレーション機能「HydraFusion」をリサーチプレビューとして実装した。従来のCopilotは1つのリクエストに1つのモデルを選択して割り当てるが、HydraFusionは1タスクに複数のモデルを組み合わせて実行する点が異なる。動作モードは3種類：(1)「Single」——1つのモデルが解決、(2)「Cascade」——効率モデルが下書き→チェッカーモデルが検証→必要なら上位モデルにエスカレーション、(3)「Critique」——異なるモデルファミリーが相互レビュー。各タスクに対して推論・コード生成・デバッグ・ツール使用の能力シグナルを評価し、最適なパターンを選択する。Copilot Pro/Pro+/Business/Enterpriseユーザーが利用可能で、BusinessとEnterpriseはAdminによるプレビュー機能の有効化が必要だ。

Microsoft đã tích hợp tính năng "HydraFusion" — một Research Preview — vào VS Code 1.140 (phát hành 30/9). Khác với Copilot truyền thống chỉ gán một model cho một request, HydraFusion kết hợp nhiều model để xử lý một tác vụ. Có ba chế độ hoạt động: (1) Single — một model giải quyết, (2) Cascade — model hiệu quả viết nháp, model kiểm tra xác nhận, rồi leo thang lên model mạnh hơn nếu cần, (3) Critique — hai model từ các "gia đình" khác nhau đánh giá chéo nhau. Hệ thống đánh giá khả năng suy luận, sinh code, debug và sử dụng tool của từng model để chọn pattern tối ưu. Tính năng này dành cho người dùng Copilot Pro/Pro+/Business/Enterprise, trong đó Business và Enterprise cần Admin bật tính năng preview.
