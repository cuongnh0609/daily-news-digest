C1Zed Launches Delta — A Multiplayer AI Collaboration Tool That Records Every Prompt, Edit, and Context

📰 Article (English)

The Zed development team has announced Delta, a standalone collaborative coding platform that fundamentally changes how teams work with AI agents by preserving the complete record of every conversation, prompt, code change, and the context behind each modification. Unlike existing editor plugins, Delta is built as an independent application powered by DeltaDB, a purpose-built database using CRDT (Conflict-free Replicated Data Type) technology that allows multiple users and AI agents to edit simultaneously without conflicts. The Rust client compiles to WebAssembly and uses WebGL for rendering, delivering native application performance through a web browser at delta.dev. Delta supports Claude Code integration, with terminal session content syncing in real-time so the entire team can observe and comment on AI-assisted development as it happens. Future support for additional agent platforms is planned. Critically, Delta captures not just code diffs but the conversational thread that produced them — including the prompts that triggered each change — making it possible to understand not only what changed, but why and how specific instructions led to specific implementations. The team deliberately kept Delta separate from the Zed editor to let each product evolve independently, though future integration remains possible.
