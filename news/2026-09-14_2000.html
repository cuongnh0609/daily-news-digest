📰 本文 + 和越対訳

The key insight behind the tool is practical rather than novel: AI coding agents tend to generate verbose commit messages packed with internal references, issue numbers, and implementation commentary that make no sense in a public context. A quick interactive cleanup pass before a public release is worth the workflow overhead. The release is part of Willison's broader pattern of building composable developer tools around the friction points he encounters while maintaining open-source projects with AI coding assistance.
