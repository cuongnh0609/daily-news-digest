B1AIエージェントの「単一ループ」vs「有向グラフ」——コスト59%削減・速度48%向上を実機で実証

📰 本文 + 和越対訳

エンジニアがZennに投稿した実機比較記事が注目を集めている。対象タスクは6つのバグを含む3モジュール構成の課金パイプラインで、LLMが自由にループしながら修正する「単一ループ」構造と、パーサ・価格計算・レポート・承認ゲートという固定ステージを持ち各段階に検証器を置く「有向グラフ」構造を同条件で比較した。20件の隠しテストを両アーキテクチャともに全通過しながらも、有向グラフではLLMのターン数が7→3回（-57%）、実行時間が36.69秒→19.07秒（-48%）、入力トークン数が23,322→5,966（-74%）、推定コストが$0.02195→$0.00893（-59%）と劇的な改善を記録した。出力トークン数はほぼ同一で、コーディング品質は変わらない。著者は「LLMに推論させ、制御フローはコードに担わせる設計が本質だ」と結論づけており、単一ループで増大し続けるコンテキストが余分なターンを生む根本原因だと指摘している。エージェント設計において「頭脳と骨格を分離する」原則の重要性を実データで示した好例として反響を呼んでいる。

Một bài viết so sánh thực nghiệm trên Zenn đang thu hút sự chú ý rộng rãi. Tác giả so sánh hai kiến trúc agent trên cùng một tác vụ: "Single Loop" cho phép một LLM tự do lặp qua các bước sửa bug, và "Directed Graph" với các giai đoạn cố định (parser, pricing, report, approval gate) mỗi giai đoạn có verifier riêng. Cả hai đều pass toàn bộ 20 test ẩn nhưng Directed Graph giảm đáng kể: số lượt LLM từ 7 xuống 3 (-57%), thời gian thực thi từ 36,69s xuống 19,07s (-48%), input token từ 23.322 xuống 5.966 (-74%), chi phí ước tính giảm 59%. Tác giả kết luận nguyên tắc cốt lõi là để LLM lo phần suy luận, còn control flow giao cho code đảm nhận — context ngày càng phình to trong single loop mới là nguyên nhân gốc rễ sinh ra các lượt thừa.

C1How Anthropic Ships Claude With Claude: Separating the Brain From the Hands

📰 Article (English)

Latent Space published a deep-dive interview with Anthropic engineers Katelyn Lesse and Angela Jiang revealing how the company builds its own products on the same Claude Platform it offers to customers. The central architectural insight is separating the agent's "brain" (the durable harness and session log) from its "hands" (the ephemeral sandbox that executes code). The harness runs persistently on a durable server while sandboxes are spun up on demand — meaning a sandbox crash no longer terminates the entire agent session. Credentials live in a separate vault; the agent sees only placeholders, and a network egress proxy injects real secrets at runtime so code inside the sandbox never holds sensitive tokens. Network controls allow domain-based allow-lists or full network isolation per sandbox. Internally, Anthropic rewrote the Messages API from Python to Rust, verified with shadow traffic, achieving roughly 40–50% CPU savings and 10–20% faster time-to-first-token. The team also introduced "Dreaming" — a managed agent that reviews another agent's outputs and writes long-term memories — as a composable primitive for higher-order agent behavior. Engineers are urged to build large eval suites and treat infrastructure work as research.

C2macOS Still Trusts Compromised eMudhra CA Certificates Ten Days After Disclosure

📰 Article (English)

A security researcher disclosed that Apple's macOS continues to trust certificates issued by eMudhra, an Indian certificate authority (CA), more than ten days after the CA was found to have issued fraudulent TLS certificates for domains it does not control. The disclosure page documents a pattern of mis-issuance by eMudhra that violates the Baseline Requirements of the CA/Browser Forum — the industry body that governs TLS certificate issuance standards. Mozilla and Google Chrome removed eMudhra from their trust stores within 48 hours of confirmation, but Apple has yet to act. macOS Safari and any macOS app that relies on the system trust store — including many developer tools, package managers, and git clients — currently accept eMudhra-signed certificates as valid. The researcher warns that an attacker in a network-adjacent position could serve a malicious HTTPS site with a valid-looking eMudhra certificate that macOS would not flag. The issue is particularly relevant for developers in India and Southeast Asia, where eMudhra is commonly used by government and financial services sites. No CVE has been issued, but the Hacker News community tracked it with 480 upvotes.
