B-01Lambda MicroVMsでAIコーディングエージェントのサンドボックス環境を整備する——Firecracker分離でローカルを守る

📰 本文 + 和越対訳

AWSソリューションアーキテクトが、Claude CodeやKiroなどのAIコーディングエージェントを安全に動作させるためのMCPサーバーを開発・公開した。コアとなるのはAWS Lambda MicroVMs（2026年6月リリース）で、Firecrackerベースの仮想マシン分離を利用したサンドボックス環境を実現している。エージェントが誤ってローカルのファイルを削除したり、リポジトリ内の悪意あるコードがクレデンシャルを外部に漏らしたりするリスクを、VM単位の完全な隔離によって防ぐ。アーキテクチャは2層構造で、VMの内部で動作する「sandbox-agent」（Node.js HTTPサーバー）と、開発者PCに置かれるMCPサーバーが連携する。スナップショットからの起動は約2秒で完了し、VM破棄後は環境を綺麗にリセットできる。実際にVMの内部でExcalidrawのビルドを実演しており、VM作成4秒・依存関係インストール41秒・Viteビルド37秒という結果が示された。

Một Solution Architect của AWS đã phát triển và công bố một MCP server giúp chạy an toàn các AI coding agent như Claude Code và Kiro. Thành phần cốt lõi là AWS Lambda MicroVMs (ra mắt tháng 6/2026), tận dụng phân lập máy ảo dựa trên Firecracker để tạo môi trường sandbox. Kiến trúc gồm hai tầng: "sandbox-agent" (Node.js HTTP server) chạy bên trong VM, kết hợp với MCP server đặt trên máy tính của developer. Khởi động từ snapshot mất khoảng 2 giây, sau khi hủy VM môi trường được reset sạch hoàn toàn. Demo thực tế build Excalidraw bên trong VM cho kết quả: tạo VM 4 giây, cài dependency 41 giây, Vite build 37 giây. Đây là giải pháp thực tiễn cho bài toán bảo vệ môi trường local khi dùng agent tự hành.

B-03AIエージェントの「文脈崩壊」を防ぐ——ファイルベース永続プランニング入門（planning-with-files実践）

📰 本文 + 和越対訳

長時間のAIエージェントセッションで繰り返し発生する「文脈崩壊」——コンテキストウィンドウが埋まってコンパクションが走ると初期計画が要約されて消え、/clearで全部リセットされる——を解決するOSSフレームワーク「planning-with-files」の実践紹介記事がZennで注目を集めている。解決策はシンプルで、計画情報をディスク上の3つのマークダウンファイルに永続化する: task_plan.md（フェーズ別チェックボックス）、findings.md（調査メモ・意思決定記録）、progress.md（セッションログ・テスト結果）。エージェントのコンテキストウィンドウは消えるが、プランはファイルとして生き続ける。Claude Codeプラグイン、npx、npmパッケージ経由で導入でき、/plan・/plan-status・/plan-goalのスラッシュコマンドでエージェントが自律的にプランを参照・更新しながら作業を続けられる設計になっている。

Bài viết thực hành về framework OSS "planning-with-files" đang thu hút sự chú ý trên Zenn. Framework này giải quyết vấn đề "context collapse" thường gặp trong các session AI agent dài — khi context window đầy và compaction chạy, kế hoạch ban đầu bị tóm tắt và biến mất; /clear sẽ reset tất cả. Giải pháp đơn giản: lưu trữ thông tin kế hoạch dưới dạng 3 file markdown trên đĩa — task_plan.md (checkbox theo giai đoạn), findings.md (ghi chú điều tra/quyết định), progress.md (log session/kết quả test). Context window của agent có thể biến mất, nhưng plan tồn tại dưới dạng file. Có thể cài qua Claude Code plugin, npx, hoặc npm package; các slash command /plan, /plan-status, /plan-goal cho phép agent tự tham chiếu và cập nhật plan trong quá trình làm việc.
