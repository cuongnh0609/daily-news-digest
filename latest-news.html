📰 本文 + 和越対訳

Googleは4日、中国の端末メーカーが工場出荷段階でAndroidスマートフォンにバックドア（不正侵入用の隠し機能）を仕込み、犯罪者にそのアクセス権を販売していたと発表した。対象となった端末は130万台を超えるとされており、広告詐欺や通信中継（プロキシ）への悪用が確認されている。Googleは問題が確認された中国企業との取引を停止し、同様の手口による被害拡大を防ぐための技術的対策も強化するとしている。バックドアはデバイスのファームウェアに組み込まれており、通常の使用では発見が困難なため、被害に気づかないままの利用者が多数存在する可能性がある。セキュリティ研究者からは、サプライチェーン（製品の供給網）全体にわたるセキュリティ審査の必要性を指摘する声が上がっている。

Do backdoor được nhúng vào firmware thiết bị và khó phát hiện trong quá trình sử dụng bình thường, nhiều người dùng có thể không biết mình đang bị ảnh hưởng. Các chuyên gia bảo mật chỉ ra sự cần thiết phải kiểm tra bảo mật toàn bộ chuỗi cung ứng (supply chain).

B1Claude Code の会話履歴からコストを正確に計測するときにはまった4つの落とし穴

📰 本文 + 和越対訳

Claude Code（Anthropic製のAI駆動型コーディングエージェント）を日常的な開発に活用するエンジニアにとって、実際のAPIコストを把握することは予算管理の観点から重要な課題だ。Zennに投稿されたこの記事では、会話のトランスクリプト（会話ログ）を解析してコストを集計する過程で著者が遭遇した4つの落とし穴が詳述されている。第一に、Claude Codeはプロンプトキャッシュを積極的に使用するため、同じトークン数でもキャッシュヒット時と未ヒット時でコストが大きく異なる点。第二に、ツール使用（tool_use）の結果も入力トークンとしてカウントされるため、コンテキストウィンドウ内の重複トークンを二重カウントしやすいこと。第三に、並列エージェント（subagent）を起動した場合、それぞれのセッションのコストが独立して積算される仕組みになっている点。第四に、会話の要約（auto-compact）が行われると、以前のターンのトークン数がリセットされてしまう問題だ。正確なコスト測定には、Anthropic APIが返す使用量メタデータを直接参照し、キャッシュ読み書きのトークンを適切に按分する実装が必要であると筆者は結論付けている。

Đối với các kỹ sư sử dụng Claude Code (agent lập trình AI của Anthropic) trong công việc hàng ngày, việc nắm bắt chi phí API thực tế là vấn đề quan trọng trong quản lý ngân sách. Bài viết trên Zenn này mô tả chi tiết 4 "cạm bẫy" mà tác giả gặp phải khi phân tích transcript hội thoại để tổng hợp chi phí. Thứ nhất, Claude Code sử dụng prompt cache tích cực, nên chi phí chênh lệch lớn giữa cache hit và cache miss dù cùng số token. Thứ hai, kết quả tool use cũng được tính là input token, dễ đếm trùng các token trong context window. Thứ ba, khi khởi động subagent song song, chi phí mỗi session được tích lũy độc lập. Thứ tư, khi auto-compact (tóm tắt hội thoại) xảy ra, số token của các turn trước bị reset. Tác giả kết luận rằng cần triển khai logic đọc trực tiếp từ usage metadata của Anthropic API và phân bổ đúng các token cache read/write để đo chính xác.
