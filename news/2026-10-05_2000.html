B-01自作MCPサーバーをClaude Codeに登録する――設定は3行、つまづくのはパスとスコープだけ

📰 本文 + 和越対訳

Claude Codeに自作のMCP（Model Context Protocol）サーバーを組み込む手順を丁寧に解説した記事がZennに投稿され、注目を集めている。著者は「設定ファイルへの追記はたった3行だが、パスの指定方法とスコープ（global・local・project）の違いを間違えると接続に失敗する」と強調する。実装例では、ローカルで起動するNode.jsサーバーとClaude Codeの接続設定（.claude/settings.json）を詳細に示し、stdio / SSEトランスポートそれぞれの使いどころも説明している。またClaude Codeのスコープ設定により、特定のプロジェクトだけにMCPサーバーを公開する「project scope」の活用例も紹介している。MCPエコシステムが広がる中、自社ツールをAIエージェントに統合したいエンジニアにとって実践的なガイドとなっている。

Một bài viết trên Zenn giải thích chi tiết quy trình tích hợp server MCP (Model Context Protocol) tự tạo vào Claude Code đang thu hút sự chú ý. Tác giả nhấn mạnh "chỉ cần thêm 3 dòng vào file cấu hình, nhưng nếu chỉ định sai đường dẫn hay nhầm lẫn về scope (global/local/project) thì kết nối sẽ thất bại". Ví dụ thực tế cho thấy cấu hình kết nối chi tiết giữa server Node.js chạy cục bộ và Claude Code (trong `.claude/settings.json`), đồng thời giải thích khi nào dùng transport stdio hay SSE. Bài viết cũng giới thiệu cách dùng "project scope" — chỉ expose MCP server cho một dự án cụ thể — thông qua tính năng scope setting của Claude Code. Khi ecosystem MCP ngày càng mở rộng, đây là hướng dẫn thực tế cho các kỹ sư muốn tích hợp công cụ nội bộ vào AI agent.
