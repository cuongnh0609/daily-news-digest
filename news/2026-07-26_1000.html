C-01The New Rules of Context Engineering for Claude 5 Generation Models

📰 Article (English)

Anthropic engineer Thariq Shihipar revealed that the Claude Code team removed over 80% of the system prompt without any performance degradation, fundamentally challenging how developers think about context engineering for advanced AI models. The key finding: Claude 5 generation models benefit from autonomy rather than rigid prescriptive rules. The old playbook — stuff the system prompt with detailed instructions, provide exhaustive tool-use examples, front-load all relevant information, and repeat key instructions — is now largely counterproductive. The new approach prioritizes principle-based guidance over enumerated rules, redesigns tool interfaces instead of providing usage examples, and uses Progressive Disclosure via Skills: loading context only when needed rather than upfront. The team also introduced a claude doctor command to help developers rightsize their context. CLAUDE.md files should be kept lightweight, covering only genuine "gotchas" and non-obvious constraints. The framework reflects a broader shift: Claude 5 models can exercise judgment from surrounding context, making over-specified prompts wasteful and sometimes harmful to output quality.
