📰 Article (English)

GitHub has shipped a redesigned Copilot metrics dashboard for enterprise administrators and organization owners, moving beyond simple "active user counts" toward a cohort-based model of AI adoption analysis. The new dashboard segments developers into four adoption phases: Code-first users (primarily using inline completions), Agent-first users (leveraging Copilot agents for longer tasks), Multi-agent users (orchestrating multiple AI tools), and Passive users (licensed but not engaged). For each cohort, the dashboard surfaces metrics such as pull requests merged, code changes per user, and an "adoption multiplier" that compares productivity between passive and engaged users — giving leadership a quantifiable ROI narrative.

The system evaluates user placement using a rolling 28-day window and aligns with the existing Copilot usage metrics API, making it queryable via existing automation. Organizations receive targeted recommendations for moving passive users toward deeper Copilot engagement. The dashboard tracks six-month trends to show organizational progress over time. For engineering managers making the case for continued Copilot investment, this represents a significant shift: instead of saying "65% of developers activated Copilot," teams can now show "Agent-first users merge 2.3× more PRs than passive users."

The partnership also signals growing confidence in AMD's ROCm software ecosystem, which has historically been the weak link in AMD's AI story compared to NVIDIA's mature CUDA platform.
