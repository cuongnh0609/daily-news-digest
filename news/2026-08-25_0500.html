C1How Claude's Text Watermark Works — Anthropic Embeds Invisible AI-Content Markers Compliant with the EU AI Act

📰 Article (English)

Anthropic has published a detailed technical explanation of how Claude's text watermarking system operates. The technique is based on Google DeepMind's SynthID-Text approach and is designed to meet the EU AI Act's requirement to mark AI-generated content. Rather than appending visible tags or metadata, the watermark works by altering the source of randomness used during word selection at inference time. When Claude faces low-stakes choices between equally good words — places where either choice reads naturally — the system uses a cryptographic key combined with recent context words to guide the selection in a statistically detectable pattern. An analogy offered by Anthropic: it's like Monopoly players using digits of pi as dice rolls — the game plays out normally, but someone with the key can read the hidden sequence. The watermark requires no extra tokens, adds no latency, and has zero measurable effect on output quality, creativity, or readability. Current limitations include reduced effectiveness on highly factual or code-heavy content where word choices are constrained, and the watermark can be removed by fully rewriting the text.

C3Beyond Line-by-Line: Simon Willison on Why Verification Strategy Is the Core Skill for Working with Coding Agents

📰 Article (English)

Simon Willison argues in a recent post that the most important skill for productively working with AI coding agents is not prompt engineering — it's the ability to confidently verify that the agent's changes are correct. As agents handle larger and larger chunks of code, manually reading every modified line becomes impractical and increasingly ineffective. Willison contends that eyeballing code has never been the most reliable form of software validation, even before AI; what changes with agents is the scale at which this limitation matters. The real unlock is developing structured verification strategies: running test suites, using static analysis, checking invariants, diffing expected vs. actual behavior, and designing changes to be inherently auditable. The implication is that engineering practices built around human-written code — where understanding the change and validating it were the same action — must decouple into two distinct skills when working with agents. Teams that invest in testability, observability, and specification clarity will get dramatically more leverage from coding agents than those relying on trust and review.
