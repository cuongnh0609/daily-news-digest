C1LangSmith Tool Gateway: Secure, Governed Tool Use for Production AI Agents

📰 Article (English)

LangChain launched Tool Gateway in Public Beta on the LangSmith Agent Platform, addressing a critical gap in production agentic systems: credential management, identity, and access control at the tool layer. As agents increasingly run on schedules and handle long-horizon tasks, teams face hard-coded credentials, unrestricted tool access, and no audit trails. Tool Gateway solves this by acting as a managed layer between agents and their tools.

Concretely, any MCP server can be registered by URL, or teams can enable built-in connectors (Google, Microsoft, Salesforce, GitHub, Linear). A "tool kit" bundles curated tools at a single URL; each agent sees only its assigned kit. Identity is handled via two modes: "acting as the user" uses OAuth credentials per user, while "acting as the agent" uses service credentials or shared workspace profiles. Deny policies block specific tool calls by user or service key, and approval policies require human confirmation before sensitive operations — such as writing to a production database. Every tool call is traced in LangSmith with server, user, outcome, and latency. Gateway works with any MCP client including LangChain, Claude Code, and Cursor.

C2Inkling 2 Mini: Open-Weights Looped MoE Hits 79% SWE-bench, Runs on MacBook

📰 Article (English)

Thinking Machines Lab released Inkling 2 Mini, an open-weights model that pushes the boundary of what can run locally. Its architecture is unusual: a looped transformer where the two middle blocks of six layers execute three times per token. This yields more reasoning per token without adding stored knowledge, making it particularly suited for agentic coding tasks. The model is a Mixture-of-Experts with 26.4B total parameters and only 3.4B active, compressed to NVFP4 at around 20GB — runnable on a MacBook Pro with 32GB RAM via Ollama or llama.cpp.

Benchmark performance is striking for its size: 79.2% SWE-bench Verified, 77.9% SWE-bench Pro v2 Hard, and 48.2% DeepSWE v1.1 (best open model under 100B total parameters). It achieves 71.6% on Terminal Bench v2.1 and 82.7% on MCP Atlas. The model was trained starting from 384 experts with 48 sparsity; two-thirds were pruned mid-training and the pruned model healed via distillation. A variable-loop research variant (TML-d24-varloop-research) is also available. The authors report no significant monitorability regression at three loops versus one, and that agentic sabotage rates did not increase with deeper looping.
