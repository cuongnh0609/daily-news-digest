B-1Claude Codeは計画・レビューに残し、実装は安いモデルへ渡す——コスト最適化の新ワークフロー

📰 本文 + 和越対訳

Zennに投稿されたこの記事では、Claude Codeを「設計・計画・レビュー専用」に据え置き、実際のコーディング実装は比較的安価なモデル（Cursor内のGemini Flash等）に委ねるという役割分担アーキテクチャが紹介されている。Claude Codeの強みである高い推論能力と指示理解をタスクの上流工程に集中させ、下流の反復的な実装作業は低コストモデルが担うことで、月次APIコストを大幅に削減しつつ品質を維持できると著者は主張する。具体的には、Claude Codeで作成した詳細仕様書（SPEC）とタスクリストをCursorに渡し、実装後のdiffをClaude Codeが最終レビューするという3ステップフローを採用している。このワークフローはSpec-Driven Developmentの実践例としても注目されている。

Bài viết trên Zenn này giới thiệu kiến trúc phân chia vai trò: Claude Code đảm nhận "thiết kế, lập kế hoạch và review", còn việc triển khai code thực tế được giao cho các model rẻ hơn (như Gemini Flash trong Cursor). Cụ thể là quy trình 3 bước: Claude Code tạo spec chi tiết và task list → chuyển cho Cursor để implement → Claude Code review diff cuối cùng. Workflow này cũng được chú ý như một ví dụ thực hành của Spec-Driven Development.
