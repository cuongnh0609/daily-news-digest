B2AIエージェントの二重実行を止める「冪等性キー」の最小実装——本番エージェント運用の必須パターン

📰 本文 + 和越対訳

AIエージェントが同じタスクを複数回実行してしまう「二重実行」問題に対し、冪等性キー（Idempotency Key）を使った最小実装パターンが紹介された。エージェントにはリトライや並列起動による重複実行リスクが常に伴い、特に外部APIへの書き込みや課金処理など副作用を持つ操作では致命的な問題となりうる。提案されたパターンでは、タスクIDとコンテキストハッシュを組み合わせたキーをRedisに保存し、実行前にチェックすることで同一タスクの多重実行を防ぐ。コードは50行未満で実装可能で、LangGraph・CrewAI・AutoGenなど主要フレームワークへの組み込み例も示されている。本番エージェント運用において「冪等性の欠如」は沈黙のバグになりやすく、設計初期から組み込むべき必須パターンとして注目されている。

Bài viết giới thiệu pattern triển khai tối giản dùng Idempotency Key (khóa mã lực) để ngăn AI agent thực thi cùng một task nhiều lần. Agent luôn có nguy cơ chạy lặp do retry hoặc khởi động song song, đặc biệt nguy hiểm với các thao tác có side effect như ghi vào API bên ngoài hay xử lý thanh toán. Pattern đề xuất lưu khóa kết hợp task ID và context hash vào Redis, kiểm tra trước khi thực thi để ngăn chạy lặp. Code dưới 50 dòng và có ví dụ tích hợp cho LangGraph, CrewAI, AutoGen. Đây được xem là pattern bắt buộc cần đưa vào từ giai đoạn thiết kế ban đầu vì "thiếu idempotency" dễ trở thành lỗi âm thầm trong môi trường production.

Instead of downloading full model weights on each upgrade, Granite Switch uses a compact delta-weight format: only the changed layers between versions are distributed as a diff patch, reducing the update payload by up to 94% compared to full re-downloads. This is the first production implementation of the "update models like you update software" concept that researchers have advocated for since early 2025.
