Bài học: trách nhiệm thuộc về engineer xây dựng hệ thống, không phải model. David Soria Parra (Anthropic) cho biết bản cập nhật MCP tháng 7/2026 đã làm cho protocol stateless — sửa lỗi "session not found" dưới load balancing. C1Rivet (YC W23): Self-Hosted Actor-Model Agent Orchestrator Built on S3 — 72 KB per Agent vs 512 MB Sandbox

📰 Article (English)

Rivet, a YC W23 company, launched on Hacker News this week with a self-hostable, open-source agent orchestrator built on the actor model. Each agent runs as a lightweight actor process — just 72 KB baseline versus 512 MB for a minimal VM/container sandbox — with startup latency of 4.9 ms p99 compared to 1.7 s p99 for traditional sandboxes. The architecture gives each actor a long-lived process, in-memory state, a WebSocket server, and durable SQLite storage backed by S3. Crucially, writes are acknowledged once SSDs in 2 of 3 availability zones confirm the write; S3 sync happens asynchronously in the background, keeping S3 off the critical write path. Measured durability: writes in 1.07 ms p99, reads in 1.36 ms p99 across 3 AZs. The comparison to Cloudflare Durable Objects is intentional — agents are written in TypeScript or Rust, and one early adopter (Amp) reportedly migrated from Durable Objects over a weekend. The self-hosted deployment requires just a single Rust binary with S3 as the only external dependency. The Rivet team argues that agent orchestration infrastructure should be separated from the agent execution sandbox: "separation of head from hands." For sandboxed execution, they point to agentOS (V8/Wasm isolation). This aligns with AAIF's "harness over model" framing from AGNTCon.
