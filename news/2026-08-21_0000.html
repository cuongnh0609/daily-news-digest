📰 Article (English)

Security researchers at SafeDep discovered that a compromised release of the popular Rust crate arrayref was published to crates.io containing a malicious dependency on a typosquatted package named proc-macro1 (note the "1" instead of legitimate proc-macro2). The proc-macro1 package's build script (build.rs) downloads and executes a remote binary payload at compile time — meaning any developer who ran cargo build with the affected version of arrayref would unknowingly execute arbitrary code on their machine. The legitimate arrayref crate has over 50 million downloads and is widely used across the Rust ecosystem in production systems. This attack exploits the fact that Rust build scripts run with full system permissions during compilation, a known but underappreciated attack surface in the supply chain. Crates.io yanked the malicious version promptly after the disclosure, but the incident highlights the need for audit tooling, dependency pinning with lockfiles, and build script sandboxing in Rust projects.
