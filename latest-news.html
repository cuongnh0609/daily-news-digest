B-02GitHub Copilot Dreaming発表 — バックグラウンドでAI指示書を自動更新・整理するエージェント機能

📰 本文 + 和越対訳

GitHub Universe 2026にてGitHubが発表した「Copilot Dreaming」（パブリックプレビュー）は、バックグラウンドで動作するAIエージェントがCopilotのメモリ（コーディング規約・アーキテクチャ・プロジェクトコマンドなど）を過去の会話やPRレビューを元に自動的に見直し・更新する機能だ。開発者が眠っている間や別作業中にも、エージェントが継続的にコードベースの変化を学習し、指示ファイルの陳腐化を防ぐことを目指している。デモではJavaアプリをSvelte/JSへ移行するプロジェクトで、古くなった指示ファイルがエージェントによって再編成され、書き直したPRが自動的に提出された。この仕組みは、チームがAI指示書の保守コストを削減しながら、Copilotの精度を高く保つことを可能にする。

"Copilot Dreaming" (public preview) được GitHub công bố tại GitHub Universe 2026 là tính năng agent AI hoạt động ngầm, tự động xem xét và cập nhật "bộ nhớ" của Copilot — bao gồm quy ước coding, kiến trúc, lệnh dự án — dựa trên lịch sử hội thoại và PR review. Trong khi lập trình viên ngủ hoặc đang làm việc khác, agent liên tục học hỏi từ những thay đổi trong codebase để ngăn các file hướng dẫn trở nên lỗi thời.
