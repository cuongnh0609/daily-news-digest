B-1プロンプトガチャはもう古い——「ハーネスエンジニアリング」こそがAI駆動開発の本質、Google Cloudが解説

📰 本文 + 和越対訳

ITmediaの@ITが掲載したGoogle Cloud「The Agent Factory」シリーズの最新回では、AIエージェントの「ハーネス（harness）」設計が開発生産性の鍵だと解説している。ハーネスとはLLMの周囲に置かれるソフトウェア層であり、ツール、コンテキスト、フィードバックをモデルに供給する役割を持つ。Google Cloudのエンジニアによると、同チームは2025年5月からコードエディタを開かずエージェントに全コーディングを委任し、プルリクエストのレビューと仕様書・AGENTS.mdの整備に注力するようになったという。ハーネスの設計で重要なのはループ（反復回数と終了条件）、ツール定義、メモリ管理の3要素であり、バグ修正なら「テスト通過まで最大5回リトライ」のクローズドループ、バッチ処理にはシンプルなループハーネス、危険操作（フォースプッシュや再帰削除）にはセーフティガード付きハーネスと使い分ける。モデル単体の性能よりも、ツールと知識の充実度がエージェントの品質を左右するという主張が核心だ。

Loạt bài "The Agent Factory" của Google Cloud trên @IT (ITmedia) giải thích rằng thiết kế "harness" — lớp phần mềm bao quanh LLM — mới là chìa khóa thực sự của AI-driven development, không phải việc tối ưu prompt. Harness cung cấp tool, context và feedback cho model. Một kỹ sư của Google Cloud cho biết nhóm họ không mở code editor từ tháng 5/2025, thay vào đó tập trung review pull request và duy trì file AGENTS.md.
