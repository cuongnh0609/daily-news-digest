B1Claude Code が「決めたこと」を忘れない — 完全ローカル・APIキー不要のエージェント記憶レイヤー「myc」

📰 本文 + 和越対訳

長時間セッションでClaude Codeなどのコーディングエージェントがコンテキスト圧縮後に過去の決定を忘れ、却下済みの提案を再び持ち出す問題を解消するオープンソースツール「myc（マイコ）」が公開された。プロジェクトディレクトリに置くSQLiteファイル1つで動作し、クラウドAPIもAPIキーも一切不要という手軽さが特徴だ。mycはタスクキュー管理、決定ログの永続化、BM25とベクトル検索を組み合わせたハイブリッド検索、セッション保存、コードへのアンカーリングなど多彩な機能を備える。検証前の決定は「候補」として扱い、事実として扱わない安全設計も盛り込まれており、エージェントが一貫した方針で作業を続けるための実用的なインフラとして注目を集めている。

Một công cụ mã nguồn mở tên "myc" (viết tắt từ "mycelium" — nấm sợi) vừa được công bố nhằm giải quyết vấn đề các coding agent như Claude Code bị quên mất các quyết định đã đưa ra sau khi context bị nén trong các phiên làm việc dài. Công cụ này chỉ cần một file SQLite đặt trong thư mục dự án, không cần cloud API hay API key nào. myc cung cấp các tính năng như quản lý task queue, lưu trữ lâu dài nhật ký quyết định, tìm kiếm hybrid (BM25 + vector), lưu session, và anchor vào code. Thiết kế an toàn: các quyết định chưa được xác nhận chỉ được coi là "ứng viên", không được xem như sự thật, giúp agent làm việc nhất quán trong dài hạn.
