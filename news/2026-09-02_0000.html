B1会話セッションを妨害せず外部イベントでClaude Code / Codex / Cursorを動かすCLI設計——マルチエージェント非同期制御の実装パターン

📰 本文 + 和越対訳

ZennのcоjiさんによるArtifact Share プロジェクトの実装報告が注目を集めている。このCLIツールは、ブラウザ上でファイルの特定箇所に指摘コメントを書くと、バックグラウンドのAIエージェント（Claude Code、OpenAI Codex、Cursor）が自動的にファイルを修正し、画面リロードで結果が確認できる、という反復レビューワークフローを実現する。最大の技術的課題は「現在進行中の会話セッションを邪魔しない」という制約だった。各プラットフォームの仕組みは異なり、Claude Codeはバックグラウンドタスク完了時の自動ターン再開機構を、CodexはメッセージキューへのRESTアクセスを、CursorはACP（Agent Client Protocol）経由の専用セッション管理を採用している。指摘位置の記録にはアンカー情報を3種類保持する設計で重複報告を防止。常駐デーモン不要の1ファイル1プロセス設計により、運用を軽量に保っている点も評価されている。複数エージェント対応の現実的なアーキテクチャを示した貴重な事例だ。

Bài viết triển khai dự án "Artifact Share" của tác giả coji trên Zenn đang thu hút sự chú ý. Công cụ CLI này cho phép người dùng viết comment chỉ ra vấn đề tại vị trí cụ thể trong file trên trình duyệt, sau đó AI agent (Claude Code, OpenAI Codex, Cursor) tự động sửa file ở background và kết quả được xem sau khi reload trang. Thách thức kỹ thuật lớn nhất là "không làm gián đoạn phiên hội thoại đang chạy". Mỗi platform có cơ chế khác nhau: Claude Code dùng cơ chế tự động tiếp tục turn khi background task hoàn thành; Codex dùng REST access vào message queue; Cursor dùng ACP (Agent Client Protocol) để quản lý phiên riêng. Thiết kế 1 file 1 process không cần daemon thường trú giúp vận hành nhẹ nhàng. Đây là case study thực tế quý giá về kiến trúc hỗ trợ nhiều AI agent.
