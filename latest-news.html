C1Anthropic Demonstrates Provable LLM Inference Using zkSNARKs — FlashProve Runs at 110 tok/s on Llama 4

📰 Article (English)

Anthropic's research team has published early results on a system called FlashProve, which uses zero-knowledge succinct non-interactive arguments of knowledge (zkSNARKs) to allow a model provider to cryptographically prove that a given response was generated by a specific, committed model. This addresses a fundamental trust problem in AI deployment: users, auditors, and regulators currently have no way to verify that the model that produced a response is actually the model the provider claims to have used. FlashProve is open-sourced and proves inference for Llama 4 Maverick, a 400B-parameter mixture-of-experts model with 4-bit quantized weights. On a single NVIDIA H100 GPU, it generates proofs at approximately 110 tokens per second, with roughly 19 megabytes of proof per 1,024-token request. The overhead is 70–95× the base GPU time for running the model in vLLM — significant, but the team notes this is a first prototype. Security properties are formally stated and verified in Lean. Current limitations include greedy decoding only, no hidden architecture support, and a 1,024-token context cap. The implications for AI governance and enterprise compliance are substantial: future deployments could include on-chain or off-chain proof verification as a standard audit trail.
