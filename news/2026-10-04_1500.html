C2FTL: A New Operating System for Clouds — Build Your OS as a Library, Get VM Security at Container Speed

📰 Article (English)

FTL is an open-source operating system designed specifically for cloud environments, releasing publicly this week to significant Hacker News attention (162 points, 65 comments). Its core insight is that you can build an OS as a library — a shared library linked into an application rather than a traditional monolithic or microkernel system. Each container running on FTL gets its own userspace OS instance implementing Linux concepts including processes, virtual filesystems, and networking. The lightweight hypervisor-like interface provides isolation comparable to virtual machines without the overhead of bare-metal hardware virtualization. FTL merges the best of two worlds: microkernel flexibility and security with the performance and simplicity of monolithic kernels. It can run standard Linux binaries (including the Rust-based HTTP server hosting the FTL website itself) while also supporting unikernel-style apps that skip POSIX compliance entirely. From an operations perspective, the userspace OS model means developers can patch the OS, deploy security fixes, or extend functionality in the same workflow as writing application code — no kernel expertise or eBPF complexity required. This is a substantial departure from how container security has been managed historically.

C3Federal Judge Rules Flock License Plate Reader Network Is "Indiscriminate Mass Surveillance" — First Major US Ruling

📰 Article (English)

A federal judge in Tulsa, Oklahoma has ruled that searching Flock Safety's automated license plate reader (ALPR) database without a warrant violates the Fourth Amendment, characterizing the system as "indiscriminate mass surveillance." The ruling is one of the first federal judicial decisions declaring a Flock search unconstitutional. In the case, a sheriff's deputy ran a search of the Flock database using only California vehicle registration as justification, then used location history from that search to justify a vehicle search. Judge Sara Hill suppressed all evidence obtained downstream, concluding that the warrantless Flock query was itself an unreasonable search. Flock Safety operates a nationwide network of automated cameras that continuously capture vehicle data — license plates, location timestamps, and vehicle characteristics — from all passing vehicles. Law enforcement agencies subscribe to access this database on demand. The judge's ruling distinguished this from targeted surveillance of specific individuals: Flock "collects information about all vehicles" regardless of suspicion. While not binding precedent nationally, the ruling reflects growing legal pressure on passive mass surveillance tools. Multiple US states including Florida and Texas have moved to discontinue Flock, and US Senator Bernie Sanders introduced legislation to ban federal agencies from using such readers.
