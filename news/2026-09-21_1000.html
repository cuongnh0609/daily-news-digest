Kiến thức về AI-Driven Development được hệ thống hóa, bao gồm cả phương pháp đánh giá và debug agent.

C2Google Releases AX — Open Agentic Orchestrator Built to Run Billions of Concurrent Agent Tasks

📰 Article (English)

Google has publicly launched AX, an open-source agentic orchestration platform built on its internal Agent Substrate infrastructure. AX is designed to run billions of concurrent agent tasks per cluster, with sub-second suspension and resumption capabilities that allow fast context switching between workloads. The platform sandboxes agent code, manages workspaces with required dependencies, enforces fine-grained network policies, and handles model configuration through declarative primitives — all without requiring developers to re-implement this foundational infrastructure themselves. AX supports heterogeneous workloads across the agentic spectrum: short-lived interactive coding agents, long-running research servers, and evaluation loop pipelines can all share the same cluster. Google positions AX as abstracting away "the plumbing" so engineering teams can focus on agent behavior and task design rather than runtime management. The platform's design mirrors the architecture behind Google DeepMind's own research agent infrastructure, now made available to external developers.
