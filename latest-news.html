B1Claude CodeでCI待ち時間を18分→4分台に——Vitest分割・DBキャッシュ・node_modulesキャッシュの三段構え

📰 本文 + 和越対訳

Next.js / TypeScript プロジェクトのGitHub Actions CI が、テスト数増加とともに中央値15分まで膨らんでいた。エンジニアはまずClaude Codeで計測を行い、テスト実行そのものが全体の14%に過ぎないことを発見。残りの大部分は環境セットアップとDBマイグレーションに費やされていた。対策は三段構えだ。①Vitestのprojects機能で.tsテストはnode環境、.tsxはjsdom環境に分け、maxWorkers: 2を明示して並列化。②Postgres DBをマイグレーション後にpg_dumpでダンプし、マイグレーションファイルハッシュをキーにActionsキャッシュへ保存。PRブランチ間でキャッシュを共有するため、mainブランチで別途キャッシュ生成ワークフローを走らせた。③npm ciの代わりにnode_modulesディレクトリをキャッシュし、--ignore-scriptsで安全に復元。結果、中央値は4分45秒まで約69%短縮された。キャッシュ容量がGitHub上限10GBを超えたため、Dockerビルドキャッシュをmode=minに変更するなど後処理も行った。

CI GitHub Actions của một dự án Next.js/TypeScript đã phình lên đến trung vị 15 phút khi số lượng test tăng. C2NVIDIA Open-Sources OpenShell: Kernel-Level Sandboxed Runtime for Fleets of Autonomous AI Agents

📰 Article (English)

NVIDIA released OpenShell as an open-source (Apache-2.0) project on GitHub, providing a safe and private runtime for running autonomous AI agents in isolated sandboxes. Unlike container-based approaches that sandbox at the process level, OpenShell enforces restrictions at the kernel level, making each agent's access to the filesystem, network, and system calls subject to declarative policies you define before the agent runs. The core mechanism works through a gateway control plane plus a supervisor and sandbox processes. Agents can still read files, install packages, and call APIs — but only endpoints and paths your policy approves. Credentials are never exposed to the agent directly; OpenShell attaches them only to requests headed to approved destinations. When an agent attempts to reach a new host with credentials, the change is flagged for human review before the policy is updated. OpenShell runs locally on Linux, Apple Silicon macOS, or Windows via WSL 2, and on Kubernetes via Helm. SDKs are available for Python, TypeScript, Go, and Rust. The project ships with agent skills for popular coding agents to enable fast integration. This addresses a practical gap in agentic systems today: agents need broad system access to be useful, but granting it without controls creates unacceptable risk for production use.
