📰 本文 + 和越対訳

Văn bản vẫn đọc bình thường với con người nhưng có thể được xác định thống kê là do AI tạo ra bằng công cụ phát hiện chuyên dụng. 📰 Article (English)

GitHub has shipped Agent Plugins 1.0 into its full suite — VS Code, the Copilot CLI, and the Copilot web app — making the cross-client plugin standard generally available to all developers. The core promise: build a plugin once and it works across every compatible agent client, with no per-platform adaptation needed. Under the hood, each plugin packages one or more agent skills alongside MCP server configurations into a single installable unit. The standard is governed independently, meaning third-party tool authors can publish plugins that plug into any conforming host, not just GitHub's. Plugin authors define capabilities in a manifest, expose them through MCP, and end-users install with a single command. Early adopters shipping plugins at launch include database inspection tools, CI/CD status checkers, and code-search agents. For enterprises already invested in MCP infrastructure, this means existing MCP servers can be wrapped into portable plugins with minimal effort. The GitHub changelog notes that the specification is open and community-driven, with governance proposed to move to an independent standards body later this year.

C3GitHub Models Is Now Retired — What Developers Using the Unified LLM API Need to Know

📰 Article (English)

GitHub has shut down GitHub Models, the unified API platform that allowed developers to access multiple LLMs — including GPT, Claude, and Llama variants — through a single GitHub-authenticated endpoint. The service, which launched in late 2024 as a way to lower the barrier to LLM experimentation, is now retired with no stated successor. Simon Willison, who covered the retirement on his blog, noted that the closure likely reflects unsustainable token consumption patterns: developers used the free API tier heavily for exploration but conversion to paid Azure OpenAI usage was insufficient to justify continued investment. For developers who built internal tooling or prototypes against the GitHub Models API, migration is now required — the recommended path is moving to direct API access via the respective model providers (OpenAI, Anthropic, Meta AI). Any api.github.com/models endpoint calls in existing codebases will now return errors. The episode is a reminder that developer-facing "free tier" API services built on top of expensive inference have a structural funding problem, and dependency on such services warrants caution in production systems.

GitHub đã đóng cửa GitHub Models — nền tảng API thống nhất cho phép developer truy cập nhiều LLM (GPT, Claude, Llama...) qua một endpoint duy nhất với xác thực GitHub. Dịch vụ này, ra mắt vào cuối 2024 nhằm giảm rào cản thử nghiệm LLM, hiện đã bị khai thác mà không có người kế nhiệm được công bố. Simon Willison nhận xét rằng việc đóng cửa này nhiều khả năng phản ánh mô hình tiêu thụ token không bền vững: developer dùng tier miễn phí nhiều cho khám phá nhưng tỷ lệ chuyển đổi sang Azure OpenAI trả phí không đủ để tiếp tục đầu tư. Với developer đã xây dựng tooling nội bộ hoặc prototype dựa trên GitHub Models API, migration là bắt buộc — con đường được khuyến nghị là chuyển sang truy cập API trực tiếp từ nhà cung cấp model tương ứng (OpenAI, Anthropic, Meta AI).
