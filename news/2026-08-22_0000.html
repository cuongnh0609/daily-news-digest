CureAppエンジニアによるZennの記事が、Claude Codeの自動メモリ機能の仕組みと問題点を詳細に解説し、注目を集めている。Claudeのメモリはプロジェクト単位で保存され、セッション開始時にはまずMEMORY.mdという目次ファイルの先頭200行（最大25KB）だけが読み込まれ、関連するトピックファイルはAIが必要と判断したタイミングでのみ参照される仕組みだ。著者が指摘する最大の問題は「嘘が混ざる」こと。クローズ済みのPull RequestやIssueに関するメモが残ったまま放置されると、実態と乖離した前提でシステムが動作し続けてしまう。公式のconsolidate-memoryコマンドでは対応しきれない「検証ベースの整理」を行うカスタムスキルを開発し、PR・Issue番号を実際に確認しながら段階的に合意を取りつつ、削除ではなくアーカイブ退避で可逆的にメモリを整理する手法を紹介している。月1回程度の定期的な棚卸しが推奨されている。

Docker has launched the public beta of Docker VMM (Virtual Machine Monitor), a new hypervisor it built in-house specifically optimized for container workloads. Docker has stated that Docker VMM will replace the current default engine by October 2026 following the public beta period.
