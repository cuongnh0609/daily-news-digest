A1相次ぐ情報漏えいの一因「A2B攻撃」——公開アプリを解析してバックエンドを狙う手口、NICTが公表

📰 本文 + 和越対訳

情報通信研究機構（NICT）と傘下の脅威分析チーム「LETTICE」は10月13日、国内で相次ぐ個人情報漏えい事件の背景に「A2B攻撃（App-to-Backend Attack）」と呼ばれる手口が存在することを明らかにした。この攻撃は、一般公開されているAndroidアプリを逆コンパイルして通信先サーバーとAPIの構造を解析し、バックエンドに直接仕掛けるものだ。アプリ本体のセキュリティが確保されていても、サーバー側の認証・アクセス制御・入力検証が不十分であれば不正アクセスが成立し、大量の個人情報が持ち出されるリスクがある。NICTは対策として、公開APIとサーバーの棚卸し・アクセスログ監視の実施、IDORやSSRF・SQLインジェクションなどの脆弱性テストの優先実施、不要APIの無効化と認証情報の再発行を推奨した。なおiOSアプリやWebサービスにも同様のリスクが潜むとして、幅広い事業者に注意喚起している。

Viện Nghiên cứu Thông tin và Truyền thông Nhật Bản (NICT) cùng nhóm phân tích mối đe dọa LETTICE hôm 13/10 công bố phát hiện một kỹ thuật tấn công mới tên "A2B攻撃" (App-to-Backend Attack) đứng sau nhiều vụ rò rỉ dữ liệu cá nhân tại Nhật Bản gần đây. Kẻ tấn công decompile ứng dụng Android công khai để phân tích cấu trúc API và máy chủ phía sau, từ đó tấn công trực tiếp vào backend mà không cần qua giao diện ứng dụng. Ngay cả khi bản thân ứng dụng được bảo mật tốt, nếu phía server thiếu kiểm soát xác thực và phân quyền thì dữ liệu vẫn có thể bị đánh cắp với số lượng lớn. NICT khuyến nghị doanh nghiệp cần kiểm kê toàn bộ API công khai, ưu tiên kiểm thử IDOR, SSRF, SQL injection, đồng thời vô hiệu hóa các API không cần thiết và cấp lại thông tin xác thực.

国際通貨基金（IMF）は10月12日に公表した世界経済見通しの最新版で、日本の名目GDPが2027年に世界第6位に後退するとの予測を示した。これはインドと英国の両国に抜かれることを意味し、4月時点の予測では英国が2029年に日本を上回るとされていたが、その時期が大幅に前倒しになった。円安基調の継続と国内経済成長の鈍化が、ドル換算のGDP順位を押し下げる主要因として挙げられている。今回の予測によれば、2027年時点での上位はアメリカ、中国、ドイツ、インド、英国の順となり、日本は5位の英国にも追い抜かれる形となる。政府や経済界は名目GDPの順位よりも実質成長率の回復を重視する立場を示しているものの、国際的な経済力の低下は対外交渉力にも影響するとの懸念が出ている。

B1AIエージェントのインシデント対応モードを設計する——初動・判断・操作の分け方

📰 本文 + 和越対訳

Zennに掲載されたエンジニアの実践記事では、テクニカルサポート用AIエージェントにインシデント対応専用モードを組み込む際の設計方針が詳しく解説されている。著者は「初動・判断・操作」の3フェーズに分けて設計することを提案する。初動フェーズでは、根本原因の特定より先に「現在も影響が継続しているか」「何が判明しているか」「次に取れる対応は何か」の3点を返すことを優先する。判断フェーズでは「この情報を読むことで意思決定が変わるか」という基準で証拠を選別し、最初に見つかったエラーを直接の原因として断定しないように設計する。操作フェーズでは、緊急対応モード中でも権限を広げず、既存の承認フローを維持し、操作対象と現在の状態を確認してからアクションを実行するよう設計している。完了の定義は処理成功ではなく「元の問題が回復したか」で判断する点が特徴的だ。

Một bài viết thực hành trên Zenn mô tả chi tiết cách thiết kế chế độ ứng phó sự cố (incident response mode) cho AI agent hỗ trợ kỹ thuật, chia thành 3 giai đoạn: khởi động, phán đoán, và thao tác. Ở giai đoạn khởi động, thay vì tìm nguyên nhân gốc rễ ngay, agent ưu tiên trả lời 3 câu hỏi: sự cố có còn đang ảnh hưởng không, đã biết được gì, và bước tiếp theo có thể làm gì. C1Janas: Run LLMs Larger Than Your RAM by Streaming Weights from NVMe SSD

📰 Article (English)

Janas is an experimental C-based AI toolset with zero external dependencies, designed to run large mixture-of-experts (MoE) language models on ordinary consumer hardware by streaming expert weights from NVMe SSD storage rather than requiring the full model to fit in RAM. The flagship component, Janas-LLM, converts models into a custom .jns format and supports Qwen3, Qwen3.5, Qwen3.6, Qwen3-Next, and Gemma 4 families — including massive models like Qwen3-Next-80B-A3B and Gemma-4-26B-A4B. Only the active experts for each token are loaded from disk, keeping memory pressure low while maintaining reasonable inference throughput. Key engineering features include speculative drafting for faster generation, an OpenAI-compatible HTTP API server, MCP protocol support, and builds targeting Linux and Windows x86-64. The project attracted 195+ Hacker News upvotes on its first day and sparked significant discussion around the practical floor for running frontier-class models without a GPU. The author explicitly calls this "an experiment, not a product," but the architecture demonstrates a compelling path for local LLM deployment on budget hardware.
