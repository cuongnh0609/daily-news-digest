C1Azure's Weakest Link — Five Full Cross-Tenant Privilege Escalation Vulnerabilities Disclosed

📰 Article (English)

Security researcher Haakon Wik Gulbrandsrud from Binary Security disclosed five critical privilege escalation vulnerabilities in Azure Logic Apps' API Connections, earning approximately $200,000 in bug bounties. All five allowed an attacker to use another tenant's API Connection — essentially impersonating any linked backend service, including Key Vaults and Azure SQL databases belonging to completely different Azure customers. The root cause is how Azure routes API Connection calls: all traffic passes through a shared Azure API Management (APIM) layer that swaps the caller's token for the backend's configured secret. The ARM (Azure Resource Manager) API could reach that APIM layer directly, meaning a crafted request could trick the platform into using someone else's connection token. The researcher found that Microsoft's initial fixes were insufficient: a path-traversal blacklist only covered DynamicInvoke, leaving four sibling endpoints unpatched. A subsequent URL validation fix was bypassed via path normalization before the validation ran. Each patch opened a new vector. All five issues are now fully fixed following coordinated disclosure. The researcher notes that scoping API connection tokens — which few customers do — would have limited the blast radius of each vulnerability.

🔴 HIGH IMPACT All Azure Logic Apps using API Connections may have been exposed to cross-tenant data access; audit your Logic Apps and verify API connection token scoping.

The first pattern is memory consolidation — a nightly cron that summarizes past conversations into long-term memory, analogous to how humans dream and consolidate memories. The second is goal-driven proactivity: an agent with a defined objective wakes hourly, checks progress, and takes the next step.
