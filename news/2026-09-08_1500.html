B1Claude Codeのサブエージェントとエージェントチームで並列処理——第9回社内勉強会が資料公開

Kỹ sư của Cybersecurity Cloud đã công bố tài liệu buổi học nội bộ thứ 9 về Claude Code, tập trung vào chủ đề subagent và Agent Team cho xử lý song song. Tính năng Agent Team — nhiều subagent phối hợp — vẫn đang thử nghiệm và cần kích hoạt qua biến môi trường. Việc xử lý song song đa agent giúp tiết kiệm context và tăng tốc độ, đặc biệt hữu ích cho codebase lớn và phát triển enterprise.

自律型AIエージェントがコードを実行する際のサンドボックス環境について、主要4方式を比較した実践的なガイドが公開された。標準的なDockerコンテナはLLMが生成したコードの実行環境として根本的に不適切だとされており、カーネル特権昇格・コールドスタートの状態ドリフト・制限なしネットワークアクセスによるSSRF攻撃の3点が主な脆弱性として挙げられている。 比較対象は4方式：Firecrackerマイクロ仮想機械を使う「E2B」（起動時間120〜180ms、双方向ファイル同期）、GPU対応サーバーレスの「Modal Labs」（コールドスタート600〜1200ms）、自己ホスト型の「Docker + gVisor」（オンプレミスデータ保護要件に適合）、そしてブラウザ内で動く「WebContainers」（インフラコストゼロだがJS/WASMのみ）だ。インタラクティブな対話型コーディングアシスタントにはE2Bが最適とされ、GPU処理が必要なバッチ処理にはModalが向くとまとめられている。

C1How Well Do AI Agents Actually Use Testing Techniques? — Dan Luu's 80-Run Study Finds Worse Results When Prompted to Use Formal Methods

📰 Article (English)

Software engineer Dan Luu published a rigorous empirical study examining whether AI agents (Claude and GPT models) can effectively use testing and verification techniques when explicitly instructed to do so. The experiment ran 80+ trials per condition across a Zstd implementation task, testing 26 different prompt configurations spanning formal methods (Verus, Lean 4, TLA+), property-based testing frameworks (QuickCheck, Proptest), fuzzing approaches, and traditional unit testing. The counterintuitive finding: giving agents specific testing instructions generally produced worse results than providing no testing guidance at all. The default "no special instructions" condition performed "well above average." When prompted to use sophisticated techniques, agents typically either wrote conventional unit tests inside unfamiliar frameworks or applied the technique superficially without capturing its intended benefit. Even when agents correctly identified risky code regions, they consistently failed to write effective tests targeting those areas. Luu argues this represents a significant capability gap: AI agents lack effective testing instincts "by default" and cannot absorb testing methodology through passive prompting. His recommendation is that AI labs should develop reinforcement learning training environments specifically for testing skills — similar to how coding capabilities were developed — rather than expecting agents to generalize from a text description of a testing approach.
