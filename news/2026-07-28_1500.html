AWS launched CloudFormation Express Mode, a new execution mode that dramatically accelerates infrastructure deployment by skipping the wait for resources to fully stabilize before marking a stack operation as complete. Unlike standard CloudFormation which waits for every resource to reach a steady state, Express Mode applies the configuration changes and returns control immediately, trusting that eventual consistency will follow. Nếu bạn dùng CloudFormation cho dev/test: hãy thử Express Mode ngay — 4× nhanh hơn thực sự giảm "chờ IaC" trong các vòng lặp phát triển. Với AI agent tự động sinh IaC, đây là enabler quan trọng để agent có thể iterate nhanh hơn.
