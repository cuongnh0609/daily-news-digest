AI ShiftのエンジニアがZennにて、AIエージェント開発における実行履歴の収集・可視化を担うトレーシング基盤の構築について詳しく解説した。同チームが開発するAI Worker Platformでは、複数のクライアント向けカスタムエージェントをForward Deployed Engineer（FDE）が構築しており、計測コードを後回しにする傾向があった。この課題に対し、2層構造のトレーシング設計を導入している。第1層はLLM GatewayであるAgent Router（旧Envoy AI Gateway）によるOpenTelemetry自動計測で、全LLM呼び出しのinput/output・モデル名・トークン数を自動取得する。第2層はカスタムのTracing SDK（Pythonはais_tracing、TypeScriptは@ais/tracing）によるビジネスメタデータ付加で、ユーザーIDやセッションID、各LLM呼び出しの目的を記録する。Langfuseを可視化ダッシュボードとして採用し、FAQエージェントのLLM-as-a-Judge評価をデモとして示している。SDKによる計装を忘れた場合でもGateway層がLLM呼び出しを保全するという設計が、本番運用を支える重要な安全網となっている。

Kỹ sư từ AI Shift đã giải thích chi tiết trên Zenn về việc xây dựng nền tảng tracing thu thập và trực quan hóa lịch sử thực thi trong phát triển AI agent. Trên AI Worker Platform mà nhóm phát triển, các Forward Deployed Engineer (FDE) xây dựng agent tùy chỉnh cho nhiều khách hàng, và có xu hướng trì hoãn việc thêm code đo lường. Để giải quyết thách thức này, họ đã triển khai thiết kế tracing hai tầng. Tầng 1 là đo lường tự động OpenTelemetry thông qua LLM Gateway (Agent Router — trước đây là Envoy AI Gateway), tự động thu thập input/output, tên model và số token của tất cả lời gọi LLM. Tầng 2 là bổ sung metadata nghiệp vụ thông qua Tracing SDK tùy chỉnh, ghi lại user ID, session ID và mục đích của từng lời gọi LLM. Langfuse được sử dụng làm dashboard trực quan hóa, với demo đánh giá LLM-as-a-Judge cho FAQ agent. Thiết kế mà ngay cả khi quên đo lường bằng SDK thì tầng Gateway vẫn bảo toàn lời gọi LLM là mạng an toàn quan trọng cho vận hành production.

📰 Article (English)

A widely-reported GitHub issue (postmanlabs/postman-app-support#14370) revealed that recent versions of Postman have been silently auto-installing AI-related plugins and, in some configurations, attempting to transmit API request and response data to third-party AI services — without explicit user consent. Developers discovered this behavior while reviewing network traffic, finding that the application was making outbound connections to AI provider endpoints during normal API testing workflows. The issue received over 600 upvotes on Hacker News within hours of surfacing. According to affected users, the data transmitted included full request bodies, headers, and occasionally authentication tokens embedded in requests. Postman acknowledged some of the concerns via a comment on the GitHub issue but has not yet issued a formal statement addressing the scope of data sharing. The company's AI features are opt-in by design according to their documentation, but users report the auto-install behavior bypasses this opt-in mechanism. For teams that use Postman to test production APIs, internal services, or APIs with sensitive credentials, this represents a significant security and compliance risk. Many security teams are recommending downgrading to an earlier Postman version or switching to alternatives like Bruno, Insomnia, or HTTPie while the situation is investigated.

📰 Article (English)

Simon Willison documented a remarkable finding on November 3: Qwen 3.8 27B, an open-weight model that runs locally on a MacBook Pro, can successfully perform "weight interpretation" tasks — examining raw neural network weight tensors and describing what the underlying network does, inferring its architecture, and identifying patterns in the parameter space. This confirms that the ability to read and reason about neural network weights is not exclusive to frontier models like GPT-6 Astra, and extends to capable open-weight models running on consumer hardware. Willison ran several experiments including feeding the model small MNIST-class network weights and asking it to describe the classifier structure, as well as larger MLP weights from game environments. The model correctly identified activation functions, inferred layer structure, and described the likely training regime in several cases — all from raw weight tensors without executing the network. While the results are not as reliable as the original GPT-6 Astra experiments, their accessibility changes the narrative: weight-space programming and neural network introspection may become standard capabilities available to researchers without access to frontier-class compute. This has implications for model interpretability, model editing workflows, and potentially for novel approaches to neural architecture search.
