📰 本文 + 和越対訳

化粧品ブランド「SHIRO（シロ）」を展開する企業が、2028年度の新卒採用から「インターバル採用」を導入すると発表した。この制度では、内定者は大学・大学院を卒業してから2年以内の期間で入社時期を自由に選択できる。日本では通常、新卒者が卒業翌月の4月に一斉入社するのが慣行だが、インターバル採用はそれを抜本的に変えるものだ。制度を考案した社長は、卒業後に旅や学び、ボランティアなどで「間」を持つことが本人の成長と企業への貢献につながると考えている。近年、若者の多様なキャリア観が広まる中、硬直した一括採用に疑問を呈する企業が増えており、今回の取り組みはその流れを先取りする形となった。採用業界でも注目を集めており、他企業への波及が期待されている。

Công ty mỹ phẩm SHIRO thông báo sẽ áp dụng chương trình "tuyển dụng khoảng cách" (interval adoption) từ năm 2028. Theo đó, ứng viên nhận được thư mời làm việc có thể tự chọn thời điểm nhập việc trong vòng 2 năm sau tốt nghiệp, thay vì phải vào làm tháng 4 theo thông lệ tuyển dụng đại trà của Nhật Bản. C3Simon Willison: "If in Doubt, Delete the uv.lock File" — The Fastest Fix for Broken Python Environments

📰 Article (English)

Simon Willison, creator of Django and Datasette, published a concise but widely-shared guide arguing that the fastest resolution for a broken uv Python environment is to simply delete the uv.lock file and let uv sync or uv pip install regenerate it from scratch. The core observation is that lock files accumulate stale constraints — dependency version pins that made sense at a point in time but create conflicts after any upstream package update. When a dependency graph becomes unsolvable, the lock file itself is the bottleneck, not the packages. Willison notes that uv, the Rust-powered Python package manager developed by Astral, resolves dependency graphs dramatically faster than pip or Poetry, so the cost of a full re-solve is negligible (sub-second on most projects). He recommends treating uv.lock as a disposable artifact rather than a precious configuration file, committing it to source control only to ensure reproducible CI builds — and regenerating it without hesitation whenever environment issues arise. The post has sparked broader discussion about the philosophy of lock files in modern Python toolchains and whether they are worth the friction they introduce.
