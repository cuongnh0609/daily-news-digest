B2「検査は走っていた。それでもpushされた」——Claude Code 3か月の実記録とSAP移送ゲートに学ぶ機械的制御

📰 本文 + 和越対訳

Claude Codeにタスクを委譲し続けた約3か月間（2026年8月〜11月）の 実記録をまとめた記事が注目を集めている。12件の委譲のうち手順書を 最後まで読み切ったのはわずか2件に過ぎず、「検査は走っていたのにpushされた」 失敗が4段階に分類された：手順の欠落、渡されても読まれない、読んでも適用されない、 そして「チェックは走ったが結果がpushを止めなかった」というケースだ。 最も効果的だった対策は、関連するメモを委譲プロンプトに直接貼り付けることと、 pre-pushゲートやsyncスクリプトによる機械的な制止だった。筆者はこれを SAP ABAPの移送ゲート（ATC Transport Gate）に例え、「表示するだけでは止まらない、 制止するゲートが必要」という設計原則を主張している。

Một bài viết tổng kết 3 tháng thực tế ủy thác tác vụ cho Claude Code đang thu hút nhiều chú ý. Trong 12 lần ủy thác, chỉ 2 lần agent đọc hết tài liệu hướng dẫn, và các lần thất bại được phân loại thành 4 cấp: thiếu hướng dẫn, có nhưng không đọc, đọc nhưng không áp dụng, và chạy kiểm tra nhưng kết quả không ngăn được việc push. You specify a PR URL and the event types you care about — submitted reviews, PR state changes (merge, close, open), head SHA updates, merge conflicts, or completed check suites — and the command exits as soon as the event fires.
