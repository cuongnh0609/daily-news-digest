B-01Pull Requestの58%をAIが承認——SHEが「人間不要レビュー」の判定基準を設計・公開

📰 本文 + 和越対訳

女性向けキャリアスクールを運営するSHE株式会社が、開発フローにおいてPull Requestの約58%をAIが自動承認する仕組みを構築したことを公開した。同社はまず過去75件のPRを分析し、約60%が実質的なフィードバックなく承認されていたという事実を確認。その上で「AIの技術評価（approve/pending/needs-fix）」と「人間レビューの必要性（required/optional）」の2軸でPRを分類するシステムを設計した。AIが承認かつ人間レビューが任意と判定したPRのみが自動承認対象となる。人間の確認が必須となる8カテゴリとして、金融トランザクション、不可逆操作、セキュリティ変更、個人データフロー、外部契約、アーキテクチャ変更、高リスク計算、ランタイム上のハザードを定義した。この仕組みにより、開発者が本当に重要なレビューに集中できる環境を実現した。

Công ty SHE đã công bố hệ thống tự động approve khoảng 58% Pull Request bằng AI trong quy trình phát triển. Sau khi phân tích 75 PR trước đó và nhận ra 60% trong số đó được approve mà không có phản hồi thực chất, họ thiết kế hệ thống 2 trục: đánh giá kỹ thuật của AI và mức độ cần thiết của review từ người. Chỉ những PR được AI approve và đánh giá là không cần human review mới được tự động approve. Tám danh mục bắt buộc có human review bao gồm: giao dịch tài chính, thao tác không thể hoàn tác, thay đổi bảo mật, luồng dữ liệu cá nhân, hợp đồng bên ngoài, thay đổi kiến trúc, tính toán rủi ro cao và các mối nguy hiểm trên runtime. Enterprise owners configure approval policies using two new keys in their managed settings: allowedMcpServers and deniedMcpServers. Each server can be identified by remote URL (with wildcard support), local command specification, or user-assigned name. The system applies a "fail closed" security posture: any malformed or unverifiable configuration entry gets blocked rather than allowed through. The feature currently integrates with GitHub Copilot app, Copilot CLI, and VS Code. Configuration is managed through copilot/managed-settings.json in the organization's .github-private repository. This makes MCP server governance version-controlled and auditable — a key requirement for security and compliance teams. The announcement signals GitHub's intent to position Copilot as an enterprise-safe agentic platform, addressing a critical gap: as MCP ecosystems grow, uncontrolled server execution is a significant attack surface.
