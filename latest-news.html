C1Amazon Saves Millions Annually by Replacing Claude Sonnet 4.6 with Strands Decider in Agent Workflows

📰 Article (English)

Amazon has revealed that it achieved multi-million dollar annual cost savings by substituting a specialized lightweight model — Strands Decider — for Claude Sonnet 4.6 in the tool-selection phase of its production AI agent workflows. The architectural insight driving this optimization is a separation of concerns between decision intelligence and reasoning intelligence. Strands Decider handles only the routing decision: given the agent's current state and available tools, which tool should be invoked next? This is a comparatively narrow classification problem. The actual reasoning, language generation, and complex multi-step analysis remain with high-capability frontier models. Because tool-routing decisions happen at every step of an agent loop, and because agentic workloads can run thousands of iterations per hour in production, even a modest per-token cost difference compounds quickly into substantial savings. The post from Strands Agents reports that this pattern is now embedded in the Strands SDK's default agent architecture. Engineers building production agents should evaluate whether a decision-only model can handle the routing layer of their own agent loops, as the technique is applicable across any framework that supports tool use.
