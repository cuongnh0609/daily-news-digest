📰 本文 + 和越対訳

Rustで書かれたコードの中にC言語のコードをそのまま埋め込んで呼び出せるライブラリが個人開発者によって公開され、Zennのトレンドで注目を集めている。通常、RustからCのコードを利用するにはFFI（外部関数インターフェース）の設定や`unsafe`ブロックの記述が必要で、手間がかかる作業だった。しかしこのライブラリを使うと、Rustのソースファイル内にCのコードブロックを記述するだけで、コンパイル時に自動的にバインディングが生成され、RustからシームレスにC関数を呼び出せるようになる。 実装にはプロシージャルマクロが活用されており、マクロ展開時にCコードを一時ファイルとしてコンパイルしてバインディングを自動生成するという巧妙な仕組みになっている。組み込みシステムやレガシーCライブラリとのインテグレーションを必要とするプロジェクトで特に有用と考えられており、アイデアの斬新さと実装の完成度の高さが評価されている。

Thông thường, để sử dụng code C từ Rust cần phải cấu hình FFI (Foreign Function Interface) và viết các khối `unsafe`, khá phức tạp. Với thư viện này, chỉ cần khai báo một khối code C trong file Rust là đủ — tại compile time, binding sẽ được tự động sinh ra. Cơ chế hoạt động dựa trên procedural macro: khi macro được expand, code C được compile thành file tạm và binding được tạo tự động. Đây đặc biệt hữu ích cho các dự án embedded system hoặc tích hợp với thư viện C legacy.

C2Cloudflare Python Workers Now Generally Available — Python Becomes a First-Class Language on the Edge via WebAssembly + Pyodide

📰 Article (English)

After a two-year preview period, Cloudflare has officially released Python Workers as a fully supported, generally available feature on its serverless edge platform. The announcement explicitly positions Python as a "first-class language" alongside JavaScript and TypeScript within the Cloudflare Developer Platform. The technical architecture is architecturally novel: Python code is compiled to WebAssembly through Pyodide, then executed within Cloudflare's V8-based workerd runtime. This approach delivers Python execution at the edge with the performance and isolation characteristics that Cloudflare's infrastructure is built on, without maintaining a separate Python runtime. For local development, Cloudflare ships pywrangler (published as workers-py on PyPI), which provides full-stack simulation by running Pyodide-compiled Python inside WebAssembly on V8 within a 123MB workerd binary — giving developers an authentic local testing environment that mirrors production behavior. Important limitations to be aware of: the WebAssembly execution model means that Python's multiprocessing and threading modules are non-functional. Developers working with CPU-bound parallel workloads or thread-based concurrency patterns will need to adapt their architecture for the edge environment. The move was enabled through deep collaboration with Gyeongjae Choi and Hood Chatham, both Pyodide core maintainers.
