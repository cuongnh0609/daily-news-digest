AWSのエンジニアが、2026年8月に一般提供（GA）を開始したAWS Agent Registryと、AIコーディングツールのKiro for Enterpriseを組み合わせた、企業向けMCPサーバーガバナンスのアーキテクチャを公開した。Agent Registryは承認済みのMCPサーバーやAIエージェント、スキルを一元管理するカタログで、未承認のMCPが組織内で野良で使われる問題を根本から防ぐ。承認フロー完了時にAmazon EventBridgeがイベントを発行し、Lambdaがリスト化して自動でCloudTrailに監査ログを残す設計だ。Kiro for EnterpriseはKiroクライアントへのアローリストを強制することで、未承認ツールの接続をブロックする。両者を組み合わせることで、ガバナンス（Registry）と強制（Kiro）を分離した多層防御が実現できる点が解説されている。

C3Slotstream: Run a 104GB Mixture-of-Experts LLM on a 48GB Mac via Expert Offloading from SSD

📰 Article (English)

Slotstream is an open-source Swift application that enables running Qwen3.8-Flash-Next — a 125-billion parameter mixture-of-experts model stored as 104 GB on disk — on Apple Silicon Macs with as little as 8 GB of RAM. The core insight is that MoE architectures only activate a small fraction of experts per token, so the system keeps only the 3.8 GB dense trunk resident in RAM while streaming the 68 GB of routed expert weights on-demand from SSD using low-level pread calls. A fixed pool of cache slots is shared across all 48 layers, with hot layers dynamically borrowing slots from cold ones. On a 48 GB M5 Pro, this yields approximately 12 tokens per second during decode with only 32 GB peak RAM usage. An 8 GB machine achieves roughly 3 tokens per second, and 24 GB reaches 8 tokens per second. Startup takes about 2 seconds, and the system produces byte-identical output regardless of cache size. The project demonstrates a practical path to running frontier-class open-weight models locally without expensive hardware.
