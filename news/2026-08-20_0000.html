B-01Claude Codeに「見せない」技術——機密データを5層防御でAIから隔離する実践アーキテクチャ

📰 本文 + 和越対訳

Claude Codeなどの AIコーディングツールを業務で活用する際、最大の課題のひとつが個人情報や顧客データといった機密情報の取り扱いだ。ある開発者はこの問題に対し、「そもそもAIに読ませない」という事前遮断を基本方針とした5層の防御アーキテクチャを構築・公開した。L0では機密データを~/datasets/に一元管理してAIが触れる領域と物理的に分離し、L1ではsettings.jsonのdenyルールでファイル読み取りを宣言的にブロックする。L2はOSレベルのsandboxで間接的なアクセスを遮断し、L3ではhookを使い実行前にスクリプトで設定の整合性を検証する。最上位のL4は人間の運用ポリシーで、機密データを含む実行処理はAIに任せず人間が担当する分担設計だ。この方式では.envでダミーデータと実データを切り替え、AIにコード生成・自己修正させたうえで人間が実データで実行するワークフローを実現している。16項目のすり抜けテストとCI統合により、防御の有効性を継続的に監視できる点も大きな特徴だ。

Người dùng macOS đang dùng Docker VMM preview sẽ nhận cập nhật tự động. Người dùng Windows có thể chuyển thủ công qua cài đặt Docker Desktop. Docker đặt mục tiêu tháng 10/2026 để Docker VMM trở thành engine ảo hóa mặc định trên Windows, Mac và Linux. Bản phát hành này cho thấy Docker đang đặt cược vào ảo hóa tùy chỉnh như chiến lược phân biệt sản phẩm desktop với các lựa chọn thay thế như Rancher Desktop và Podman Desktop.
Nếu bạn dùng Docker Desktop cho dev workflow hàng ngày trên macOS hoặc Windows, hãy thử bật Docker VMM ngay trong beta — I/O nhanh hơn sẽ giúp chu trình build-test nhanh lên đáng kể, đặc biệt với project có nhiều volume mount.
