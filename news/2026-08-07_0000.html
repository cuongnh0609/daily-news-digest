B1マイクロソフト「Windows Performance Analyzer MCP」発表——AIがトレースログからパフォーマンス問題を自律診断

📰 本文 + 和越対訳

マイクロソフトは8月6日、Windows向けパフォーマンス分析ツール「Windows Performance Analyzer MCP（WPA MCP）」のプレビュー版を公開した。従来のWPAはCPU処理、ファイルI/O、ネットワーク入出力などのボトルネックを分析できるものの、使いこなすには相応の専門知識が必要だった。WPA MCPはこれにGitHub Copilot CLIを統合し、開発者が自然言語で「アプリがハングする原因は何か」「どこでCPUが枯渇しているか」といった質問を投げかけるだけで、AIがトレースデータを解析して回答・レポートを生成する仕組みだ。AIはハングアップ、入力遅延、長い待ち時間、CPUやディスクのボトルネックを優先的に調査し、問題箇所の特定と解決策の提示までを自律的に行う。これにより、パフォーマンス診断の専門知識がない開発者でも、複雑なトレースファイルを活用できるようになる。MCPツールとしての実装により、Claude CodeやCursorなど他のAIコーディングアシスタントとの連携も期待される。

Microsoft ngày 6/8 công bố preview của "Windows Performance Analyzer MCP (WPA MCP)" — công cụ phân tích hiệu năng Windows tích hợp AI. Công cụ WPA truyền thống có thể phân tích các bottleneck về CPU, file I/O, network nhưng đòi hỏi kiến thức chuyên sâu. WPA MCP tích hợp GitHub Copilot CLI để cho phép developer hỏi bằng ngôn ngữ tự nhiên như "tại sao app bị hang?" hay "CPU bị kiệt ở đâu?" và AI sẽ tự phân tích trace data rồi đưa ra báo cáo. AI ưu tiên điều tra các vấn đề như hang, input lag, thời gian chờ kéo dài, bottleneck CPU và disk. Nhờ implement theo chuẩn MCP, công cụ này có thể tích hợp với Claude Code, Cursor và các AI coding assistant khác.

Deno has released Celld, an open-source daemon that allows developers to run Cloudflare Workers and Durable Objects on their own infrastructure rather than relying on Cloudflare's proprietary cloud. Each cell — Celld's name for a Durable Object — functions as its own SQLite database that is addressed by a unique name and automatically replicated to any S3-compatible object storage bucket. The architecture is deliberately centerless: nodes coordinate with each other exclusively through the shared object storage, with no central control plane to manage or fail. For teams invested in the Cloudflare Workers programming model — which has become popular for edge functions and AI inference endpoints — Celld offers a vendor-neutral path to run the same code on self-hosted or cloud infrastructure. This is particularly relevant as teams building AI agent backends increasingly want to avoid vendor lock-in while retaining the simplicity of the Workers API.
