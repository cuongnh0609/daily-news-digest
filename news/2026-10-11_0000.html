📰 本文 + 和越対訳

Microsoftは2026年9月30日リリースのVisual Studio Code 1.140にて、「HydraFusion」と名付けたAIオーケストレーションの研究プレビューを公開した。従来のCopilot「Autoモード」が1つのタスクに対して最適な1モデルを選択するのと異なり、HydraFusionは同一タスク内で複数の異なるAIモデルを組み合わせて動作させる仕組みだ。タスクの内容に応じて推論・コード生成・デバッグ・ツール利用などの能力シグナルを評価し、3つの実行パターンを使い分ける。「Single」は1モデルで解決、「Cascade」は効率重視モデルが下書き後に検証モデルが精査してエスカレーションを判断、「Critique」は異なるモデルファミリーのモデルが互いにレビューして品質を向上させる。CopilotのPro/Pro+/Business/Enterpriseユーザーが利用可能で、Businessと Enterpriseはアドミンによるプレビュー機能の有効化が必要となる。

Microsoft đã công bố preview nghiên cứu về orchestration AI mang tên "HydraFusion" trong Visual Studio Code 1.140 phát hành ngày 30/9/2026. Khác với "Auto mode" hiện tại của Copilot — chọn một model tối ưu cho mỗi task — HydraFusion phối hợp nhiều model AI khác nhau trong cùng một task. Hệ thống đánh giá các tín hiệu năng lực như suy luận, sinh code, debug, và sử dụng tool để chọn một trong 3 pattern thực thi. "Single" dùng 1 model; "Cascade" dùng model hiệu quả để phác thảo rồi model xác minh kiểm tra và quyết định escalate; "Critique" dùng hai model từ các gia đình khác nhau để review lẫn nhau. Tính năng này khả dụng với người dùng Copilot Pro/Pro+/Business/Enterprise, với Business và Enterprise cần admin bật tính năng preview.

C-02Microsoft Execution Containers (MXC) 1.0 Generally Available — Policy-Driven Containment for AI Agents

📰 Article (English)

Microsoft has released Microsoft Execution Containers (MXC) 1.0 as generally available, providing a policy-driven execution layer that enforces boundaries on what AI agents can access and do. Unlike traditional container solutions, MXC places access policies outside the agent's control so that the agent — or any code it generates — cannot expand its own permissions. MXC supports four containment backends: process containers (AppContainer, Seatbelt, Bubblewrap across Windows, macOS, and Linux), session containers (Windows 11, isolated OS session with separate desktop and clipboard), WSL containers (Linux environments on Windows), and experimental MicroVMs (hardware-backed isolation). A unified JSON-schema configuration and multi-language SDK let developers define one policy that MXC maps to the appropriate backend. Three operating modes assist authoring: Enforcement (strict), Learning (blocks but logs), and Permissive (allows but logs). Intune will soon let IT admins govern container creation. Frameworks already integrating MXC include GitHub Copilot, OpenAI Codex, Replit, and LM Studio, with Claude Code support coming. NVIDIA has also integrated its OpenShell into MXC.
