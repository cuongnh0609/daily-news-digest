B1RTX 5090でFreeTokenを試す——35B未満は不要、120B超のMoEモデルでは話が変わる

📰 本文 + 和越対訳

FreeTokenは、巨大なMixture-of-Experts（MoE）モデルの推論を消費者向けGPUで実現するために設計されたエンジンで、エキスパートウェイトをVRAMではなくホストRAMに退避させることで、VRAMの制約を超えた大規模モデルの動作を可能にする。 RTX 5090を用いた検証では、VRAMに収まる35BクラスのモデルについてはvLLMやllama.cppと比較してスループットが劣るため導入メリットが薄いことが判明した。 一方、VRAMに載せ切れない120BクラスのMoEモデル（gpt-oss）では、FreeTokenが「65GBモデルで127.1 tok/s」という実用的な速度を達成し、通常は諦めるしかなかった超大型モデルの手元推論が現実的な選択肢になることが示された。 筆者は「FreeTokenの価値は汎用的な高速化ではなく、GPUのVRAM上限を超えたモデルを動かせるという一点にある」と結論づけており、ローカルLLM研究者にとって重要な選択肢が増えたと言える。

FreeToken là engine suy luận được thiết kế để chạy các mô hình Mixture-of-Experts (MoE) khổng lồ trên GPU tiêu dùng bằng cách lưu trữ các expert weight vào RAM thay vì VRAM. Kiểm tra trên RTX 5090 cho thấy với các mô hình 35B vừa khít VRAM, FreeToken chậm hơn vLLM và llama.cpp nên không có lợi ích rõ ràng. C2ATProto Spaces Alpha: AT Protocol Gets Non-Public, Access-Controlled Data Layers

📰 Article (English)

The AT Protocol team released the alpha specification for "ATProto Spaces," a new protocol extension that enables developers to build applications with non-public, access-controlled data. Until now, atproto (the protocol underlying Bluesky) only supported fully public data — every post, like, and follow was visible to anyone. Spaces change this by creating what the team describes as "a miniature atproto network that can be gated so that only certain people and applications are able to access the data published in it." This unlocks entirely new use cases for atproto-based apps: private settings and preferences, bookmarked posts, direct messages, gated communities, subscription-based content, group chats, and private collaboration spaces — all while preserving atproto's core advantages of portable identity (your DID stays yours), interoperable data formats, and self-hosting capability. From a developer perspective, Spaces represent a significant protocol-level expansion. Apps built on atproto can now implement permission models and private data without forking the protocol or using off-chain storage. The alpha status means APIs may change, but the team is soliciting developer feedback before stabilizing the spec. This positions AT Protocol as a serious competitor to federated protocols like ActivityPub (Mastodon) and Matrix, which have historically had stronger private messaging support.
