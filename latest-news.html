Microsoft chính thức phát hành "Microsoft Execution Containers (MXC)" — môi trường cách ly để chạy AI agent an toàn trên Windows 11. MXC giới hạn các file và mạng mà agent có thể truy cập thông qua policy, phân tách hành động của con người và agent, đồng thời cung cấp cơ sở hạ tầng để giám sát hành vi agent. Có nhiều mức độ cách ly: AppContainer (cho coding agent), Session Container (cách ly desktop và clipboard), WSLc và MicroVM (cách ly cấp phần cứng). Anthropic's Claude Code đã thông báo hỗ trợ MXC. Đây là công nghệ quan trọng để giảm thiểu rủi ro agent vô tình xóa file hoặc kết nối mạng trái phép.
