C1Google DeepMind's AlphaProof Code Formally Verifies Signal's Cryptographic Protocol Using AI Agents

📰 Article (English)

Google DeepMind has announced AlphaProof Code, a multi-LLM agentic framework designed for formal software verification. The team used it to mathematically verify the security properties of the actual compiled code behind Signal's cryptographic messaging protocol — which DeepMind claims is both a first for AI on a widely deployed protocol at this depth, and the first formal verification of such a protocol's implementation by any method. Formal verification proves that code behaves correctly under all conditions and is considered the highest standard of security assurance. The process divides work as a research team would: human experts worked with several models to translate Signal's security goals into formal Lean specifications. Agents powered by Gemini Carbon then generated over six million lines of Lean proof code, while the Lean type checker verified each proof automatically. The entire verification took four weeks — a task that historically requires expert teams years to accomplish. To validate detection capability, researchers deliberately reintroduced two previously fixed bugs into an isolated copy of Signal's code. In both cases, the system produced a machine-checked proof confirming the buggy version was insecure. Signal's CTO Ehren Kret called the approach a major breakthrough. DeepMind is open-sourcing the verification artifacts and published a technical paper. The company frames this as a step toward securing other critical systems like medical device firmware and power grid software.

C2LangChain Deep Agents Go Async: Orchestrators Can Now Delegate to Background Subagents

📰 Article (English)

LangChain has released async subagents for Deep Agents, allowing an orchestrator agent to dispatch long-running tasks to background workers while remaining responsive to the user. The release addresses a core limitation of the standard ReAct loop: when an agent is blocked waiting for a slow tool call, the entire queue stalls behind it. The ecosystem has been converging on a split-responsibility model: one orchestrator stays with the user and multiple background workers handle long tasks. Claude Code already runs subagents in the background by default; OpenAI's dots and DeepSeek Harness use similar architectures. LangChain now brings this pattern to Deep Agents with five new tools: start_async_task, check_async_task, update_async_task, cancel_async_task, and list_async_tasks. Steering a running subagent depends on the update_strategy field. Setting it to "interrupt" (the default) restarts the subagent with a new instruction. Setting it to "enqueue" waits for the current run to complete first. Notifications are state-aware: if the orchestrator is busy, it picks up results mid-run; if idle, the subagent wakes it; if waiting for user approval, the approval is left untouched and results arrive after. Async subagents are available in both Python and JavaScript Deep Agents, and in Managed Deep Agents with a one-field change. Task notifications are in beta.

GitHub is also providing API access to identify which repositories in an organization are affected before the December 8 cutoff. For teams managing large GitHub organizations with legacy or fork repositories that receive infrequent pushes, this represents a meaningful change to alert SLAs and on-call workflows if those repositories are still considered active dependencies.
