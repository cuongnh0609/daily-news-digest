B-01Claude CodeがAGENTS.mdに対応——CLAUDE.mdがない場合に自動読み込み、マルチエージェント環境を統一

📰 本文 + 和越対訳

AnthropicはClaude Codeのバージョン2.1.277（9月18日更新）において、AGENTS.mdファイルの読み込みに対応したことを明らかにした。具体的には、プロジェクト内にCLAUDE.mdが存在しない場合、Claude Codeが自動的にAGENTS.mdを読み込む仕様となっている。AGENTS.mdはAIコーディングアシスタントや自律型エージェント向けに設計されたMarkdown形式の設定ファイルであり、開発環境の情報やテスト手順、プルリクエストのガイドラインなどを一元管理できる。OpenAI Codex、Google Gemini CLI、Devin、Cursor、GitHub CopilotといったツールはすでにAGENTS.mdをサポートしていたが、Claude Codeはこれまで対応していなかった。今回の対応によって、異なるAIベンダー間での移行や複数エージェントの並行運用がより容易になると期待される。なお、Amazon Bedrock・Google Vertex・Microsoft FoundryではまだこのAGENTS.md対応は利用できない点に留意が必要だ。

Anthropic đã thông báo rằng trong Claude Code phiên bản 2.1.277 (cập nhật ngày 18/9), công cụ này đã hỗ trợ đọc file AGENTS.md. Cụ thể, khi không có file CLAUDE.md trong dự án, Claude Code sẽ tự động đọc AGENTS.md thay thế. AGENTS.md là file cấu hình định dạng Markdown được thiết kế cho các AI coding assistant và autonomous agent, cho phép quản lý tập trung thông tin môi trường phát triển, quy trình kiểm thử, và hướng dẫn pull request. Các công cụ như OpenAI Codex, Google Gemini CLI, Devin, Cursor, GitHub Copilot đã hỗ trợ AGENTS.md từ trước, nhưng Claude Code chưa hỗ trợ cho đến nay. Sự cập nhật này được kỳ vọng sẽ giúp việc chuyển đổi giữa các AI vendor khác nhau và vận hành song song nhiều agent trở nên dễ dàng hơn. Cần lưu ý rằng tính năng hỗ trợ AGENTS.md này chưa khả dụng trên Amazon Bedrock, Google Vertex và Microsoft Foundry.
