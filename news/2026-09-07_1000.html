📰 本文 + 和越対訳

Claude CodeやCursorなどのAIコーディングエージェントの振る舞いを制御するための設定ファイル「AGENTS.md」（あるいは「CLAUDE.md」）を書いても、本当に効いているかを確認している開発者は少ない。Zennに投稿されたこの記事の著者は、実際に自分のルールが一度も発動していなかったことを測定で発見し、ETH Zurichの研究チームによる実証評価論文の結果を紹介している。論文によると、人間が手書きしたAGENTS.mdは平均で+4%の精度向上をもたらす一方、AIに自動生成させたものは逆に-3%の精度低下を引き起こすという驚くべき結果が得られた。この知見は「スペック駆動開発（Spec-Driven Development）」の重要性を改めて示すものでもある。ルールが発動していることを検証するためのモニタリング手法や、効果的なAGENTS.mdの書き方についての考察も含まれており、AIエージェントを運用する実務者にとって必読の内容となっている。

Ít nhà phát triển thực sự kiểm tra xem file cấu hình AGENTS.md (hay CLAUDE.md) dùng để kiểm soát hành vi của các AI coding agent như Claude Code hay Cursor có thực sự hoạt động hay không.
