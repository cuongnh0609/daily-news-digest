B1Claude Codeに「セキュリティ監査」を依頼するプロンプト20選——IDOR・インジェクション・乱用まで網羅したチェックリスト

📰 本文 + 和越対訳

ZennユーザーのYuisekiが公開した記事では、Claude Codeによるセキュリティレビューを最大限に活用するための、コピー＆ペーストで使える20種類のプロンプトが紹介されている。チェック項目は認証・認可・インジェクション・乱用・情報露出の5カテゴリに分類されており、それぞれに具体的な攻撃ベクトルを想定した質問が用意されている。認証では、削除済みユーザーのトークンが依然有効かどうか、JWTの検証が正しく行われているかなどを確認する。認可ではIDOR（Broken Object Level Authorization）の有無を重点的に調べ、攻撃者が他ユーザーのリソースにアクセスできる経路がないかをチェックする。また、最終確認プロンプトでは、AIが提案した修正策がDDoSなどの新たな攻撃経路を生まないかどうかも検証するよう求めている。著者はこの記事のURLをClaude Codeに渡すだけで、リポジトリ全体の監査が行えると説明している。

Bài viết của Yuiseki trên Zenn giới thiệu 20 prompt có thể copy-paste trực tiếp vào Claude Code để thực hiện security review cho dự án. Các câu hỏi được phân loại thành 5 nhóm: xác thực (authentication), phân quyền (authorization), injection, lạm dụng (abuse) và lộ thông tin (exposure). Phần xác thực kiểm tra xem token của người dùng đã xóa có còn hợp lệ không, JWT có được xác minh đúng cách không. Phần phân quyền tập trung vào IDOR — liệu kẻ tấn công có thể truy cập dữ liệu của người dùng khác bằng cách thay đổi ID không. Điểm thú vị là prompt kiểm tra cuối yêu cầu Claude Code xác nhận rằng các fix đề xuất không vô tình tạo ra lỗ hổng DoS mới. Tác giả giải thích chỉ cần truyền URL bài viết này cho Claude Code là có thể audit toàn bộ repository.
