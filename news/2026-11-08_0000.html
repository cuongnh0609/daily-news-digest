📰 Article (English)

Anthropic's research team has published a comprehensive framework breaking down the components of agent memory — one of the most critical yet often misunderstood aspects of building reliable AI agents. The paper categorizes memory into four types: in-context storage (information within the active context window), external storage (databases, vector stores, files outside the model), in-weights storage (knowledge baked into model parameters during training), and in-cache storage (saved computation states via KV cache). The research argues that most production agent failures can be traced back to poor memory architecture decisions: agents that overflow context windows, lose critical state across sessions, or fail to retrieve relevant historical information at the right time. Practical guidance covers tradeoffs between retrieval latency and freshness, when to use semantic search vs. exact lookup, and how to structure episodic memory for long-running autonomous agents. This directly informs patterns like ReAct, reflection loops, and the emerging class of persistent agents that maintain state across days or weeks of operation. The paper is positioned as a foundational reference for anyone designing multi-step agentic systems at scale.
