B1Claude Code / Codexでusage limitが急減する本当の理由——長期セッションのトークン消費を解剖

C3ESP32-S3 Cluster Runs a 0.4B LLM Across 7 Microcontrollers Using 1.58-bit BitNet Quantization

📰 Article (English)

A hobbyist project on GitHub has demonstrated distributed LLM inference using a cluster of seven ESP32-S3 microcontrollers running a 0.4B parameter language model — entirely without a GPU or cloud backend. The architecture uses 1.58-bit ternary quantization (BitNet), where model weights are represented as -1, 0, or +1 rather than standard floating-point values. This extreme compression reduces the model from gigabytes to megabytes, making it runnable on chips with only megabytes of PSRAM. The implementation slices 24 transformer blocks across 6 compute nodes connected in a SPI daisy-chain topology, with a master node handling tokenization, embedding, and final output. Hidden state vectors are passed from node to node sequentially. The quantization uses INT4 for embeddings and FP16/FP32 for activations, while the attention weights use ternary values. The entire cluster fits on a small custom PCB and runs inference in real-time. This project is primarily of educational and research interest — the 0.4B ternary model is far below the capability threshold of modern frontier models. But it demonstrates a reproducible pathway to running language models on the cheapest class of microcontrollers, with implications for offline edge AI in IoT sensors, embedded systems, and devices that cannot rely on network connectivity. The project is MIT-licensed with 135 stars on GitHub.

Một dự án hobbyist trên GitHub đã chứng minh khả năng chạy suy luận LLM phân tán bằng cụm 7 vi điều khiển ESP32-S3 — hoàn toàn không cần GPU hay backend đám mây — cho một model ngôn ngữ 0,4B tham số. Kiến trúc sử dụng quantization ternary 1,58-bit (BitNet), trong đó trọng số model được biểu diễn dưới dạng -1, 0, hoặc +1 thay vì các giá trị dấu phẩy động thông thường. Nén cực đoan này làm giảm kích thước model từ gigabyte xuống megabyte, cho phép chạy trên các chip chỉ có vài megabyte PSRAM. Triển khai chia 24 transformer block cho 6 compute node kết nối theo topology daisy-chain qua SPI, với master node xử lý tokenization, embedding và output cuối. Vector hidden state được truyền tuần tự từ node này sang node khác. Toàn bộ cụm nằm gọn trên một PCB tùy chỉnh nhỏ và chạy suy luận theo thời gian thực. Dự án chủ yếu có giá trị giáo dục và nghiên cứu — model ternary 0,4B vẫn còn cách xa ngưỡng khả năng của các model frontier hiện đại — nhưng chứng minh con đường khả thi để chạy LLM trên vi điều khiển rẻ nhất, với ý nghĩa đối với AI edge ngoại tuyến trong IoT và hệ thống nhúng.
Với Cloud/Embedded Engineer, đây là bằng chứng thực nghiệm rằng BitNet quantization có thể đưa LLM vào các thiết bị IoT cực thấp chi phí. Nếu bạn làm edge computing, đáng theo dõi xu hướng này cho các use case offline inference không phụ thuộc network.

📖 Thuật ngữ khó

Thuật ngữPhiên âmGiải thích
BitNet / 1.58-bit /bɪt nɛt/ Kỹ thuật quantization cực đoan: mỗi trọng số chỉ dùng 1,58 bit bằng cách encode thành -1, 0, +1 (ternary). Phát triển bởi Microsoft Research, cho phép nhân ma trận bằng phép cộng/trừ đơn giản thay vì phép nhân float.
Daisy-chain topology /ˈdeɪzi tʃeɪn/ Cấu hình kết nối chuỗi — mỗi thiết bị kết nối trực tiếp với thiết bị tiếp theo, dữ liệu truyền tuần tự qua toàn chuỗi. Đơn giản nhưng latency tăng theo số node.
PSRAM /piː es ræm/ Pseudo Static RAM — loại RAM ngoài (external) thường thấy trên ESP32, kết nối qua SPI/QSPI. Chậm hơn SRAM nội bộ nhưng dung lượng lớn hơn nhiều (4–16 MB).
Transformer block /trænsˈfɔrmər/ Đơn vị cơ bản của kiến trúc Transformer — gồm multi-head attention và feed-forward network. Một LLM gồm hàng chục đến hàng trăm block xếp chồng lên nhau.
Edge AI / offline inference /ɛdʒ eɪ aɪ/ AI chạy trực tiếp trên thiết bị đầu cuối (không qua server) — giảm độ trễ, bảo vệ quyền riêng tư, và hoạt động khi không có mạng.
