B-01CLI上のClaude CodeでComputer Useを再現する――追加課金ゼロ、441行のGUIエージェント

📰 本文 + 和越対訳

Zennに掲載されたこの技術記事では、Claude CodeのCLIサブスクリプションだけを使い、Anthropic APIへの追加課金なしにGUI操作エージェントを実現する方法を紹介している。実装の核心は441行のPythonスクリプト2本で構成される。snap.pyはスクリーンショットを1366×768にダウンスケールして画像トークンを約49%削減し、act.pyはClaudeが出力した座標をネイティブDPI解像度に変換して実際のマウス・キーボード操作を実行する。安全機構として、ANTHROPIC_API_KEYなどの機密パターンをブロックするdeny-listと、全アクション前の人間承認ステップが組み込まれている。スクリーンショットをビジョン入力としてClaude Codeセッションに渡すことで、Claudeは次のアクションを判断し、ローカルCLIツールが実行するという分業構造だ。

Bài viết kỹ thuật trên Zenn này giới thiệu cách xây dựng agent điều khiển GUI hoàn toàn không tốn thêm phí API Anthropic, chỉ dùng subscription Claude Code CLI. Triển khai gồm 2 script Python tổng cộng 441 dòng. snap.py downscale màn hình về 1366×768 để giảm ~49% image token, còn act.py chuyển đổi tọa độ Claude xuất ra thành thao tác chuột/bàn phím thực tế theo độ phân giải DPI gốc. Cơ chế an toàn bao gồm deny-list chặn các pattern nhạy cảm như ANTHROPIC_API_KEY, và yêu cầu con người phê duyệt trước mỗi hành động.
