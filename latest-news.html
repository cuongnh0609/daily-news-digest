B-01Deno開発元がCloudflareに合流——DenoランタイムとDeno Deployは終了へ、JSRは継続

📰 本文 + 和越対訳

JavaScriptランタイム「Deno」の開発元であるDeno LandがCloudflareに合流し、事実上の買収となることが明らかになった。合流後の1年間はDenoのバグ修正とセキュリティアップデートが毎月提供されるが、その後Deno LandによるDenoランタイムの開発は終了する。商用サービスの「Deno Deploy」は6ヶ月後に終了し、Cloudflare Workersへの移行ツールが提供される予定だ。一方、JavaScriptパッケージレジストリの「JSR」はインフラをCloudflareに移管して運営を継続し、ライアン・ダール氏らはCloudflareのworkerdとcelldを中心に、Workersのセルフホスティング基盤の開発に注力する方針だ。Denoのコードはオープンソースとして公開され続けるため、コミュニティによる継続開発の可能性は残されている。

Deno Land — công ty phát triển runtime JavaScript "Deno" — đã gia nhập Cloudflare trong một thương vụ được xem là mua lại. Trong 1 năm sau khi sáp nhập, Deno tiếp tục nhận vá lỗi và cập nhật bảo mật hàng tháng, nhưng sau đó Deno Land sẽ dừng phát triển runtime. Dịch vụ thương mại "Deno Deploy" sẽ đóng cửa sau 6 tháng, với công cụ hỗ trợ migration sang Cloudflare Workers. JSR — registry package JavaScript — sẽ chuyển hạ tầng sang Cloudflare và tiếp tục hoạt động. Ryan Dahl và cộng sự sẽ tập trung vào phát triển nền tảng self-hosting cho Workers dựa trên workerd và celld. Deno vẫn là open source nên cộng đồng có thể tiếp tục phát triển.

C-01GitHub Push Attribution Now in Public Preview — Stops Commit Spoofing with Verified Pusher Identity

📰 Article (English)

GitHub has launched push attribution into limited public preview for GitHub Enterprise customers. This feature records the authenticated user who actually pushed each commit to a repository, storing that pusher identity as a field separate from the traditional author and committer metadata. The key problem it solves: the author and committer fields in a Git commit can be set to any name and email by anyone with write access, enabling a compromised low-privilege account to make commits appear as if they came from a trusted senior maintainer. With push attribution, the true pusher is cryptographically verified against their authenticated GitHub account and visible in both the UI and API. Organizations can also create a repository ruleset requiring that the committer metadata matches a verified email of the pusher, blocking any push that mismatches. This makes it straightforward to audit commit provenance, detect suspicious activity, and speed up security incident investigations. The feature is especially valuable for enterprises running agentic CI workflows where automated pushes need to be clearly distinguished from human pushes.
