B-01TLA+で「AIにテストケースを書かせるな、ルールを書け」——仕様記述による生成AIの制御

📰 本文 + 和越対訳

Zennで注目を集めている記事は、形式仕様記述言語TLA+を使って生成AIのコード生成を制御するアプローチを提唱している。著者は「AIにテストケースを書かせると、AIが通りやすいテストを作ってしまう」という問題意識から出発し、テストより上位の抽象レベルである「ルール（仕様）」を人間が定義し、AIはその仕様に従ってコードを実装すべきだと主張する。TLA+を使えば、並行処理や状態機械の振る舞いをモデル検査器によって検証できるため、AIが生成したコードの正確性をより厳密に保証できるという。このアプローチはSpec-Driven Developmentの実践例として注目されており、AI駆動開発のバイブルとして広まりつつある。

Một bài viết đang được chú ý trên Zenn đề xuất cách kiểm soát việc AI sinh code bằng ngôn ngữ đặc tả hình thức TLA+. Tác giả xuất phát từ vấn đề "nếu để AI viết test case, AI sẽ tạo ra các test dễ pass", từ đó lập luận rằng con người nên định nghĩa "rules (specification)" ở mức trừu tượng cao hơn test, còn AI sẽ implement code theo spec đó. Với TLA+, có thể dùng model checker để xác minh hành vi của concurrent processing và state machine, từ đó đảm bảo tính chính xác của code do AI sinh ra một cách nghiêm ngặt hơn. Cách tiếp cận này được xem là ví dụ thực tiễn của Spec-Driven Development và đang lan rộng như một triết lý phát triển trong thời đại AI.

C-02LittleBit: Ultra Low-Bit Quantization via Latent Factorization — Sub-1-Bit LLM Weights

📰 Article (English)

Researchers have published LittleBit, a novel quantization technique that pushes LLM weight compression beyond traditional 1-bit boundaries by using latent factorization. Instead of representing each weight as a single binary value, LittleBit decomposes the weight matrix into a low-rank latent space and then quantizes the latent factors rather than the original weights directly. The result is effective per-weight storage that falls below 1 bit on average while maintaining model quality substantially better than naive 1-bit approaches like BitNet. In benchmarks on 7B and 13B parameter models, LittleBit achieves 15–20% lower perplexity than comparable 1-bit methods at the same memory footprint. The technique is particularly promising for edge deployment scenarios where VRAM is severely constrained — a Raspberry Pi or mobile NPU class device may eventually run a capable assistant model. The paper includes reference implementations in PyTorch and integration hooks for llama.cpp, making it accessible for practical experimentation.
