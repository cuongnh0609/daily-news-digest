Hiện tại đã tích lũy 47 rule, bao gồm các rule về TDD và "luôn chạy test cuối cùng". C3Auto-Research with Codex: How I Achieved a 232× Faster GPU Kernel — Agentic Iterative Optimization Loop

📰 Article (English)

Engineer Sankalp Dayal published a deep-dive post on how he used OpenAI's Codex agent in an automated research loop to achieve a 232× speedup on a GPU kernel, starting from a naive PyTorch baseline. The process, which he calls "auto-research," involves giving Codex a high-level optimization goal, a set of benchmark scripts, and permission to iterate — writing candidate kernels in CUDA or Triton, running benchmarks, analyzing the result, and then proposing the next optimization hypothesis without human intervention. The key insight is treating kernel optimization as a search problem in code-space rather than a hand-tuned engineering task. Codex explored techniques including memory coalescing, shared memory tiling, warp-level reductions, and mixed-precision arithmetic across dozens of iterations in a single session. The 232× speedup represents a jump from ~4 TFLOPS to ~928 TFLOPS effective throughput on an A100 GPU for the target operation. Dayal emphasizes that the breakthrough wasn't just raw performance — it was the speed of exploration: what would take a human kernel engineer weeks of trial-and-error took the agent a few hours.
