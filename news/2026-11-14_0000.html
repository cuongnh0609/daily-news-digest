📰 Article (English)

Google launched the Gemini Decisions API on November 11, a fundamentally new type of AI primitive that returns probability distributions rather than generated text. Unlike traditional LLM calls that produce a string response, Decisions API accepts a question and a set of options, then returns a probability score for each option — without ever generating text tokens. Simon Willison analyzed the API in depth, noting that this design sidesteps the "overthinking" problem seen in reasoning models while making the output directly machine-consumable. The API is designed for high-frequency classification tasks — routing decisions in agent workflows, content moderation signals, intent detection — where generating a full text response wastes compute and adds parsing overhead. Willison notes the pricing is significantly lower than standard Gemini API calls, making it viable for use cases that would be cost-prohibitive with text generation. The API currently supports up to 32 options per request and returns calibrated confidence scores. This represents a potential paradigm shift: instead of an LLM deciding by writing out its reasoning, it decides by assigning probabilities — a distinction that matters enormously for latency-sensitive agentic pipelines.

Brave announced on November 13 that its Search API now natively supports the x402 payment protocol, allowing AI agents to pay for search queries autonomously without requiring a pre-registered API key or human-in-the-loop authorization. The x402 protocol, an emerging standard built on HTTP 402 "Payment Required" responses, enables agent-native micropayments: an agent making a request receives a 402 response with payment details, pays the required amount in stablecoin via a compatible wallet, and re-sends the request with a payment proof header to receive the response. This removes a key friction point in agentic workflows where agents currently need API keys provisioned in advance by human operators. Brave's implementation charges per-query at a rate below standard API key pricing for most use cases. The announcement appeared on Hacker News front page with significant discussion around whether x402 could become the universal payment layer for agent-to-service interactions. The protocol is backed by several infrastructure providers and has integrations with Coinbase's payment stack, though it currently requires stablecoin rather than fiat currency.
