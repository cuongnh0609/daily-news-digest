B01AIエージェントの「認可疲れ」を解消する——OBOトークン交換の理論と実装

📰 本文 + 和越対訳

AIエージェントが複数の外部サービスと連携する際に発生する「認可疲れ」——サービスごとに認可を求められ、ユーザー体験が著しく損なわれる問題——に対する処方箋として、OBO（On-Behalf-Of）トークン交換の手法が注目されている。本稿は認可疲れの原因を整理し、OBOの仕組みを解説した上で、Amazon Bedrock AgentCoreを使った実装例を示す。OBOではユーザーの初回認証で得たid_tokenを各サービスのaccess_tokenに一括交換し、エージェントがユーザーに代わって複数サービスに自律的にアクセスできるようにする。本番環境での実装には、トークン署名鍵の管理、なりすましや権限昇格への対策、そして監視ログの設計が不可欠だ。Amazon Bedrock AgentCoreはすでにOBOに対応しており、カスタム認可サーバーの登録のみで利用できる。

Khi AI agent kết nối với nhiều dịch vụ bên ngoài, người dùng thường gặp phải "mệt mỏi xác thực" — phải chấp thuận quyền truy cập riêng lẻ cho từng dịch vụ, làm giảm đáng kể trải nghiệm. C01Cloudflare Launches Kitesurf — An AI-Native Headless Browser Built in Rust on Workers

📰 Article (English)

Cloudflare has announced Kitesurf, a headless browser purpose-built for AI agents rather than human users. Written primarily in Rust and compiled to WebAssembly, Kitesurf runs natively on Cloudflare Workers and deliberately strips out everything a human browser needs but an AI does not — no tabs, bookmarks, browser extensions, or themes. The result is a browser that spins up per-request and consumes 3–7× less CPU and memory than Chromium-based alternatives. Kitesurf exposes the Chrome DevTools Protocol over WebSocket and a RESTful API, making it compatible with existing automation tools including Puppeteer, Playwright, and Chrome DevTools without code changes. The browser passed Web Platform Tests and was validated against real-world websites in comparative testing against Chromium. Currently available in public beta with a playground for live testing, Kitesurf is positioned as infrastructure for the agentic web — where AI agents need to browse, extract, and interact with pages at scale without the overhead of human-facing browser machinery. This is a direct response to the growing demand for lightweight, high-concurrency browser execution in agentic pipelines.
