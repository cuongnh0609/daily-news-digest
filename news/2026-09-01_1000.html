B-1「AIが勝手にやった」は通じない——AIエージェントにも身元証明と権限委任の仕組みが必要な理由

📰 本文 + 和越対訳

AIエージェントが業務の自律実行を担う時代が近づく中、セキュリティ専門家たちの間では「Agentic Identity（エージェンティック・アイデンティティ）」と「Delegated Authorization（委任型権限付与）」という2つの概念が急速に注目を集めている。前者は各エージェントに固有のIDを割り当て、所有部門・責任者・用途・アクセス可能システムを管理する仕組み。後者は「誰の代理として・どのリソースに・どの操作を・いつまで・どの条件で行うか」を明示的に定義する権限委任モデルだ。実際にはReplit、EchoLeakなどの事故事例が示すように、エージェントが過剰権限で動くことによる情報漏えいやシステム破壊のリスクが現実のものとなっている。MicrosoftやAWS、Googleなどの主要クラウドベンダーもすでに短命トークンと最小権限の原則を軸とした対策を進めており、企業に対しては社内AIの棚卸しと権限の最小化から始めることが推奨されている。

Khi các AI agent ngày càng được giao thực thi công việc một cách tự động, hai khái niệm "Agentic Identity" và "Delegated Authorization" đang nhanh chóng thu hút sự chú ý trong cộng đồng bảo mật. Khái niệm đầu là cơ chế gán ID duy nhất cho mỗi agent, quản lý bộ phận sở hữu, người chịu trách nhiệm, mục đích sử dụng và hệ thống được phép truy cập. Khái niệm thứ hai là mô hình ủy quyền xác định rõ ràng "đại diện cho ai, truy cập tài nguyên gì, thực hiện thao tác nào, trong bao lâu và với điều kiện nào". Các sự cố thực tế như Replit hay lỗ hổng EchoLeak cho thấy rủi ro rò rỉ thông tin và phá hủy hệ thống do agent hoạt động với quyền quá mức là nguy cơ có thật. Microsoft, AWS và Google đều đã triển khai giải pháp dựa trên token ngắn hạn và nguyên tắc quyền tối thiểu, đồng thời khuyến nghị doanh nghiệp bắt đầu bằng việc kiểm kê AI nội bộ và thu hẹp phạm vi quyền.

📗 文法

〜を軸とした〜 — lấy～làm trục, dựa trên～

C-1Wrapture: A Python Library for AI-Directed Testing and Tracing Without Code Modification

📰 Article (English)

Simon Willison has introduced Wrapture, a new Python library created by Graham Dumpleton that brings together two traditionally separate concerns: monkeypatching for testing and observability tracing — without requiring changes to the code under observation. The library lets developers wrap any function or method to intercept calls, record arguments and return values, or substitute predetermined responses, all from outside the codebase being tested. This makes it particularly powerful for teams working with legacy systems or third-party dependencies where modifying source code is impossible or undesirable. Wrapture integrates OpenTelemetry natively and supports a TOML-based configuration format, allowing engineers to add distributed tracing to existing applications without touching a single line of production code. The configuration-driven approach means tracing rules can be versioned alongside infrastructure config rather than baked into application logic. What makes Wrapture stand out in the AI era is the development philosophy: Dumpleton used Claude to write all code and documentation, but explicitly rejected "vibe coding." He treated AI as a precision production tool, directing each output based on deep Python internals expertise. The result is a library that demonstrates the difference between AI-assisted engineering and AI-generated noise — the human expertise shapes the architecture while AI accelerates implementation. Willison calls this approach a model for responsible AI-directed development.

C-3Google Removes All MV2 Extensions from Chrome Web Store, Including uBlock Origin

📰 Article (English)

Google has completed the removal of all Manifest V2 (MV2) browser extensions from the Chrome Web Store, including the widely used ad and content blocker uBlock Origin. The move completes a transition that Google first announced years ago: Chrome extensions must now use the Manifest V3 (MV3) platform, which imposes stricter limitations on how extensions can intercept and modify network requests. The core technical change is the replacement of the webRequest API (which allowed extensions to dynamically block and redirect network traffic) with the declarativeNetRequest API, which uses pre-defined static rule sets evaluated by the browser engine rather than extension code. Privacy advocates and security researchers have argued that MV3's rule-set cap — 30,000 rules maximum per extension — fundamentally limits the effectiveness of content blockers compared to the dynamic filtering MV2 enabled. For enterprise users who relied on MV2 extensions, Google offered an Enterprise Policy bypass that expires on January 12, 2027. The uBlock Origin developer has released "uBlock Origin Lite," an MV3-compatible version, though it operates with reduced capability. Other ad blockers like Ghostery and AdGuard have published MV3 versions as well. The change affects Chrome's over 3 billion active users and has sparked renewed interest in Firefox, which still supports MV2 extensions with no announced deprecation timeline.

🔴 HIGH uBlock Origin is no longer available in Chrome Web Store — users and enterprises must migrate to MV3 alternatives immediately.
