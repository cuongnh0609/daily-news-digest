Engineers from Anthropic, Google, OpenAI, and others will maintain it as individuals, with David Soria Parra and Mahesh Murag as Lead Maintainers. Anthropic notes it previously donated the Model Context Protocol (MCP) to the same foundation. This move is designed to prevent any single vendor from controlling the format and to encourage cross-platform agent interoperability.

In a post surfaced by Simon Willison, Sansbury explains that the key inflection point came when Fable-class models became capable enough to handle the full development loop autonomously: writing, testing, reviewing, and deploying code. The development pipeline is driven by agents running continuously in the background. Each hour, agents propose changes, run tests, pass a review gate, and deploy — all without a human pressing a button. Sansbury notes that GPT-6 Astra struggled with the same pipeline where Fable-class models succeeded, which he attributes to differences in instruction-following fidelity and long-horizon task coherence. The game world itself is the product — players type natural-language prompts and the in-game agent reshapes terrain, spawns objects, and changes rules in real time. This creates a tight feedback loop between the AI development pipeline and the product, because the agents building the game are the same class of models the players interact with. Sansbury argues this makes Spawn one of the most honest demonstrations of what production-grade agentic AI can do today when the infrastructure is purpose-built for it.

Pipeline phát triển được điều hành bởi các agent chạy liên tục trong nền. Mỗi giờ, agent đề xuất thay đổi, chạy test, vượt qua cổng review và deploy — tất cả mà không cần người nhấn nút.
