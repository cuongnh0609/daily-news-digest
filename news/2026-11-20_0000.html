B1AWSがElastiCache Distributed KV Cachingを発表——GPU 2台のvLLM推論で分散キャッシュを試す

📰 本文 + 和越対訳

AWSがElastiCacheの新機能として「Distributed KV Caching」を発表した。この機能は、LLMの推論処理において頻繁に再利用されるKVキャッシュ（Key-Valueキャッシュ）を複数のGPUインスタンス間で共有・再利用することを可能にするものだ。Zennのエンジニアが実際にGPU 2台構成のvLLMクラスタで検証を行ったところ、プリフィルフェーズのレイテンシが大幅に削減され、同一プロンプトのプレフィックスに対するキャッシュヒット率が向上することが確認された。KVキャッシュの分散管理はマルチエージェントシステムや長いシステムプロンプトを持つアプリケーションにとって特に恩恵が大きく、推論コストの削減に直結する。今後はより大規模なクラスタでの性能評価が期待される。

AWS thông báo tính năng mới "Distributed KV Caching" cho ElastiCache. Tính năng này cho phép chia sẻ và tái sử dụng KV cache (Key-Value cache) — vốn được tái sử dụng thường xuyên trong quá trình suy luận LLM — giữa nhiều GPU instance. Một kỹ sư trên Zenn đã thực nghiệm với cluster vLLM cấu hình 2 GPU và xác nhận rằng latency ở giai đoạn prefill giảm đáng kể và tỷ lệ cache hit với prefix prompt giống nhau được cải thiện. Việc quản lý KV cache phân tán đặc biệt có lợi cho các hệ thống multi-agent và ứng dụng có system prompt dài, dẫn thẳng đến giảm chi phí inference. Thời gian tới, đánh giá hiệu năng trên cluster lớn hơn được kỳ vọng.

C1External Sandboxes for Coding Agents: Three New MCP Servers Let Agents Run Code Safely

📰 Article (English)

Simon Willison's post on "External sandboxes for coding agents" identifies a critical gap in current AI coding agent setups: when an agent writes and runs code, it typically executes inside the same environment where it has access to credentials, files, and secrets. Three new MCP server implementations now offer isolated sandbox environments where agent-generated code can be executed safely, with no access to the host machine's resources. The first approach uses ephemeral container spin-up per code execution, destroying the container after each run. The second uses WebAssembly runtimes (WASM) for code that doesn't need native system calls. The third leverages micro-VMs with sub-second cold start times. All three expose a standardized MCP tool interface so any MCP-compatible agent can invoke them interchangeably. Willison notes this fills a major security gap: "Until now, the standard advice was to run agents in Docker, but Docker doesn't prevent an agent from reading your ~/.ssh directory via a volume mount bug." These sandboxes make production-grade code execution safe for autonomous agentic systems.
