あるエンジニアチームが、社内の非エンジニアスタッフが業務システムの仕様や処理ロジックについて自力で調べられるよう、Google ChatとClaude Agent SDK、AWS Lambdaを組み合わせたAIエージェントを構築した事例が公開された。アーキテクチャはシンプルで、Google Chatへのメッセージが Lambda Function URLをトリガーし、コンテナ化されたClaude Agentがコードベースをツールで自律探索して回答を生成する。会話メタデータはDynamoDB、履歴はS3に保管される。実装を進める中で7つの技術的落とし穴が明らかになった。JWT検証にはOIDCトークンではなく独自形式が使われていた点、Lambdaからの外部API呼び出しはCI側でキューに積んで非同期処理する設計が必要だった点などが特に対処が難しかった。またAgentDefinition.toolsとallowedToolsの双方に同じツールを定義しないとエージェントがツールを認識しない挙動も確認された。このシステム導入により、スタッフは業務上の疑問をエンジニアに問い合わせることなく自己解決できるようになり、生産性の向上に加えてドキュメント化が会話を通じて自然に蓄積されるという副次効果も生まれている。

Một nhóm kỹ thuật đã công khai chia sẻ cách họ xây dựng agent AI nghiệp vụ cho nhân viên non-engineer, kết hợp Google Chat, Claude Agent SDK và AWS Lambda. Kiến trúc đơn giản: tin nhắn Google Chat kích hoạt Lambda Function URL, agent Claude tự động đọc codebase bằng các tool, rồi trả lời. Metadata hội thoại lưu trên DynamoDB, lịch sử lưu trên S3. Quá trình triển khai phát lộ 7 vấn đề kỹ thuật: JWT verification dùng định dạng riêng thay vì OIDC chuẩn, các lệnh gọi API bên ngoài phải được xử lý bất đồng bộ qua queue CI, và cả hai trường AgentDefinition.tools lẫn allowedTools đều cần được khai báo mới nhận diện được tool. LangChain published a detailed case study on how they built and deployed a long-running paid media agent that operates inside Slack. The agent autonomously manages advertising campaigns — delivering weekly performance summaries, answering follow-up questions about campaign data, and proposing optimizations for team approval. The key architectural insight was organizing agent knowledge into five layers: a navigational prompt, reusable skills, company-specific wiki pages, live tools fetching current advertising data, and deterministic Python/DuckDB code for calculations. Rather than stuffing everything into the system prompt, this separation keeps context windows lean and tool selection precise. A critical design decision was to unify two previously separate workflows — scheduled weekly reports and ad-hoc Slack queries — into one agent runtime with different capability profiles per entry point. Subagents with isolated context windows handle platform-specific work (Google Ads, Meta, LinkedIn) while the orchestrator synthesizes cross-platform insights. The team discovered that moving computational work from the model to code reduced a weekly reporting run from 18 minutes to 85 seconds and cut per-run costs by 40×. The agent now drives 20% of LangChain's marketing pipeline, cut cost per qualified lead by 30%, and saved roughly $5,000/month by eliminating external agency analysis.
