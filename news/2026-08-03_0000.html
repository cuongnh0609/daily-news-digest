Obsidianと複数のAIエージェントを組み合わせてPersonal Knowledge Base（PKB）を構築する実践的なガイドが注目を集めている。中核エージェントにはOpenAIのCodex CLIを採用し、外部サービスとの接続には「Hermes Agent」と呼ばれる専任エージェントを配置する2層構造が特徴だ。Google Calendar、Gmail、Slackなどのツールを段階的に連携させ、情報の自動取り込み、日次集約、そして永続的な知識への蒸留という3段階のワークフローを実現する。著者はLevel 0からLevel 2に分けた導入手順を公開しており、CLIに不慣れなユーザーでもAIに質問しながら構築できるよう設計されている。エージェントが外部データを取得してObsidianノートに自動書き込みする仕組みは、AIエージェント時代の個人生産性向上の一例として参考になる。

📰 Article (English)

The Diátaxis documentation framework, authored by Daniele Procida, reached the top of Hacker News with over 400 points, sparking renewed discussion about systematic approaches to technical documentation. Diátaxis proposes a four-quadrant model that separates documentation into: Tutorials (learning-oriented), How-To Guides (task-oriented), Reference (information-oriented), and Explanation (understanding-oriented). The framework argues that most documentation failures occur because writers conflate these four types — for example, writing a tutorial that also tries to explain concepts, or mixing reference material into how-to guides. The core insight is that each type serves a fundamentally different user need at a different moment: a new user learning needs a tutorial, an experienced user trying to accomplish something needs a how-to guide, a developer looking up details needs reference, and someone trying to understand the "why" needs explanation. For engineering teams maintaining docs alongside code — and increasingly, teams using AI to generate docs — Diátaxis provides a principled taxonomy that improves both human-written and AI-generated documentation quality. Many teams have found the framework particularly useful when integrating AI doc generation into their workflows, as it helps define clear contracts for what each document type should contain.
