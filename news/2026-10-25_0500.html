A5クリスタ、PHP脆弱性への緊急対応でクラウド機能を予告なく停止——データの事前保存を呼び掛け

📰 本文 + 和越対訳

セルシスは10月22日、同社のペイントソフト「CLIP STUDIO PAINT（クリスタ）」のクラウドサービスについて、多くのWebサービスで使われている技術の脆弱性に対応するため、予告なく緊急メンテナンスを行う可能性があると公式Xアカウントで告知した。対象とされる脆弱性はプログラミング言語PHPに存在する「緊急」レベルのものとみられ、pixivやBASEなどの国内サービスも同様に緊急対応を実施している。クラウドを通じた作品の同期・保存、CLIP STUDIO ASSETSでの素材購入、アカウントへのログインや新規登録などが停止対象となる可能性がある。ペイントソフト本体の機能は引き続き利用可能だが、セルシスはユーザーに対して重要な作品データを事前にローカル環境へダウンロードするよう強く呼び掛けている。クリエイターを対象としたサービスだけに、作業中のデータ損失リスクに関心が集まっている。

Celsys ngày 22/10 thông báo trên tài khoản X chính thức rằng dịch vụ cloud của phần mềm vẽ CLIP STUDIO PAINT (Kurista) có thể phải bảo trì khẩn cấp không báo trước để vá lỗ hổng nghiêm trọng liên quan đến ngôn ngữ lập trình PHP. Các dịch vụ trong nước như pixiv và BASE cũng đã thực hiện bảo trì khẩn cấp tương tự. Các tính năng có thể bị gián đoạn bao gồm: đồng bộ và lưu tác phẩm qua cloud, mua vật liệu trên CLIP STUDIO ASSETS, đăng nhập và tạo tài khoản mới. Phần mềm vẽ bản thân vẫn hoạt động bình thường, nhưng Celsys khuyến cáo người dùng nên tải xuống dữ liệu quan trọng về máy trước khi sự cố xảy ra. Đây là mối lo ngại lớn đối với các nghệ sĩ kỹ thuật số đang làm việc với dữ liệu trên cloud.

B1Claude Code で GitHub Actions の CI 待ち時間を 18 分から 4 分台に——e-dash が公開した並列化・キャッシュ戦略の全記録

📰 本文 + 和越対訳

e-dashのエンジニアがZennに投稿した記事が注目を集めている。Next.js（TypeScript）製アプリの PR CI が2か月で約2倍の最長18分超にまで膨れ上がり、開発速度を著しく損ねていた問題を、Claude Codeの分析補助を活用しながら体系的に解決した実録だ。まず計測を徹底し、テスト本体はCI全体の約14%に過ぎず、残りはセットアップなどのオーバーヘッドであることを特定。Vitestのprojects設定でDOMを使わないテストをNode環境に移し、ワーカー数を最適化した。さらにマイグレーション済みDBのダンプをキャッシュしてジョブ間で共有し、ユニットテストを--shardで並列化した。node_modulesキャッシュも導入した結果、直近20 PRの中央値は約4分45秒となり、中央値で約69%の短縮を達成。一方でActionsキャッシュが10GBの上限を超える問題も発生し、Dockerキャッシュの出力モードをmode=maxからmode=minに変更するなど容量管理にも工夫を凝らした。

Một kỹ sư của e-dash đã đăng bài viết trên Zenn thu hút sự chú ý lớn về việc tối ưu hóa CI cho ứng dụng Next.js (TypeScript). CI thời gian chạy đã tăng từ khoảng 9 phút lên tới 18+ phút chỉ trong 2 tháng. Bằng cách đo lường chi tiết với sự hỗ trợ của Claude Code, nhóm phát hiện rằng phần test thực sự chỉ chiếm 14% tổng thời gian. Họ đã dùng cấu hình `projects` của Vitest để phân tách môi trường test, cache database dump đã migrate, và dùng `--shard` để chạy song song unit test. Kết quả, thời gian CI giảm khoảng 69% xuống còn ~4 phút 45 giây. Cũng phát sinh vấn đề cache Actions vượt 10GB, giải quyết bằng cách đổi Docker cache mode từ `max` sang `min`. Đây là tài liệu thực tế rất hữu ích cho bất kỳ team nào đang gặp vấn đề tương tự.

📰 Article (English)

Aikido Security published a detailed analysis of CVE-2026-111497, a critical out-of-bounds write flaw in Google's Brotli compression library (versions 1.0.3–1.2.0, CVSS v4.0 score 9.2). Originally disclosed as the Node2Shell exploit in Node.js, the blast radius has since expanded to cover multiple languages and runtimes. The vulnerability allows a remote, unauthenticated attacker to send a crafted Brotli-compressed HTTP stream that can crash a process, leak memory contents, corrupt data, or potentially execute arbitrary code. The underlying bug was discovered by OpenAI in February but was not flagged as a security issue when the source code was patched. For Python specifically, the affected packages are Brotli 1.2.0 and brotlicffi 1.2.0.x. Because popular HTTP clients like requests, httpx, and aiohttp automatically pull these packages as optional dependencies, any service using those libraries could be exposed even if it never imports Brotli directly. As of October 23, pip-audit, Dependabot, and Safety had not flagged affected versions, making manual dependency-tree audits essential. Developers should upgrade to Brotli 1.2.1 or brotlicffi 1.2.1.0 and rebuild container images immediately.
