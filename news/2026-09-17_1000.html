B-01SKILL.mdを良くする技術——「自己進化エージェント」でAIの一貫性ギャップを埋める

📰 本文 + 和越対訳

C-01Dream-RSI: Recursive Self-Improvement for AI Agents via Evolving Replay Simulators

📰 Article (English)

Researchers from multiple institutions published "Dream-RSI: Recursive Self-Improvement through Evolving Worlds" (arXiv:2609.14858), a new framework that enables autonomous AI agents to continuously improve their exploration strategies without repeated expensive online trials. The core innovation is a "replay simulator" constructed from historical discovery trees — rather than rerunning costly online experiments to evaluate policy changes, the system reuses accumulated exploration history to cheaply estimate policy performance. This creates a self-reinforcing feedback loop: improved exploration policies drive more discoveries, which expand the replay simulator, enabling further policy refinement. The framework operates as an orchestration layer that does not modify the underlying agent, making it compatible with any exploration-based system. Experiments across three domains — algorithm engineering, mathematical optimization, and GPU kernel engineering — demonstrate that Dream-RSI achieves competitive or improved discovery quality while substantially reducing discovery cost. The key insight is making exploration "explicit and programmable," allowing recursive improvement without the Matthew Effect (harder problems getting proportionally less compute). Unlike fixed-strategy systems that degrade as search spaces scale, Dream-RSI adapts continuously as the agent accumulates more experience.

C-02NVIDIA Introduces CUDA Rust: Two Tracks for Native GPU Kernel Development

📰 Article (English)

NVIDIA announced native Rust support for GPU kernel development through "CUDA Rust," offering two distinct programming models that bring memory safety guarantees to GPU programming for the first time. The SIMT Track (cuda-oxide) is a custom Rust compiler backend that compiles Rust kernels directly to PTX assembly, routing code through Rust's MIR and an LLVM-based pipeline. It uses the DisjointSlice type to enforce exclusive thread access at compile time, eliminating the aliasing race conditions that plague CUDA C kernels. Currently in early alpha, it requires a pinned nightly toolchain and CUDA 12.x+. The Tile Track (cutile-rs) offers a higher-level abstraction working with tile-based tensor computations, JIT-compiling through CUDA Tile IR and requiring only stable Rust 1.89+ and CUDA 13.3. Already published on crates.io and adopted by HuggingFace's Grout and mistral.rs, cutile-rs is the more immediately usable path. Both approaches enforce safety at compile time, preventing the class of parallel access bugs that have historically made GPU kernel debugging notoriously difficult. This represents a fundamental shift in GPU systems programming, potentially reducing correctness burden for AI infrastructure teams building custom CUDA kernels for training and inference optimization.
