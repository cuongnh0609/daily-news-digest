B1MicrosoftエージェントフレームワークパッケージがPyPIで改ざん——資格情報窃取マルウェアを埋め込み

📰 本文 + 和越対訳

Microsoftが開発するAIエージェントフレームワーク向けPythonパッケージが、PyPI（Python Package Index）上で不正改ざんされていたことが明らかになった。攻撃者は正規パッケージに資格情報（APIキーや環境変数）を窃取するマルウェアを仕込み、インストールしたユーザーの開発環境から機密情報を奪う手口を使っていた。国内でも複数のAIエージェント開発者がこのパッケージを利用していたとみられており、被害範囲の確認が急がれる。ITmediaの報道によれば、MicrosoftはすでにPyPI側と連携して不正パッケージの削除対応を進めているが、ユーザーへのアップデート適用と認証情報のローテーションを早急に行うよう呼びかけている。今回の事案はサプライチェーン攻撃の典型例であり、開発者には依存パッケージの定期的な検証が改めて求められる。

Package Python dành cho AI agent framework của Microsoft đã bị phát hiện bị giả mạo trên PyPI (Python Package Index). Kẻ tấn công đã nhúng malware thu thập thông tin xác thực (API key, biến môi trường) vào package hợp lệ, nhằm đánh cắp thông tin bí mật từ môi trường phát triển của những người đã cài đặt. Nhiều nhà phát triển AI agent trong nước được cho là đã sử dụng package này, và việc xác định phạm vi thiệt hại đang được tiến hành khẩn cấp. Theo ITmedia, Microsoft đã phối hợp với PyPI để xóa package giả mạo, nhưng đang kêu gọi người dùng khẩn cấp áp dụng bản cập nhật và thực hiện credential rotation. Sự cố này là ví dụ điển hình của tấn công supply chain, và nhắc nhở các nhà phát triển cần thường xuyên kiểm tra các dependency.

C1External Sandboxes for Coding Agents: Three Open Implementations for Safe Tool Execution

📰 Article (English)

Simon Willison documented three open-source sandbox server implementations that allow coding agents to execute tools in isolated environments, addressing one of the core safety challenges in agentic engineering. The three implementations are: (1) a Docker-based sandbox that spins up ephemeral containers per code execution request, ensuring filesystem isolation; (2) a WebAssembly sandbox using WASM runtimes for in-process isolation without container overhead; and (3) a network-namespaced sandbox using Linux namespaces to prevent arbitrary network access during tool calls. Each approach trades off startup latency, security guarantees, and portability differently. The key insight is that production-grade coding agents must never execute untrusted code in the agent's own process space — a sandbox boundary must exist between the LLM's tool calls and the host system. Willison notes that while Claude Code, Cursor, and Devin each implement their own sandboxing, the lack of a standard interface has led to fragmented implementations across the ecosystem. These three reference servers aim to provide reusable primitives that agent frameworks can adopt as-is or fork.
