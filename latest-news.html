B2AkinatorでAgentic RL——LLMエージェントの質問戦略を強化学習で改善

📰 本文 + 和越対訳

Zennに掲載された技術記事では、Akinatorスタイルの人物当てゲームをタスクとして、LLMエージェントの質問戦略を強化学習（RL）で訓練する試みが報告されている。エージェントはK人の候補者リストを見ながら、質問ごとにyes/no/unknownで答えるLLMに問いかけ、理論上は約log₂K回の質問で正解を導けるかを検証するものだ。初期実験ではGPT-4.1-mini、GPT-4.1、o3を比較し、推論能力の高いo3が理論値に最も近い結果を示した。次にQwen3.5-4BをGRPOで学習させ、presence_penaltyの調整によりトレーニングが安定化。正答数と少ない質問数を同時に報酬として与える設計により、精度が0.89から0.96に向上し、平均質問数も3.70から3.54へ減少するという成果を得た。この手法はシンプルながらAgentic RLの基礎パターンとして再現性が高い。

Một bài kỹ thuật trên Zenn mô tả thử nghiệm huấn luyện chiến lược đặt câu hỏi cho LLM agent bằng reinforcement learning (RL) với game đoán nhân vật kiểu Akinator. Agent nhìn vào danh sách K ứng viên và hỏi một LLM khác đóng vai nhân vật đích với câu trả lời yes/no/unknown, mục tiêu là đoán đúng trong khoảng log₂K câu hỏi. Researchers have proposed HybridAgent, a new agent architecture that lets LLMs alternate between latent (internal, non-verbal) reasoning and text-based tool interaction within a single generation process. The key component is HybridLink, a lightweight module that handles transitions between the two modes while maintaining a continuous working memory across turns.
