B-03Microsoft Execution Containers（MXC）がGA——Windows 11でAIエージェントを安全に隔離実行

📰 本文 + 和越対訳

マイクロソフトは、Windows 11上でAIエージェントを安全に動かすための隔離実行環境「Microsoft Execution Containers（MXC）」の正式版（GA）を公開した。メールの自動返信や予定調整、ファイル整理など自律的な作業を行うエージェントが普及する中、誤削除や不正通信を防ぐ仕組みとして設計されている。MXCには主に3つの役割がある。エージェントのアクセス範囲と行動を制限すること、人間とAIの操作を明確に区別すること、そしてエージェントの活動を監視することだ。隔離方式はユースケースに応じて選べる構造になっており、コーディングエージェントや短期的なツール実行には軽量なAppContainer方式が向いている。長時間稼働するエージェントにはセッションコンテナが適しており、エージェントが別ユーザーアカウントで動作し、デスクトップや入力、クリップボードが人間の操作から完全に分離される。将来的にはWindows Intuneによる組織全体へのポリシー配布も予定されており、AnthropicのClaude Codeを含む複数のエージェントがMXC対応を表明している。

Microsoft đã phát hành phiên bản chính thức (GA) của "Microsoft Execution Containers (MXC)" — môi trường thực thi cách ly để vận hành an toàn các AI agent trên Windows 11. Trong bối cảnh các agent tự động thực hiện công việc như tự động trả lời email, lên lịch hẹn và sắp xếp file ngày càng phổ biến, MXC được thiết kế như một cơ chế ngăn chặn việc xóa nhầm và kết nối trái phép. MXC có ba vai trò chính: giới hạn phạm vi truy cập và hành động của agent, phân biệt rõ ràng thao tác của con người và AI, và giám sát hoạt động của agent. Cấu trúc cho phép chọn phương thức cách ly tùy theo use case — AppContainer nhẹ phù hợp với coding agent và thực thi công cụ ngắn hạn, trong khi Session Container phù hợp với agent chạy lâu dài, cho agent hoạt động với tài khoản người dùng khác và hoàn toàn tách biệt desktop, đầu vào và clipboard khỏi thao tác của con người. Trong tương lai, sẽ có phân phối policy toàn tổ chức qua Windows Intune, và nhiều agent bao gồm Claude Code của Anthropic đã tuyên bố hỗ trợ MXC.

C-03pg_vectorsearch: Timescale's New PRISM Index Beats pgvector IVFFlat and HNSW for 100M+ Vector Datasets in PostgreSQL

📰 Article (English)

Timescale released pg_vectorsearch, an open-source PostgreSQL extension introducing a new approximate nearest neighbor (ANN) index called PRISM — Partitioned Routing Index for Similarity Matching. The key claim: PRISM outperforms pgvector's IVFFlat and HNSW on both query speed and index build time for datasets of 100M+ vectors, while using a quarter of the memory that HNSW requires at equivalent recall. PRISM is an IVF-style index that uses a hierarchical centroid tree to route queries to relevant clusters. It applies RaBitQ quantization (SIGMOD 2024) to compress vectors into posting lists, with error bounds that skip non-candidates before full-precision reranking — reducing expensive heap fetches. The extension supports SIMD via AVX2, AVX512, and ARM NEON, and is binary-compatible with pgvector's vector and halfvec types, so existing pgvector columns can get a PRISM index with no table rewrite. Dynamic updates (insert, update, delete) are supported. The project is currently in alpha (PostgreSQL 18+ required) and the authors explicitly caution against production use. For teams already on PostgreSQL for their application data, pg_vectorsearch could eliminate the need for a separate vector database in high-scale RAG pipelines.

Approximate Nearest Neighbor (ANN) /əˈprɒksɪmɪt ˈnɪərɪst ˈneɪbər/ Tìm kiếm láng giềng gần đúng — thay vì tìm chính xác vector gần nhất (rất chậm với triệu vector), ANN tìm kết quả "đủ gần" với tốc độ nhanh hơn nhiều. Nền tảng của mọi vector DB.
HNSW /ˌeɪtʃ en es ˈdʌbljuː/ Hierarchical Navigable Small World — thuật toán index vector phổ biến nhất hiện nay, cho recall và tốc độ query cao nhưng tốn nhiều RAM (lưu toàn bộ đồ thị trong memory). pgvector dùng HNSW làm default.
IVF (Inverted File Index) /ˌaɪ viː ˈef/ Inverted File Index — chia vector space thành các cluster bằng k-means, khi query chỉ tìm trong một số cluster liên quan. Tốn ít RAM hơn HNSW nhưng thường chậm hơn. PRISM là IVF cải tiến.
Quantization /ˌkwɒntɪˈzeɪʃən/ Lượng tử hóa — kỹ thuật nén vector từ float32 (4 byte/chiều) xuống định dạng nhỏ hơn (float16, int8, binary). Giảm RAM và tăng tốc SIMD nhưng giảm nhẹ precision. RaBitQ là biến thể tiên tiến cho phép bỏ qua candidates không liên quan.
