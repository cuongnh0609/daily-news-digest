C-3Simon Willison: "So You Want to Use OpenRouter?" — A Practical Guide to Provider Inconsistency and How to Tame It

📰 Article (English)

Simon Willison published a practical guide to using OpenRouter, the API consolidation service that routes requests to many different AI model providers through a single endpoint. The central insight is counterintuitive for new users: OpenRouter's automatic routing is not a "set and forget" solution. Because different providers use different serving software, hardware configurations, and model optimizations, "the same OpenRouter endpoint can serve model requests that behave in different ways." Vision capabilities may be absent on some providers for vision models, and reasoning effort handling differs significantly. Willison recommends using the provider.only option to explicitly restrict which backend providers your requests can reach, eliminating unpredictable behavior in production systems. He also highlights the /endpoints API endpoint for discovering which providers serve a given model, allowing developers to make informed routing decisions.
